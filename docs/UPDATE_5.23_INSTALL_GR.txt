FLEET CONTROL 5.23 — ΟΔΗΓΙΕΣ ΕΝΗΜΕΡΩΣΗΣ

1. Worker/Web: κράτησε το υπάρχον wrangler.jsonc, τα bindings και τα secrets. Αντέγραψε τα ενημερωμένα αρχεία src/ και package.json στον υπάρχοντα φάκελο Worker, εκτέλεσε npm install και μετά npm run deploy.
2. Η νέα στήλη D1 δημιουργείται αυτόματα από τον Worker. Δεν χρειάζεται χειροκίνητο ALTER TABLE.
3. Web: ανέβασε το περιεχόμενο του Fleet_Control_Web_Update_v5.23.zip στον ίδιο φάκελο public/R2 ή χρησιμοποίησε το υπάρχον deployment flow.
4. Android Client: εγκατάστησε το Fleet_Control_Client_v5.23.apk πάνω από την έκδοση 5.22. Μην απεγκαταστήσεις την παλιά εφαρμογή.
5. Μετά την ενημέρωση, έλεγξε Admin → Βάρδιες → Χειροκίνητο Clock In και Payroll → Κανόνες πληρωμής.

Η έγκριση υπερωρίας πρέπει να δίνεται μόνο για τα λεπτά που θέλεις να πληρωθούν. Χωρίς έγκριση, ο χρόνος μετά το προγραμματισμένο Clock Out δεν προστίθεται στη μισθοδοσία.
