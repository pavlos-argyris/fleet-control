FLEET CONTROL — ΕΝΗΜΕΡΩΣΗ 5.35.1

1. Από το Server APK άνοιξε «Ενημερώσεις».

2. Ανέβασε και ενεργοποίησε το:

   `Fleet_Control_Client_v5.35.1.apk`

   Έχει versionCode `40`, επομένως συσκευή με έκδοση `5.35` θα εμφανίσει το prompt αυτόματης ενημέρωσης.

3. Ανέβασε και ενεργοποίησε το Web package:

   `Fleet_Control_Web_Assets_v5.35.1.zip`

4. Στο Web κάνε μία φορά `Ctrl+F5`. Στο APK η νέα έκδοση θα εμφανίσει το prompt μέσω του ενσωματωμένου ελέγχου ενημερώσεων.

5. Δεν χρειάζεται νέο Server APK ή νέο Worker deploy για αυτή τη διόρθωση, εφόσον ο Worker περιλαμβάνει ήδη το endpoint επανεπεξεργασίας τιμολογίων.

Η επόμενη λειτουργική έκδοση θα είναι `5.36` για Web και Client APK.
