# Fleet Control v5.27

## Τι διορθώθηκε

- Προστέθηκε κουμπί «Σκάναρε QR» με ζωντανή κάμερα στο νέο και στο παλιό service.
- Αν το QR επιστρέφει PDF ή σύνδεσμο PDF, ο Worker το εισάγει απευθείας στο ιδιωτικό R2.
- Αν η άντληση QR αποτύχει, παραμένει διαθέσιμη η φωτογραφία/PDF ως αυτόματη εναλλακτική.
- Η φωτογραφία τιμολογίου αποθηκεύεται πλέον ανεξάρτητα από την επιτυχία του OCR.
- Διορθώθηκε η μορφή αποστολής εικόνας στο Workers AI OCR, ώστε να μην εμφανίζονται κενά πεδία λόγω λάθος payload.
- Υποστηρίζονται εικόνες με κενό ή γενικό MIME όταν ο τύπος αναγνωρίζεται από την επέκταση ή την επικεφαλίδα του αρχείου.
- Η νέα σύνδεση τιμολογίου γίνεται και στον canonical snapshot του Worker, ώστε να μη χάνεται μετά από συγχρονισμό.
- Το Android Client ζητά άδεια κάμερας μόνο όταν χρησιμοποιείται ο QR scanner.

## Έλεγχοι

- Worker model, UI static checks, πρόγραμμα, μισθοδοσία και admin simulations: επιτυχία.
- Έλεγχος κοινών web assets: επιτυχία.
- Δεν έγινε πραγματική άντληση από πάροχο τιμολογίων χωρίς συγκεκριμένο QR/PDF URL και δεν υπήρχε Chromium για screenshot test.
