# Fleet Control 5.49.2 — σταθεροποίηση κίνησης καρτέλας

Client/Web 5.49.2 (66), Worker 5.10.4. Ο Server παραμένει 2.2.5 (31), με το ίδιο APK.

- Διατηρείται η ανάπτυξη από την επιλεγμένη κάρτα και η αντίστροφη κίνηση στην επιστροφή, διάρκειας 220 ms, χωρίς σβήσιμο διαφάνειας.
- Οι προηγούμενες κινήσεις `fill:both` δημιουργούνταν στο documentElement χωρίς ρητή ακύρωση. Αντικαθίστανται με CSS animations που ανήκουν στα προσωρινά pseudo-elements του View Transition και απομακρύνονται μαζί τους.
- Η πινακίδα παραμένει στην ίδια εικόνα με την κάρτα. Αφαιρείται η δεύτερη, ανεξάρτητη κίνηση και το πρόσθετο αντίγραφο κειμένου στο ενσωματωμένο Fleet.
- Η νέα εικόνα λαμβάνεται μετά από δύο κύκλους εργασιών σταθεροποίησης διάταξης/επαναφοράς θέσης (χωρίς αναμονή animation frame όσο η απόδοση είναι παγωμένη). Η αλλαγή ύψους του iframe και η επαναφορά της κάρτας ολοκληρώνονται πριν αρχίσει η κίνηση επιστροφής.
- Κατά τη διακοπή από επόμενη ενέργεια, τα styles χωρίς cross-fade διατηρούνται μέχρι ο browser να αφαιρέσει τα προσωρινά στιγμιότυπα. Ο καθαρισμός παλιότερης κίνησης δεν αλλάζει τη νεότερη.
- Η πράσινη ολισθαίνουσα ένδειξη των κάτω καρτελών παραμένει όπως στην 5.49.1. Διατηρούνται Μείωση κίνησης και άμεση πλοήγηση όταν το View Transition API δεν υποστηρίζεται. Δεν προστίθενται αιτήματα δικτύου ή αλλαγές δεδομένων.

## Έλεγχοι

`bash scripts/check-all.sh`: κύκλοι ανοίγματος/επιστροφής, ιστορικό Back/Forward, διακοπή, καθαρισμός styles και απουσία ανεξάρτητης πινακίδας.

Το υποχρεωτικό CI/publish gate `node scripts/test-navigation-motion-browser.mjs` εκτελεί πραγματικό Chromium σε Web, Portal, τοπικά αρχεία Client και Μείωση κίνησης. Περιλαμβάνει στιγμιότυπα ανοίγματος/επιστροφής, πολλαπλούς κύκλους με κύλιση της καρτέλας, επαναφορά της ίδιας κάρτας με ανοχή 3 px και έλεγχο ότι δεν μένουν animations στο documentElement. Διατηρούνται οι έλεγχοι αφής για την κάτω πλοήγηση. Τα στιγμιότυπα/αποτελέσματα αποθηκεύονται στο artifact navigation-motion-verification.

Οι δοκιμές browser χρησιμοποιούν συνθετικά δεδομένα. Δεν αποτελούν δοκιμή στη φυσική Samsung/WebView και δεν μεταβάλλουν παραγωγικά δεδομένα.

## Εγκατάσταση και ανάκτηση

Client: «Έλεγχος τώρα» και ενημέρωση σε 5.49.2 πάνω στην υπάρχουσα εφαρμογή. Web/Worker δημοσιεύονται μέσω του εξουσιοδοτημένου workflow. Δεν απαιτείται εγκατάσταση Server APK. Ο πλήρης κώδικας όλων των τμημάτων, τα APK, Web/Worker, build inputs και checksums παραδίδονται στο GitHub release.

Κράτησε το συνηθισμένο backup Server εκτός εφαρμογής πριν από ενημερώσεις. Η δημοσίευση δεν λαμβάνει από μόνη της backup παραγωγικών δεδομένων. Τα ιδιωτικά κλειδιά υπογραφής παραμένουν εκτός αποθετηρίου.
