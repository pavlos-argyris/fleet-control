# Κοινό αρχείο συνέχειας Fleet Control

Αυτό είναι το κοινό σημείο ενημέρωσης όλων των ChatGPT/βοηθών. Διάβασέ το πριν ξεκινήσεις και ενημέρωσέ το όταν αναλαμβάνεις εργασία, σε σημαντικά ορόσημα και πριν σταματήσεις. Οι καταγραφές διασταυρώνονται πάντα με GitHub branches/commits/PR/Actions και την ενεργή έκδοση.

## Μόνιμη οδηγία χρήστη — 27/10/2026

Κάθε αίτημα υλοποίησης/διόρθωσης περιλαμβάνει εξουσιοδότηση για συγχώνευση και αυτόματη δημοσίευση μετά από επιτυχείς ελέγχους. Δεν απαιτείται δεύτερη ερώτηση. Αίτημα μόνο καταγραφής issue ή ρητή εξαίρεση από δημοσίευση δεν ενεργοποιεί παραγωγή. Διατηρούνται όλοι οι έλεγχοι, τα αρχικά signing keys, ο πλήρης πηγαίος κώδικας και τα παραγωγικά δεδομένα. Διάβασε και το [AGENTS.md](../AGENTS.md).
