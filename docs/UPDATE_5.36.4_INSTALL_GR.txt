FLEET CONTROL — ΑΝΑΓΝΩΣΗ ΤΙΜΟΛΟΓΙΩΝ 5.36.4

1. Server APK

Εγκατέστησε πάνω από την υπάρχουσα εφαρμογή:
`Fleet_Control_Server_v2.0.10.apk`

Έχει versionCode `13`, επομένως εγκαθίσταται πάνω από την 2.0.9. Ο Server περιλαμβάνει τη διορθωμένη τοπική ανάγνωση των PDF Impact.

2. Client APK

Εγκατέστησε ή ανέβασε από την επιλογή «Ενημερώσεις»:
`Fleet_Control_Client_v5.36.4.apk`

Έχει versionCode `45`, επομένως αναγνωρίζεται ως νεότερο από την 5.36.3 και εμφανίζει prompt ενημέρωσης όταν το κατεβάσει ο Client.

3. Cloudflare Worker / Web

Κράτησε το υπάρχον production `wrangler.jsonc`, το πραγματικό D1 ID και όλα τα υπάρχοντα bindings. Μην αντικαταστήσεις τυφλά τη ρύθμιση.

Ανέβασε από την επιλογή «Ενημερώσεις» του Server APK το:
`Fleet_Control_Web_Worker_Update_v5.36.4.zip`

Ο Worker πρέπει να εμφανίσει τα υπάρχοντα bindings `DB`, `RELEASES`, `SERVICE_DOCS`, `AI` και `ASSETS`. Δεν χρειάζεται νέα βάση ή νέο bucket.

4. Χρήση χειροκίνητου fallback

Άνοιξε την καρτέλα «Τιμολόγια». Σε κάθε τιμολόγιο με διαθέσιμο PDF θα υπάρχει το κουμπί:
`⚡ Workers AI`

Το πατάς όταν θέλεις να ζητήσεις εσύ νέα ανάγνωση από Workers AI. Θα εμφανιστεί επιβεβαίωση και μετά η κάρτα θα γράψει ότι η ανάγνωση ζητήθηκε χειροκίνητα. Οι επιβεβαιωμένες διορθώσεις παραμένουν.

Η «Νέα ανάγνωση όλων» δεν χρησιμοποιεί υποχρεωτικά Workers AI: ξεκινά με τον τοπικό αναγνώστη του Server και κάνει fallback μόνο στα τιμολόγια που παραμένουν αμφίβολα.

5. Έλεγχος

Μετά το deploy, έλεγξε ότι το `/api/status` λειτουργεί και άνοιξε την καρτέλα «Τιμολόγια». Στο δοκιμαστικό format Impact οι εργασίες πρέπει να εμφανίζονται χωρίς κωδικούς, ενδεικτικά:

- ΛΑΔΙ YAMALUBE 20W50
- ΛΑΣΤΙΧΑ ΤΑΜΠΟΥΡΟΥ CRYPTON 105/115/135 FEDERAL
- ΣΙΑΓΩΝΕΣ Τ-135
- ΑΛΥΣΙΔΑ 420/112 MHQ

Αν κάποιο PDF παραμένει αμφίβολο, θα εμφανιστεί προειδοποίηση και μπορείς να πατήσεις `⚡ Workers AI` μόνο σε αυτό.
