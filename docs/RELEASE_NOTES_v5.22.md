# Fleet Control 5.22 / Worker 5.0.22

Η έκδοση 5.22 περιλαμβάνει το hotfix ειδοποιήσεων και διορθώσεις που προέκυψαν από πλήρη στατικό έλεγχο και admin προσομοιώσεις.

## Διορθώσεις

- Οι κανόνες μισθοδοσίας με `Ισχύει από/έως` χρησιμοποιούν πλέον την τοπική ημερομηνία Ευρώπης/Αθήνας, ακόμη και σε βάρδιες λίγο μετά τα μεσάνυχτα.
- Η μαζική δημιουργία προγράμματος απορρίπτει ίδιες ώρες έναρξης και λήξης, ώστε να μη δημιουργείται κατά λάθος 24ωρη βάρδια.
- Οι μη έγκυρες percent-encoded διαδρομές asset απορρίπτονται καθαρά.
- Το Android Client και Server δεν επιτρέπουν πλέον Android backup των τοπικών tokens/ρυθμίσεων και ανοίγουν εξωτερικούς συνδέσμους εκτός του τοπικού WebView.
- Το Server καθαρίζει αποτυχημένο αρχείο πριν την ολοκλήρωση backup και περιορίζει το μέγεθος απάντησης του Worker.
- Το Server versionCode ανεβαίνει σε 7 (`2.0.4`) για ασφαλή εγκατάσταση πάνω από το `2.0.3`.

## Αποτελέσματα ελέγχου

- Admin προσομοιώσεις: authentication, fleet, μόνιμη ανάθεση/αφαίρεση μηχανής, σύγκρουση προγράμματος, draft/publish, κάλυψη, ιδιόκτητο μηχανάκι, μισθοδοσία, υπερωρία, υγεία Server και Client update: επιτυχία.
- Regression και static UI checks: επιτυχία.
- APKs: v1/v2/v3 signature verification: επιτυχία.
- Δεν έγινε πραγματικός έλεγχος σε φυσική Android συσκευή, επειδή δεν υπάρχει συνδεδεμένη συσκευή/emulator στο περιβάλλον.

## Εγκατάσταση

1. Κράτησε το πραγματικό `wrangler.jsonc`, τα bindings, τα secrets, το D1 database ID και το R2 bucket.
2. Αντέγραψε μόνο τα ενημερωμένα `cloudflare-worker/src/` και `cloudflare-worker/package.json` και εκτέλεσε `npm install` και `npm run deploy`.
3. Το Web παραμένει στην έκδοση 5.21, επειδή οι διορθώσεις αυτές είναι Worker/Android και δεν χρειάζεται νέο web bundle.
4. Εγκατάστησε το `Fleet_Control_Client_v5.22.apk` πάνω από το υπάρχον Client.
5. Εγκατάστησε το `Fleet_Control_Server_v2.0.4.apk` πάνω από το υπάρχον Server. Δεν χρειάζεται απεγκατάσταση.

## Ανοιχτό θέμα ασφάλειας

Το Server APK περιέχει ακόμη το κοινόχρηστο Server key που χρησιμοποιεί το τρέχον production Worker. Αυτό δεν μπορεί να διορθωθεί μονομερώς με νέο APK: χρειάζεται συντονισμένη αλλαγή πρωτοκόλλου/secret στον Worker και rollout σε όλες τις Server συσκευές. Μέχρι τότε το key πρέπει να θεωρείται εκτεθειμένο σε όποιον αποκτήσει/decompile-άρει το APK.
