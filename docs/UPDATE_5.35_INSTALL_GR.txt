FLEET CONTROL — ΕΝΗΜΕΡΩΣΗ CLIENT 5.35

1. Από το Server APK άνοιξε «Ενημερώσεις».

2. Ανέβασε το αρχείο:

   `Fleet_Control_Client_v5.35.apk`

3. Ο Client θα ελέγχει:

   - στην εκκίνηση,
   - όταν επιστρέφει στο προσκήνιο,
   - και κάθε 15 λεπτά όσο παραμένει ανοιχτός.

4. Δεν χρειάζεται νέα εγκατάσταση του Server APK ούτε νέο deploy Worker/Web.

5. Για τη νέα ορατή πρόοδο της «Νέας ανάγνωσης όλων» ανέβασε επιπλέον από τις ενημερώσεις του Server το:

   `Fleet_Control_Web_Assets_v5.35.zip`

   Μετά την ενεργοποίηση κάνε μία ανανέωση της Web εφαρμογής (Ctrl+F5 στον υπολογιστή). Ο κύκλος θα εμφανίζεται αμέσως μετά την επιβεβαίωση της μαζικής νέας ανάγνωσης και θα ελέγχονται όλα τα τιμολόγια που έχουν αποθηκευμένο PDF.
