# Ordexa — αρχική διερεύνηση μόνο ανάγνωσης

Ημερομηνία: 28/10/2026. Η σύνδεση στον browser ολοκληρώθηκε και επαληθεύτηκε από τη συνδεδεμένη οθόνη του ordexa.gr. Εξετάστηκε μόνο η ενότητα αποτελεσμάτων «Διανομείς & βάρδιες», οι ορατές καταγραφές και ο δημόσια διαθέσιμος client JavaScript. Δεν εκτελέστηκε επεξεργασία επιχειρησιακών δεδομένων στο Ordexa.

## Πηγές και όρια επαλήθευσης

- Ορατή εφαρμογή: https://ordexa.gr/ — Deliveryman Οικονομικά.
- Δημόσιο client asset που δήλωνε το έγγραφο: `/assets/index-C14BgXZX.js`. Χρησιμοποιήθηκε μόνο για αναγνώριση αιτημάτων/σχήματος. Δεν αντιγράφεται ο κώδικας του παρόχου στο έργο.
- Η διεύθυνση API που ορίζει ο client είναι `https://api.ordexa.gr/api`. Πρόκειται για εσωτερική διεπαφή της ιστοσελίδας, όχι επιβεβαιωμένο δημόσιο ή υποστηριζόμενο API τρίτων.
- Η επιτυχής σύνδεση και οι πραγματικές οθόνες επιβεβαιώθηκαν στον browser. Το ακριβές JSON response και η ανεξάρτητη σύνδεση από Server APK δεν έχουν ακόμη επαληθευτεί. Δεν εξήχθησαν κωδικοί, cookies ή bearer token από τον browser.
- Ο διαθέσιμος ρόλος αποκλειστικά ανάγνωσης στον πάροχο δεν έχει επιβεβαιωθεί. Η ύπαρξη λογαριασμού δεν αποδεικνύει περιορισμένα δικαιώματα· ο connector χρειάζεται δικό του αυστηρό έλεγχο εξόδου.

## Διαδρομές προς ελεγχόμενη υλοποίηση

Τα παρακάτω προκύπτουν από τον δημόσιο client και συνδέονται με τις ορατές προβολές. Δεν έχουν επαληθευτεί ως ανεξάρτητες ζωντανές κλήσεις από τον Server.

| Ενέργεια | Method | Path κάτω από το σταθερό API origin |
| --- | --- | --- |
| Αυθεντικοποίηση | POST | /api/login |
| Έλεγχος συνδεδεμένου χρήστη | GET | /api/me |
| Διαθέσιμες πόλεις του λογαριασμού | GET | /api/cities |
| Αναφορά πόλης και αναλυτικές παρουσίες | GET | /api/cities/{cityId}/report?from=YYYY-MM-DD&to=YYYY-MM-DD |

Ο client συνδέεται με πεδία username/password και χρησιμοποιεί το token της απάντησης για εξουσιοδοτημένες αναγνώσεις. Καμία πραγματική τιμή δεν καταγράφεται εδώ. Δεν επιτρέπεται γενικό proxy, URL απόκρισης/χρήστη ως νέα διεύθυνση, αυθαίρετο method/path ή ανεξέλεγκτη ανακατεύθυνση. Η υλοποίηση πρέπει να διατηρεί σταθερό origin, ασφαλή κωδικοποίηση cityId/ημερομηνιών και συγκεκριμένο επιτρεπόμενο σύνολο ενεργειών. Άγνωστη ενέργεια σταματά πριν τη δικτυακή αποστολή.

Εκτός επιτρεπόμενων ενεργειών μένουν όλες οι αλλαγές terms/αμοιβών, settings, expenses, access, scenario/apply, προγράμματος ή clock in/out. Δεν δοκιμάζονται στην πραγματική υπηρεσία. Το POST login είναι η απαραίτητη αυθεντικοποίηση και δεν αποτελεί άδεια για άλλα POST.

## Σχήμα παρουσιών που χρησιμοποιεί η προβολή

Ο client διαβάζει `report.riders`, και για κάθε διανομέα χρησιμοποιεί `riderId`, `name` και `sessions`. Στις παρουσίες εμφανίζει:

| Πεδίο | Χρήση/απαίτηση διασύνδεσης |
| --- | --- |
| inAt | Αρχική χρονική σήμανση clock in. Διατηρείται πλήρης, με ζώνη/offset, όχι μόνο το ορατό HH:mm. |
| outAt | Αρχική χρονική σήμανση clock out ή κενή τιμή. Κενό δεν μετατρέπεται σε ολοκληρωμένη πληρωτέα βάρδια. |
| day | Ημέρα αναφοράς του παρόχου. Διατηρείται χωριστά από τις πραγματικές ημερομηνίες εισόδου/εξόδου. |
| unclosed / forgotten | Ενδείξεις ελλιπούς εξόδου. Χρειάζεται καταγραφή κατάστασης και χειρισμός στο Fleet Control. |
| long | Ένδειξη μεγάλης διάρκειας. Χρειάζεται έλεγχος, όχι σιωπηρή διόρθωση στο Ordexa. |
| choice / shift | Επιλογή ή περιγραφή βάρδιας στον πάροχο, χρήσιμη ως πληροφορία προέλευσης. |
| hours / pay | Υπολογισμοί του Ordexa. Δεν υποκαθιστούν τα αρχικά clock in/out και τους κανόνες μισθοδοσίας του Fleet Control. |

Η οθόνη αναφέρει ρητά ότι οι ώρες μπορεί να είναι πληρωμένες ώρες επιλεγμένης βάρδιας και όχι η πραγματική διάρκεια clock in/out. Συνεπώς οι μισθοδοσίες του Fleet Control πρέπει να τροφοδοτούνται από τις αρχικές χρονικές σημάνσεις. Παρατηρήθηκαν ορατά πολλαπλά τμήματα ανά ημέρα, νυχτερινές έξοδοι, ιστορικές ελλιπείς έξοδοι και ενεργή παρουσία χωρίς ολοκληρωμένο clock out. Ακριβής μετατροπή ζώνης, αλλαγή θερινής ώρας, ομαδοποίηση και επανεισαγωγή πρέπει να ελεγχθούν με συνθετικά δεδομένα.

## Πολλαπλά clock in/out — απαίτηση χρήστη προς μελλοντική οριστικοποίηση

Ο χρήστης εξήγησε στις 28/10/2026 ότι προσωρινή αποσύνδεση από την πλατφόρμα μπορεί να καταγραφεί ως clock out, παρότι ο διανομέας συνεχίζει να εργάζεται. Θέλει να ορίζει ο ίδιος χρονικό όριο και πρόσθετους κανόνες που αναγνωρίζουν αυτή τη συνέχεια και χρησιμοποιούν το τελικό clock out της ενιαίας εργασίας. Υπάρχουν επίσης πραγματικές χωριστές βάρδιες, π.χ. 7–8 ώρες πρωί και άλλες 4 το βράδυ, που δεν πρέπει να συγχωνεύονται αδιακρίτως.

- Διατηρούνται αμετάβλητες όλες οι αρχικές καταγραφές από το Ordexa, χωριστά από την υπολογισμένη ομαδοποίηση στο Fleet Control.
- Ο ακριβής ορισμός του ορίου, των εξαιρέσεων και της εφαρμογής των κανόνων θα συζητηθεί αργότερα. Δεν επιλέγεται τώρα αυθαίρετο όριο ή προεπιλεγμένη αυτόματη συνένωση.
- Απαιτείται μελλοντικός έλεγχος προσωρινής αποσύνδεσης, πολλών διαδοχικών επανασυνδέσεων, πραγματικής διπλής βάρδιας, αλλαγής ημέρας και ελλιπούς τελικής εξόδου.
- Η διόρθωση/ομαδοποίηση αφορά μόνο το Fleet Control και δεν γράφει ποτέ αλλαγές πίσω στο Ordexa.

## Απαιτήσεις επόμενου βήματος

- Ελεγχόμενη σύνδεση από Server APK με προστατευμένα διαπιστευτήρια, αποκλειστικά μέσω των επιτρεπόμενων ενεργειών.
- Πρώτα προεπισκόπηση/έλεγχος σχήματος και αντιστοίχιση υπάρχοντος εργαζομένου με σταθερό riderId· καμία αυτόματη δημιουργία διπλών εργαζομένων από ονόματα.
- Οι πραγματικές παρουσίες εισάγονται ανεξάρτητα από την ύπαρξη ή δημοσίευση προγράμματος στο Fleet Control. Χρησιμοποιείται ο υπάρχων μηχανισμός μισθοδοσίας και προστατεύονται κλειδωμένες περίοδοι.
- Η επανεισαγωγή δεν διπλομετρά ώρες. Χρειάζεται επαλήθευση σταθερού ID παρουσίας ή ρητά ελεγχόμενη εναλλακτική ταυτότητα, με χειρισμό αλλαγής clock in/out και σύγκρουσης τοπικών διορθώσεων.
- Άγνωστο σχήμα, αποτυχία ανάγνωσης, κενό αποτέλεσμα, νέα προσπάθεια ή ακύρωση δεν αποτελούν εντολή διαγραφής/αντικατάστασης υπάρχοντος ιστορικού.
- Έλεγχοι περιορισμού εξόδου με test double πριν από οποιαδήποτε αποστολή, εισαγωγής/μισθοδοσίας με συνθετικά δεδομένα και συμβατότητας backup/mirror/Server/Client/Worker.

Δεν έχει υλοποιηθεί ή ενεργοποιηθεί αυτόματος connector, δεν έχουν εισαχθεί παρουσίες σε παραγωγική βάση Fleet Control και δεν έγινε νέα έκδοση ή δημοσίευση. Η παρούσα καταγραφή τεκμηριώνει τον πρώτο έλεγχο και τον δεσμευτικό περιορισμό μόνο ανάγνωσης.
