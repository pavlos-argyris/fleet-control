# Fleet Control 5.36.5 / Server 2.0.11 / Worker 5.0.40

## Τι διορθώθηκε

- Η διαγραφή τιμολογίου κατά τη «Νέα ανάγνωση όλων» το αφαιρεί από την κοινή ουρά αντί να αφήνει τη διαδικασία κολλημένη ή να το μετρά ως αποτυχία OCR.
- Η κοινή ουρά συνεχίζει στα υπόλοιπα τιμολόγια και καταγράφει τις σκόπιμες παραλείψεις χωριστά από τα σφάλματα.
- Ο Server APK αποθηκεύει και εμφανίζει ζωντανά την κατάσταση της επεξεργασίας: τρέχον PDF, ποσοστό, στάδιο, Workers AI fallback, παραλείψεις και σφάλμα.
- Η μαζική ανάγνωση δεν περιμένει πλέον τον επόμενο πλήρη κύκλο συγχρονισμού ανά τιμολόγιο· συνεχίζει διαδοχικά όσο υπάρχει σύνδεση.
- Η οθόνη Server ανανεώνει την ένδειξη κάθε δευτερόλεπτο και κάνει ελαφρύ έλεγχο της κοινής ουράς περίπου κάθε 5 δευτερόλεπτα, χωρίς να περιμένει τον πλήρη συγχρονισμό.
- Προστέθηκε έλεγχος stale batch ώστε διαδικασία χωρίς ενημέρωση για 20 λεπτά να εμφανίζεται ως σφάλμα αντί να μένει επ’ αόριστον σε επεξεργασία.

- Server APK: `2.0.11`, versionCode `14`.
- Web: `5.36.5`.
- Cloudflare Worker runtime: `5.0.40`.
