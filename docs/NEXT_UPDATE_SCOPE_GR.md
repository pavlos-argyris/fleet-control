# Fleet Control 5.43.0 — συμφωνημένο επόμενο update

Κατάσταση: υλοποίηση. Δεν έχει δημοσιευτεί. Ασφαλής βάση: 5.42.1,
source commit 2fea67ca31fb3077a8b26ebbe56631846712747e.

- Όμορφη επιλογή σε διαφορά χιλιομέτρων: εφαρμογή ένδειξης τιμολογίου ή διατήρηση ένδειξης service. Και οι δύο ολοκληρώνουν τον έλεγχο.
- Πλήρες ιστορικό με ένδειξη service, τιμολογίου και αρχική χειροκίνητη ένδειξη όταν διορθώθηκε.
- Ιστορικό αποφάσεων και ασφαλής αναίρεση μόνο εφόσον δεν έχουν μεσολαβήσει αλλαγές.
- Έλεγχος καθαρής αξίας, ΦΠΑ και τελικού ποσού.
- Προβολή PDF με αναζήτηση πεδίων και επισήμανση όταν υπάρχει κείμενο.
- Προεπισκόπηση επαναφοράς backup πριν από μεταβολή δεδομένων.
- Σύνολο κόστους ανά μηχανάκι, επιλεγμένα και ενεργό στόλο, περίοδος βάσει ημερομηνίας service ή τιμολογίου, Excel/PDF και σαφείς ενδείξεις ελλιπών ποσών.
- Απόκρυψη περιττής «Τελευταίας λήψης δεδομένων» από κανονική προβολή.
- Παράκαμψη cache ως επεξηγημένη υποεπιλογή «Νέα ανάλυση από την αρχή».
- Συντήρηση ανά εργασία με προαιρετικά όρια χιλιομέτρων/ημερών που ορίζει ο χρήστης.
- Νέο service: ημερομηνία/χιλιόμετρα, χωρίς χειροκίνητο συνεργείο/κόστος, μικρές όμορφες επιλογές δύο ανά σειρά, πρότυπα, προσχέδια και αποθήκευση/επόμενο.
- Ανθεκτική εκκρεμής ουρά τιμολογίων στο παρασκήνιο με αποφυγή διπλού ανεβάσματος.
- Πλήρης πηγαίος κώδικας, συμβατά APK, Web, Worker, εξαρτήσεις, οδηγίες και SHA-256 στο ιδιωτικό GitHub. Παράδοση μέσω συνδέσμων αντί αρχείων στη συνομιλία.
- Αυτόματη δημοσίευση μόνο μετά από επιτυχείς ελέγχους του ακριβούς source commit.

Η αποσύνδεση του περιβάλλοντος διέγραψε τις προηγούμενες τοπικές,
μη ανεβασμένες αλλαγές. Επαναδημιουργούνται από την επαληθευμένη βάση.
Η πρόοδος αποθηκεύεται σταδιακά στο GitHub χωρίς παραγωγικό deploy.
