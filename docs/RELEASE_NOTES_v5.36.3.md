# Fleet Control v5.36.3 / Server 2.0.9 / Worker 5.0.38

Η έκδοση διορθώνει το `NaN%` στην κοινή νέα ανάγνωση τιμολογίων.

- Ο Server αποθηκεύει τις ώρες προόδου ως ISO timestamps και το Web/Client τις μετατρέπει πλέον σωστά.
- Το συνολικό ποσοστό έχει προστασία για κενές, μη αριθμητικές ή μη έγκυρες τιμές και παραμένει πάντα μεταξύ 0% και 100%.
- Η διόρθωση εφαρμόζεται τόσο στην έκδοση Web όσο και στην ενσωματωμένη σελίδα του Client APK.
- Ανεβαίνει το Android `versionCode` ώστε να εμφανιστεί κανονικά το prompt ενημέρωσης.
- Ο χρόνος στα μεμονωμένα τιμολόγια ξεκινά από την τρέχουσα/τελευταία προσπάθεια και δεν χρησιμοποιεί την αρχική ημερομηνία ενός παλιού QR.
- Οι παλιές ή κολλημένες εργασίες εμφανίζουν `Χρόνος: >10:00` αντί για τεράστιους αριθμούς και οι επαναλήψεις ξεκινούν νέο χρονόμετρο.
- Ο κύκλος προόδου QR/τιμολογίων έγινε Canvas wiggly ring: η γραμμή κυματίζει και πάλλεται συνεχώς, με ομαλή μετάβαση του ποσοστού και διαφορετικό χρώμα για καθυστέρηση ή σφάλμα.
- Η ίδια Canvas υλοποίηση μπήκε στο Web και στο embedded WebView του APK, χωρίς αλλαγή της υπάρχουσας Java/WebView αρχιτεκτονικής και χωρίς νέα Compose εξάρτηση.

Εκδόσεις:

- Client APK: `5.36.3`, versionCode `44`.
- Server APK: `2.0.9`, versionCode `12` — δεν χρειάζεται αλλαγή για αυτή τη διόρθωση.
- Web: `5.36.3`.
- Cloudflare Worker runtime: `5.0.38`.
