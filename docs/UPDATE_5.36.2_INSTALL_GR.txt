FLEET CONTROL — ΟΔΗΓΙΕΣ ΕΝΗΜΕΡΩΣΗΣ 5.36.2 / SERVER 2.0.9

1. Κράτησε αντίγραφο ασφαλείας του υπάρχοντος φακέλου Fleet Control.

2. Cloudflare Worker

Άνοιξε CMD στον φάκελο:
`C:\Users\User\Downloads\Fleet_Control_Cloudflare_v5.0\cloudflare-worker`

Αντέγραψε μόνο τα νέα `src`, `public`, `package.json`, `package-lock.json` και τις οδηγίες. Κράτησε το δικό σου `wrangler.jsonc` με το πραγματικό D1 ID και τα παραγωγικά bindings. Δεν το αντικαθιστάς τυφλά.

Έλεγξε ότι υπάρχουν τα bindings `DB`, `RELEASES`, `SERVICE_DOCS`, `AI`, `ASSETS` και εκτέλεσε:

`npm install`

Αν εμφανιστεί blocked install script:

`npm install-scripts approve esbuild workerd`

`npm install`

Μετά:

`npm run deploy`

3. Ενημέρωση APK

Στο Server APK εγκατέστησε πρώτα:
`Fleet_Control_Server_v2.0.9.apk`

Μετά εγκατέστησε στους χρήστες το:
`Fleet_Control_Client_v5.36.2.apk`

Ο Server πρέπει να είναι online για την τοπική ανάγνωση QR και για τη «Νέα ανάγνωση όλων». Αν αποτύχει η τοπική ανάγνωση ή είναι αμφίβολη, ο Worker χρησιμοποιεί αυτόματα Workers AI και το τιμολόγιο εμφανίζεται με προειδοποίηση.

4. Web

Ανέβασε στο Server APK από την επιλογή «Ενημερώσεις» το:
`Fleet_Control_Web_Worker_Update_v5.36.2.zip`

ή, αν η διαδικασία σου ζητά ξεχωριστά αρχεία, χρησιμοποίησε τα περιεχόμενα του:
`Fleet_Control_Web_Assets_v5.36.2.zip`

Μετά άνοιξε την καρτέλα «Τιμολόγια» και έλεγξε ότι εμφανίζεται η επιλογή «Μεταφορά τιμολογίου σε άλλο service» σε κάθε αποθηκευμένο PDF.
