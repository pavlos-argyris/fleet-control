FLEET CONTROL — ΟΔΗΓΙΕΣ ΕΝΗΜΕΡΩΣΗΣ 5.32 / SERVER 2.0.7

1. Κάνε πρώτα ένα χειροκίνητο backup από το Server APK.
2. Κάνε deploy τον Worker από τον υπάρχοντα φάκελο `cloudflare-worker`:

   npm install
   npm run deploy

   Μην αντικαταστήσεις τυφλά το `wrangler.jsonc` και μην αλλάξεις το D1 ID.
3. Εγκατέστησε πάνω από την προηγούμενη έκδοση το:

   `Fleet_Control_Server_v2.0.7.apk`

4. Από το Server APK, στην καρτέλα «Ενημερώσεις», ανέβασε:

   `Fleet_Control_Client_v5.32.apk`

   και το ZIP `Fleet_Control_Web_Assets_v5.32.zip`.

   Το `Fleet_Control_Web_Worker_Update_v5.32.zip` είναι ο φάκελος πηγαίου
   κώδικα για το χειροκίνητο Cloudflare deploy· δεν το ανεβάζεις στο κουμπί
   «Web» του Server APK. Εκεί ανεβαίνει μόνο το ZIP με τα web assets.
5. Μετά την ενεργοποίηση κάνε ανανέωση της Web καρτέλας και έλεγξε ένα ιστορικό service με δύο διαφορετικά χιλιόμετρα. Το μεγαλύτερο πρέπει να εμφανίζεται πρώτο.
6. Για δοκιμή backup τιμολογίων, χρησιμοποίησε backup που δημιουργήθηκε αφού εγκαταστάθηκε ο Server `2.0.7`. Κατά την επαναφορά επίλεξε το `.fcbackup` από τον ίδιο φάκελο όπου υπάρχει το αντίστοιχο `.fcdocs`.
