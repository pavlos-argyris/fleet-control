# Fleet Control 5.61.2 — διόρθωση αρχικοποίησης Server, υπό έλεγχο

Server 2.10.20 (74), Client/Web 5.61.0 (Client 104), Worker 5.18.8.
Η νέα έκδοση δεν έχει ακόμη δημοσιευτεί. Η προηγούμενη 5.61.1 παραμένει η ενεργή ενημέρωση.

- Διορθώνεται η αποστολή σχολίων του σχήματος ως ξεχωριστών SQL εντολών στο Android, που αναπαράγει το `Local capability failed (bundled-business#2)` στην αρχικοποίηση της μεταφοράς.
- Οι δοκιμές SQLite εφαρμόζουν πλέον και τους περιορισμούς του Android για κενές εντολές και επιστροφή αποτελεσμάτων από execSQL.
- Τα διαγνωστικά περιλαμβάνουν συγκεκριμένη λειτουργία και κατηγορία σφάλματος, με απόκρυψη SQL, τιμών παραμέτρων και προσωπικών δεδομένων.
- Διατηρούνται συναλλαγές/rollback, αμετάβλητο ιστορικό, έλεγχοι εξουσιοδότησης, πλήρες backup και δοκιμή ανάκτησης.
- Περιλαμβάνονται οι πέντε επαληθευμένοι πόροι Rhino της διόρθωσης 5.61.1.
