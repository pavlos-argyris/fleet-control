# Fleet Control 5.41.0

- Διακοπή και νέα προσπάθεια καθυστερημένου QR, με νέο job ID και αποκλεισμό παλιών αποτελεσμάτων.
- Ανεξάρτητος συγχρονισμός στόλου, τιμολογίων, αντιγράφου προσωπικού και σύνδεσης.
- Μικρή απάντηση όταν δεν έχει αλλάξει ο στόλος και τμηματικό αντίγραφο βάσης.
- Αναλυτικά στάδια, ακριβής διαδρομή σφάλματος και ενέργειες αποκατάστασης στον Server.
- Συνέχιση διακοπείσας μαζικής ανάγνωσης από τον αποθηκευμένο δείκτη.
- OTA UI Client στο ύφος του Server, με πραγματική πρόοδο λήψης και συνεχή φωτεινή γραμμή.
- Άμεσο εφέ σε κάθε χειροκίνητο έλεγχο ενημέρωσης και σε κάθε ενεργό στάδιο Server/Client.

Server 2.1.7 (code 23), Client/Web 5.41.0 (code 54), Worker 5.4.0. Αρχικές υπογραφές. Ενημέρωσε και τα δύο APK μετά από backup· Web/Worker ενεργοποιούνται αυτόματα.

Η πλήρης σουίτα, οι δοκιμές μεγάλου ιστορικού/ακύρωσης/σελιδοποίησης, Java HTTP/snapshot/mirror/OTA/PDF, build APK και dry-run Worker ελέγχθηκαν. Οι δοκιμές UI έγιναν σε VM, χωρίς εγκατάσταση ή οπτικό έλεγχο φυσικού Android. Δεν έγινε πραγματικό scan/AI ή παραγωγικό backup/restore από τον βοηθό. Το backup βασίζεται στο τελευταίο επιτυχές τοπικό mirror· έλεγξε την ολοκλήρωσή του πριν πάρεις πρόσφατο backup.

Πλήρεις οδηγίες και περιορισμοί: docs/SYNC_RECOVERY_UPDATE_5.41.0_GR.md.
