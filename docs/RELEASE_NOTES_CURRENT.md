# Fleet Control 5.51.2

Client/Web 5.51.2 · Server 2.2.10 · Worker 5.12.2.

- Ολόκληρο το «Όλες οι πινακίδες» σε Web και APK με περισσότερο διαθέσιμο πλάτος.
- Επιλογή πινακίδας και πρόσθετων φίλτρων με κοινό παράθυρο στο UI της εφαρμογής.
- Αναζήτηση πινακίδας και σαφής επισήμανση της τρέχουσας επιλογής.
- Ομαλό swipe και συρόμενο πράσινο περίγραμμα στις τρεις ουρές τιμολογίων.
- Διατήρηση σωστού φιλτραρίσματος και επιστροφής με Πίσω χωρίς έξοδο από την εφαρμογή.
- Σαφές κουμπί «Πώς λειτουργεί;» αντί για σκέτο ερωτηματικό στα εργαλεία τιμολογίων.
