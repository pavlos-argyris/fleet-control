# Fleet Control 5.40.1

Client/Web 5.40.1 · Server 2.1.6 · Worker 5.3.3

- Ελαφρύτερη ανάγνωση στόλου/κατάστασης και ενημέρωση τιμολογίου, για τις αποτυχίες exceededCpu/503.
- Συγχρονισμός ανά αλλαγμένη μηχανή, με διατήρηση τοπικών εκκρεμοτήτων σε διακοπή σύνδεσης.
- Πραγματική επανάληψη ανάγνωσης αποθηκευμένου PDF μετά από σφάλμα AI.
- Προσωρινά 503 παραμένουν στην ουρά και δεν καταναλώνουν τις προσπάθειες δημιουργίας PDF.
- Προορισμοί μεταφοράς φορτώνονται όταν ανοίγει ο έλεγχος.
- Προστασία από καθυστερημένη πρόοδο/σφάλμα σε ήδη ολοκληρωμένο PDF.

Πέρασαν οι δοκιμές Worker/SQLite με 20.000 συνθετικές εγγραφές, 200 τιμολόγια και 10 ταυτόχρονες ενημερώσεις, η προηγούμενη σουίτα και οι έλεγχοι Client/Java. Η τοπική προσομοίωση δεν αποτελεί μέτρηση Cloudflare CPU ή δοκιμή σε φυσική συσκευή. Διατηρούνται οι υπογραφές και το σχήμα δεδομένων. Οδηγίες: docs/CPU_SNAPSHOT_UPDATE_5.40.1_GR.md.
