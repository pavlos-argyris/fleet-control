# Fleet Control 5.39.0

Client/Web 5.39.0 · Server 2.1.3 · Worker 5.3.0

- Στο Νέα ανάγνωση όλων επιλέγεις Server πρώτα ή Μόνο Workers AI σε νέο παράθυρο με δύο κάρτες. Η επιλογή επιβάλλεται στον Worker και ο Server παρακάμπτει την τοπική ανάγνωση όταν ζητηθεί μόνο AI.
- Οι ομάδες πινακίδων παραμένουν κλειστές κατά την αυτόματη ανανέωση και ανοίγουν/κλείνουν ομαλά.
- Νέα Λίστα τιμολογίων: όλα τα PDF, μόνο όνομα και Άνοιγμα/Λήψη, ανά συνδεδεμένη πινακίδα και ημερομηνία τιμολογίου, με αναζήτηση και φίλτρο πινακίδας.
- Διατηρούνται επιβεβαιωμένες διορθώσεις, αρχικές υπογραφές Android, κλειδιά και σχήμα βάσης.

Οι δοκιμές περιλαμβάνουν την πραγματική συμπεριφορά των Portal functions, επιβολή επιλογής στο API, αποτυχία AI χωρίς τοπική υποκατάσταση, υπάρχουσες λειτουργίες service/μισθοδοσίας/προγράμματος, συνθετικά backup, κατασκευή APK και έλεγχο υπογραφών. Browser screenshots και πραγματική εγκατάσταση συσκευής δεν έχουν εκτελεστεί.
