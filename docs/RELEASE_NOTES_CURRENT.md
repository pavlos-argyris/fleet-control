# Fleet Control 5.37.0 / Server 2.1.0 / Worker 5.1.0

- Πλήρες έργο για ιδιωτικό GitHub, με ιστορικό Git και οδηγίες ανεξάρτητης ανάπτυξης.
- Έλεγχοι σε κάθε push/PR. Ρητή δημοσίευση μέσω της ενέργειας “Publish Fleet update”.
- Εγκατάσταση του ripgrep στα workflows ελέγχου και δημοσίευσης, ώστε τα Android build scripts να λειτουργούν σε καθαρό Ubuntu runner.
- Αρχική καταχώριση των 8 repository secrets και των 5 variables από Windows με το `Setup_OTA_Secrets.ps1`. Διαβάζει τα υπάρχοντα bindings, επιβεβαιώνει το Worker URL και το αρχικό signing container, κρατά το υπάρχον release token και δεν δημοσιεύει update. Περιλαμβάνονται δοκιμές με προσομοιωμένα GitHub/Cloudflare και έλεγχος σύνταξης PowerShell στο CI.
- Build και υπογραφή APK με το αρχικό πιστοποιητικό. Επαλήθευση package/version/πιστοποιητικού πριν από τη δημοσίευση.
- Πλήρες ZIP πηγαίου κώδικα και αρχεία έκδοσης σε κάθε GitHub release.
- OTA έλεγχος Server ανά 15 λεπτά, λήψη συγκεκριμένης έκδοσης, έλεγχος SHA-256, μεγέθους, versionCode και υπογραφής.
- Backup Server σε επιλεγμένο εξωτερικό φάκελο πριν από την εγκατάσταση, αφού ολοκληρωθεί ένας επιτυχής κύκλος συγχρονισμού. Αποτυχία backup εμποδίζει την εγκατάσταση.
- Αυτόματη εγκατάσταση όπου την επιτρέπει το Android, διαφορετικά επιβεβαίωση από την εφαρμογή ή την ειδοποίηση.
- Client: λήψη του ακριβούς APK που αντιστοιχεί στο manifest και κοινός installer με έλεγχο υπογραφής. Η επιλογή ενημέρωσης παραμένει στον χρήστη.
- Client/Web/Server ενεργοποιούνται με μία συναλλαγή μετά την επαλήθευση όλων των αρχείων. Το Server APK και το manifest του απαιτούν το υπάρχον κλειδί Server.
- Διατηρούνται οι προηγούμενες διορθώσεις service, πολλαπλών τιμολογίων, αποθήκευσης στο background και αντιστοίχισης ελληνικών/λατινικών πινακίδων.

Έλεγχοι: μεταγλώττιση και υπογραφές APK, Worker dry-run, πραγματικά endpoints σε τοπικό SQLite/R2, ατομική ενεργοποίηση/αποτυχία, απαγόρευση downgrade, διατήρηση συγκεκριμένων λήψεων, service/QR, πρόγραμμα, μισθοδοσία, διαχείριση και συνθετικό backup/restore.

Ο πλήρης κώδικας έχει αποθηκευτεί στο ιδιωτικό GitHub, μαζί με πλήρες Git bundle του αρχικού ιστορικού. Δεν έγινε εγκατάσταση σε πραγματική Android συσκευή ή παραγωγική δημοσίευση στο Cloudflare. Το υπογεγραμμένο πακέτο προορίζεται για αρχική σύνδεση και έλεγχο στο S24 Ultra. Το ιστορικό κώδικα και οι δοκιμές με συνθετικά δεδομένα δεν αποτελούν backup παραγωγής.
