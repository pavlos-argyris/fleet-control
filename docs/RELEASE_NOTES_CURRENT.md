# Fleet Control 5.50.1

- Λίστα «Για το επόμενο service» ξεχωριστά σε κάθε μηχανή.
- Νέες σημειώσεις κάτω από τις άλλες εργασίες κατά την καταχώρηση service.
- Υπενθύμιση εκκρεμών εργασιών και προαιρετική ολοκλήρωση όσων έγιναν τώρα.
- Διατήρηση σημειώσεων σε προσχέδια, συγχρονισμό και backup με δυνατότητα επαναφοράς αφαιρεμένων.
- Ταχύτερη διανομή με περιορισμένες παράλληλες μεταφορές και αναλυτική πρόοδο δημοσίευσης.
