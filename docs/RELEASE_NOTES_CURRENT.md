# Fleet Control 5.49.3

• Η επιστροφή από μηχανάκι δείχνει καθαρή πράσινη επιφάνεια με πινακίδα και εικονίδιο.
• Το πλαίσιο συρρικνώνεται προς τη σωστή κάρτα χωρίς μικρογραφία των λεπτομερειών.
• Διατηρούνται η θέση στη λίστα και η ολισθαίνουσα πράσινη κάτω ένδειξη.
