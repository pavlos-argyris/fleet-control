# Fleet Control 5.39.1

Client/Web 5.39.1 · Server 2.1.4 · Worker 5.3.1

- Οι ρυθμίσεις Server διατηρούν το πρόχειρο μέχρι την αποθήκευση, χωρίς επαναφορά από το polling.
- Ο έλεγχος OTA γίνεται κάθε λεπτό, ανεξάρτητα από το διάστημα πλήρους συγχρονισμού. Η ουρά τιμολογίων παραχωρεί προτεραιότητα στην ενημέρωση μετά την ολοκλήρωση του τρέχοντος αποτελέσματος και συνεχίζεται από τον αποθηκευμένο δείκτη.
- Νέα κάρτα OTA με πραγματική πρόοδο λήψης, στάδια ελέγχου/backup/εγκατάστασης και σαφή επιβεβαίωση Android.
- Οι σημειώσεις αλλαγών εμφανίζονται σε bullets στον Server και Client, και για παλαιότερες σημειώσεις με κόμματα.
- Ανεξάρτητος παλμός σύνδεσης κατά την παράλληλη επεξεργασία δέκα τιμολογίων, ελαφρύς έλεγχος σύνδεσης και περιορισμένες επαναλήψεις GET σε προσωρινά HTTP 429/502/503/504.
- Νέο κουμπί στο κάτω μέρος του Fleet «Σειρά τελευταίων service»: ενεργά μηχανάκια από το πιο πρόσφατο προς το παλαιότερο βάσει ημερομηνίας service, με ημερομηνία/χιλιόμετρα και τελευταία αλλαγή λαδιών. Το ανέβασμα παλιού τιμολογίου ή μεγαλύτερα χιλιόμετρα δεν αλλάζουν τη χρονολογική σειρά. Αρχικές ενδείξεις και έλεγχοι χιλιομέτρων εξαιρούνται. Αν η καρτέλα υπολογίζει περισσότερα χιλιόμετρα λαδιών από τη χρονολογικά τελευταία αλλαγή, εμφανίζεται επισήμανση για έλεγχο. Το Πίσω επιστρέφει στο Fleet και στην προηγούμενη θέση κύλισης· από καρτέλα μηχανής επιστρέφει πρώτα στη λίστα. Η λίστα είναι ενημερωτική και δεν αλλάζει αυτόματα χιλιόμετρα/όρια service.
- Σταθεροποίηση κύλισης σε Fleet/Portal/Server: σταθερά ύψη viewport, κατάργηση ελαστικής κύλισης και μεταφοράς scrolling μεταξύ παραθύρου/σελίδας/iframe, ένα βασικό σημείο κύλισης ανά παράθυρο, κλείδωμα υποβάθρου με ανοικτό dialog, λιγότερα βαριά εφέ σε οθόνες αφής. Η εμφάνιση πληκτρολογίου και περιστροφή εξακολουθούν να προσαρμόζουν το διαθέσιμο ύψος. Ο controller δεν εκτελεί εργασία layout σε κάθε scroll.
- Η ένδειξη της συσκευής γράφει Server S24 Ultra.

Διατηρούνται η αρχική υπογραφή Android, τα υπάρχοντα κλειδιά, το σχήμα βάσης και οι διορθώσεις τιμολογίων της 5.39.0. Το backup πριν από εγκατάσταση εξακολουθεί να είναι υποχρεωτικό. Δεν επαναλαμβάνονται αυτόματα αιτήματα POST/PUT.

Οι δοκιμές περιλαμβάνουν την πραγματική Server UI σε VM, Java OTA policy/HTTP retry, τα πραγματικά Worker API με συνθετικά D1/R2, συνέχιση ουράς μετά από ενημέρωση, πλήρεις παλαιότερους ελέγχους και κατασκευή/υπογραφές APK. Το γρήγορο scrolling σε φυσική συσκευή δεν έχει αναπαραχθεί από τον βοηθό. Δεν έχουν εκτελεστεί εγκατάσταση σε συσκευή, πραγματικό backup ή μαζική ανάγνωση παραγωγικών PDF. Η ακριβής προειδοποίηση Play Protect δεν έχει δοθεί και δεν θεωρείται επιλυμένη.
