# Εγκεκριμένο σχέδιο Fleet — 05/11/2026

Ο χρήστης ζήτησε πριν από την ανάπτυξη αναλυτική περιγραφή και οπτική
προεπισκόπηση κάθε αλλαγής. Εξέτασε την πρόταση και απάντησε «Ξεκίνα».
Οι αναφορές εμφάνισης βρίσκονται στο `docs/ui-proposals/`. Περιέχουν συνθετικά
δεδομένα και τοπικές αλληλεπιδράσεις αποκλειστικά για αναφορά σχεδιασμού.

## Σταθερή πλοήγηση

Προστίθεται μόνο ένα κύριο μενού: **Ταμείο διανομέων**. Διατηρούνται Αρχική,
Βάρδιες, Πρόγραμμα, Εργαζόμενοι, Μηχανάκια, Τιμολόγια, Καταστήματα, Μισθοδοσία,
Αναφορές, Ειδοποιήσεις, Αρχείο ενεργειών, Κάδος, Backup & Server και Ρυθμίσεις.
Η κάτω πλοήγηση του Client παραμένει συμπαγής με πρόσβαση στα υπόλοιπα από το
μενού. Σε μικρή οθόνη οι οικονομικοί πίνακες γίνονται αναγνώσιμες εγγραφές με
ορατά ποσά και ενέργειες. Στον Server διατηρούνται οι τέσσερις καρτέλες
Κατάσταση / Αντίγραφα / Ενημερώσεις / Ρυθμίσεις.

## #59 — κύρια αποθήκευση στον Server

Απογραφή authority ανά υπηρεσία και ελεγμένη ανάκτηση προηγούνται της μεταφοράς.
Σταδιακός έλεγχος δεδομένων/ιστορικού και ατομική μετάβαση ανά ενότητα, με
μοναδικά operation IDs, CAS/versions, δικαιώματα και audit. Login/ανάκληση δεν
εξαρτώνται από D1 μετά από επαληθευμένη μεταφορά authority. Καμία δεύτερη
ανεξέλεγκτη πηγή εγγραφών και καμία διαγραφή παλιού archive.

Κοινή ορατή σύνδεση/χρόνος δεδομένων, επιβεβαίωση πραγματικής αποθήκευσης,
read-only cached προβολή και διατήρηση προσχεδίου όταν ο Server λείπει.
Πραγματική σύγκρουση εμφανίζεται χωρίς αντικατάσταση του προσχεδίου.

## #61 — backup και ανάκτηση

Αξιοποίηση υπάρχοντος backup, έλεγχος κάλυψης όλων των ledgers, προαιρετική
κρυπτογράφηση με φορητό κωδικό ανάκτησης, ρυθμιζόμενη διατήρηση και χωριστές
ενδείξεις ακεραιότητας αρχείου / πραγματικής απομονωμένης ανάκτησης. Φάκελος και
πρόγραμμα διατηρούνται. Η ρύθμιση διατήρησης δεν ενεργοποιεί αυθαίρετη διαγραφή
παλιών αντιγράφων. Εξαιρούνται Ordexa credentials, AndroidKeyStore identities
και ιδιωτικά signing keys. Η παραγωγική επαναφορά παραμένει χωριστή επιλογή.

Νεότερη προτεραιότητα: διόρθωση του backup πριν από OTA, που ο χρήστης αναφέρει
ότι αποτυγχάνει και αργεί. Το checkpoint `0d14a862a3af03c8347f2d4d701d39132702181d`
έχει επιτυχές πλήρες GitHub source CI `42017874019`: ξεχωριστή ουρά επαναλήψεων
και streaming συμπαγές JSON. Το επόμενο βήμα προσθέτει πραγματικό restore probe
και UI. Το πρώτο checkpoint δεν αποτελεί νέα παραγωγική έκδοση.

## #60 — ταμείο διανομέων

Επιβεβαίωση πραγματικών stable order→courier IDs πριν από αυτόματη εισαγωγή.
Αν λείπουν, ελεγχόμενη χειροκίνητη καταχώριση. SQLite ledger στον Server,
χρονική ισχύς κανόνων ανά κατηγορία/κατάστημα, idempotent εισαγωγές, παραλαβές
και αντιλογισμοί με audit. Ανεξάρτητο από μισθοδοσία και χρεώσεις καταστημάτων.

Καρτέλες **Ανά διανομέα / Κινήσεις / Κανόνες απόδοσης**, οφειλή, παραδοθέν ποσό,
υπόλοιπο/διαφορά, breakdown ανά κατάστημα/κατηγορία και Excel/PDF.
Ημέρα ταμείου 05:00–05:00 Europe/Athens, όπως η αποδεκτή πρόταση. Προσθήκη
καρτέλας Ταμείο στην καρτέλα εργαζομένου με διατήρηση των άλλων καρτελών.

## #62 — οικονομικά καταστημάτων

Server-first υπολογισμός από υπάρχοντα ημερήσια αποτελέσματα. Ημέρα, εβδομάδα
Δευτέρα–Κυριακή, μήνας, διάστημα. Στήλες παραγγελίες, χρέωση παραγγελιών,
συμπλήρωμα παγίου και τελικό ποσό, με ίδιους αριθμούς στα Excel/PDF.
0 έγκυρες παραγγελίες → 0 πάγιο. Ημέρα 05:00–05:00 Europe/Athens, ιστορικές
τιμές, explicit aliases και διατήρηση διαγραμμένων παραγγελιών default OFF.
Ορατή κάλυψη/δημοσίευση/ηλικία στοιχείων. Καρτέλες Οικονομικά / Ανά ημέρα /
Χρεώσεις & επιλογές.

## #63 — έλεγχος μισθοδοσίας

Υπάρχων υπολογισμός και πηγή Ordexa διατηρούνται. Queue **Προς έλεγχο** ανά
εβδομάδα, πραγματικές ώρες / πρόγραμμα / πληρωτέο / αιτία. Χωριστές αποφάσεις
ανά εγγραφή με versioned audit: διόρθωση ή Ελέγχθηκε/διατηρείται. Μόνο πραγματικά
blockers εμποδίζουν κλείδωμα, χωρίς μηδενισμό έγκυρης εκτός-προγράμματος παρουσίας.
6€/10€/15€, συμφωνημένη στρογγυλοποίηση, κλειδωμένα ποσά, όριο 02:00 και ειδικές
ώρες στην ημέρα έναρξης διατηρούνται. Συγχρονισμός κάθε 5 λεπτά δεν χάνει drafts.

## #64 — υγεία και ειδοποιήσεις

Αξιοποίηση υπαρχόντων snapshots, χωρίς νέο βαριάς χρήσης polling. Server,
Ordexa, καταστήματα, εκκρεμότητες/outbox, χώρος, backup και δοκιμή ανάκτησης.
D1 quota μόνο από εγκεκριμένη πραγματική μέτρηση, αλλιώς Άγνωστο. Actionable
ειδοποιήσεις συνενωμένες, acknowledgement χωριστό από επίλυση, εξαγωγή διάγνωσης
με allowlist και χωρίς προσωπικά δεδομένα/credentials/raw errors.

## #8 — APK / Play Protect

Σύγκριση διαθέσιμων artifacts, permissions, εξαρτήσεων, συμπεριφοράς και υπογραφών.
Διόρθωση επαληθευμένου προβλήματος ή τεκμηρίωση επίσημης επανεξέτασης όπου
ενδείκνυται. Στις ενημερώσεις πηγή/ακεραιότητα/συμβατή υπογραφή. Δεν εμφανίζεται
δήθεν έγκριση Google και δεν αλλάζουν τα αρχικά signing keys ή η προστασία.
