# Fleet Control — λειτουργία μέσω Direct Android Server

Τρέχουσα υποψήφια έκδοση: Client5.64.0/code108, Server2.13.0/code78, Web5.64.0, Worker5.21.0. Νεότερες ρητές οδηγίες ιδιοκτήτη13/11/2026: μόνο Direct, προσωρινά ανενεργή επιλογή Cloudflare και αποθήκευση στοιχείων στον Server. Η δημοσίευση και οι πραγματικοί έλεγχοι καταγράφονται χωριστά στο CHATGPT_HANDOFF_GR.md.

## Τρέχουσα λειτουργία και δεδομένα

Server, Android Client και Web επιλέγουν Direct στο `https://fleet-control.duckdns.org`. Δεν εμφανίζουν επιλογέα ή κουμπί ανάκτησης Cloudflare. Σε αστοχία παραμένουν στον Server και προσφέρουν επανάληψη σύνδεσης. Η προηγούμενη αποθηκευμένη επιλογή Cloudflare δεν ξεκινά cloud εργασίες στη νέα έκδοση. Μη έτοιμο Direct εμφανίζει προετοιμασία και αποκλείει επιχειρησιακές εγγραφές.

Ο μηχανισμός εναλλαγής, οι αρχικές Cloudflare κλάσεις, τα UI controls και οι ξεχωριστές ρυθμίσεις/SQLite διατηρούνται αδρανή στον πηγαίο κώδικα για μελλοντική εγκεκριμένη ενημέρωση. Δεν διαγράφεται ή απενεργοποιείται ο λογαριασμός Cloudflare. Παλιά APK ή ήδη ανοικτές παλιές καρτέλες χρειάζονται ενημέρωση/ανανέωση για τη νέα συμπεριφορά.

Η αλλαγή πολιτικής δεν μεταφέρει, συγχρονίζει, συμφιλιώνει ή αντικαθιστά επιχειρησιακά δεδομένα. Direct και Cloudflare διατηρούν χωριστές βάσεις, φακέλους, ρυθμίσεις, λογαριασμούς, sessions και Keystore aliases. Η αρχική εισαγωγή backup στο Direct είναι ξεχωριστή ρητή ενέργεια του ιδιοκτήτη.

## Στοιχεία που αποθηκεύονται στο Server

Στην Προετοιμασία Direct συμπληρώνεις μία φορά τον ιδιοκτήτη και κάνεις Έλεγχο σύνδεσης. Μετά επιτυχή πραγματική αυθεντικοποίηση/ρόλο owner, username και password αποθηκεύονται με AES-GCM Android Keystore στη συσκευή. Οι επόμενες ενέργειες επαναχρησιμοποιούν την έγκυρη συνεδρία ή συνδέονται ξανά αυτόματα όταν λήξει. Δεν χρειάζεται επαναλαμβανόμενη συμπλήρωση. Υπάρχει Αλλαγή / διαγραφή αποθηκευμένης σύνδεσης.

Ο σωστός φορητός κωδικός backup αποθηκεύεται προστατευμένος μετά επιτυχή εισαγωγή, ρύθμιση προστασίας ή επαλήθευση backup. Κενό πεδίο χρησιμοποιεί τον αποθηκευμένο κωδικό. Backup με διαφορετικό κωδικό μπορεί να χρειαστεί νέα καταχώριση μία φορά. Η διαγραφή του αποθηκευμένου κωδικού δεν διαγράφει backup ή δεδομένα και δεν καταργεί την κρυπτογράφησή τους. Διατήρησε τον φορητό κωδικό και εκτός της συσκευής για ανάκτηση σε άλλο κινητό.

Το ήδη προστατευμένο DuckDNS token και η αποδοχή όρων πιστοποιητικού επαναχρησιμοποιούνται. Κενό token σημαίνει χρήση αποθηκευμένου. Το Ordexa διατηρεί την υπάρχουσα προστατευμένη αποθήκευση/αυτόματη επανασύνδεση· κενός κωδικός με τον ίδιο αποθηκευμένο λογαριασμό χρησιμοποιεί την υπάρχουσα σύνδεση. Αλλαγή λογαριασμού ή κωδικού απαιτεί τα νέα στοιχεία.

Τα μυστικά δεν εμφανίζονται σε status/logs, δεν αποθηκεύονται plaintext και δεν δίνονται σε Client/Web/Cloudflare. Η αποθήκευση δεν παρακάμπτει τον πραγματικό έλεγχο ρόλων, κρυπτογράφησης backup ή επιβεβαιώσεις ανάκτησης. Οι Clients εξακολουθούν να συνδέονται με τον δικό τους λογαριασμό.

## Πρώτη εγκατάσταση και προετοιμασία

1. Εγκατέστησε το κανονικό αρχικά υπογεγραμμένο Server APK πάνω στο υπάρχον, χωρίς απεγκατάσταση. Ενημέρωσε τον Client και ανανέωσε τις ανοικτές Web καρτέλες. Τα παλιά δεδομένα/πιστοποιητικά διατηρούνται. Η νέα προεπιλογή είναι Direct. Αν το Direct είχε ήδη αρχικοποιηθεί και εγκριθεί, δεν επαναλαμβάνεις την εισαγωγή backup.
2. Άνοιξε Ρυθμίσεις → Direct Android Server → Προετοιμασία Direct / backup / HTTPS. Για νέα αρχικοποίηση επίλεξε τον φάκελο του πλήρους backup και το `.fcbackup`, με τα αντίστοιχα `.fcdb` και `.fcdocs` όταν υπάρχουν αρχεία. Ένα μεμονωμένο `.fcdocs` δεν αρκεί. Συμπλήρωσε τον φορητό κωδικό μία φορά.
3. Συμπλήρωσε τα στοιχεία ιδιοκτήτη από το backup και πάτησε Έλεγχος σύνδεσης. Αποθηκεύονται στη συσκευή. Στο σταθερό `fleet-control.duckdns.org` βάλε το δικό σου DuckDNS token και αποδέξου τους όρους πιστοποιητικού μία φορά. Πάτησε Ρύθμιση HTTPS και έναρξη Server. Χρειάζονται έγκυρο πιστοποιητικό και ενεργός listener8443· DNS update μόνο του δεν αποδεικνύει έτοιμο HTTPS.
4. Στο router δέσμευσε σταθερή DHCP IP για το κινητό Server και όρισε WAN TCP443 → αυτή η IP:8443. Έλεγξε τη σημερινή IP του κινητού, όχι παλιά διεύθυνση. Αν η WAN IPv4 δεν συμφωνεί με τη δημόσια IPv4, χρειάζεται έλεγχος CGNAT/DS-Lite. Για το ίδιο Wi-Fi χρειάζεται NAT loopback ή εσωτερική δρομολόγηση443→8443· split DNS μόνο του δεν μεταφράζει τις θύρες.
5. Από δεύτερο κινητό με κλειστό Wi-Fi και ενεργά δεδομένα άνοιξε `https://fleet-control.duckdns.org/?fleetSetup=1`, συνδέσου ως ιδιοκτήτης και πάτησε Έλεγχος σύνδεσης. Επιτυχής πραγματικός public-peer read/write-rollback έλεγχος, πλήρες ελεγμένο backup, έγκυρο TLS και ενεργός listener ολοκληρώνουν την ετοιμότητα Direct. Δεν υπάρχει μοχλός Cloudflare που πρέπει να πατήσεις εντός δεκαλέπτου. Το εσωτερικό αποδεικτικό ελέγχεται όσο είναι πρόσφατο και η έγκριση αποθηκεύεται ατομικά.
6. Έλεγξε την ένδειξη ετοιμότητας στον Server, σύνδεση Client/Web, Wi-Fi και 4G, μία συνήθη καταχώριση/ανάγνωση, νέο επαληθευμένο backup και επανεκκίνηση. Ρύθμισε Ordexa και τον ξεχωριστό φάκελο backup του Direct. Το Ordexa παραμένει αυστηρά μόνο ανάγνωσης.

Αν η παλιά χωριστή Test εφαρμογή χρησιμοποιεί ήδη την8443 στο ίδιο κινητό, σταμάτησε μόνο τη δοκιμαστική υπηρεσία πριν ξεκινήσεις τον κανονικό Server. Δεν χρειάζεται απεγκατάσταση ή διαγραφή δεδομένων.

## HTTPS και έλεγχοι

Χρησιμοποιείται ACME DNS-01, όχι HTTP-01. Δεν απαιτείται inbound80 ή κανόνας80→8080. Οι έλεγχοι chain/SAN/trust/keypair, πραγματικής κατάστασης listener, persistence και backoff διατηρούνται. Δεν χρησιμοποιείται cleartext fallback, trust-all ή παράκαμψη πιστοποιητικού μέσω IP. Επίσημη αναφορά DNS-01: https://letsencrypt.org/docs/challenge-types/ .

Η αρχική επιλογή Direct δεν εγκρίνει μόνη της επιχειρησιακές εγγραφές. Νέα ή παλιά Cloud επιλογή παραμένει σε προετοιμασία μέχρι το ασφαλές owner/HTTPS/public-peer proof. Προηγουμένως εγκεκριμένο Direct διατηρείται κατά την ενημέρωση. Αποτυχία δικτύου δεν ενεργοποιεί Cloudflare.

## Υλοποίηση και διατήρηση λειτουργιών

Διατηρούνται το κανονικό package/signature, οι τέσσερις καρτέλες, όλα τα native εργαλεία, τα πλήρη FCB3 manual/automatic backups και οι ελεγμένες ανακτήσεις με πριν/μετά backup και διατήρηση παλιών καταλόγων. Τα runtime classes του Direct χρησιμοποιούν `gr.argyrismitsos.fleetdirect`, process`:direct`, ξεχωριστό ScopedContext και pinned SQLite με όλα4ABIs/JSON/WAL/FULL. Η φυσική ιδιωτική IPC authority παραμένει `gr.argyrismitsos.fleetserver.direct-control`· δεν μετονομάζεται μαζί με το Java namespace. Ο compiled έλεγχος και η πραγματική Android δοκιμή ServerBridge ελέγχουν αυτή τη διάκριση.

Η επιλογή πολιτικής και η ετοιμότητα χρησιμοποιούν ατομικό mode file, revision/CAS, fsync και shared OS file locks. Παλιές εργασίες/απαντήσεις ακυρώνονται ή απορρίπτονται. Δεν επαναλαμβάνονται οικονομικά αιτήματα μετά αλλαγή revision ή επανασύνδεση. Τα sessions παραμένουν δεσμευμένα στο σωστό origin/backend.

Το Direct Web έχει service-worker cache μόνο για το στατικό περιβάλλον και επανάληψη σύνδεσης. Δεν αποθηκεύει API απαντήσεις, mode descriptor ή APK και δεν επαναλαμβάνει αποτυχημένες POST. Φρέσκος browser χρειάζεται αρχική πρόσβαση στο Direct URL. Ήδη ανοικτές παλιές καρτέλες χρειάζονται ανανέωση.

Ο Server περιλαμβάνει ολόκληρο το αρχικά υπογεγραμμένο Client και όλες τις απαραίτητες λειτουργίες/βιβλιοθήκες, με επιτρεπόμενο μέγεθος πάνω από50MB και όριο192MiB. Για μεγάλο APK η δημοσίευση χρησιμοποιεί το ήδη υπογεγραμμένο GitHub release: μικρό εξουσιοδοτημένο αίτημα, allowlisted HTTPS redirects χωρίς Fleet credentials, bounded R2 stream και native έλεγχο ολόκληρου SHA-256/μεγέθους. Δεν περιορίζεται το APK στα όρια ενός εισερχόμενου Cloudflare upload. Η ενεργοποίηση Server/Client/Web παραμένει συνολική μετά επαλήθευση όλων των αρχείων.

Η υπηρεσία Direct διατηρεί το δηλωμένο ιδιωτικό FOREGROUND_SERVICE_SPECIAL_USE contract, τις αρχικές υπογραφές/package/permissions, τα παλιά immutable Web snapshots, τον τοπικό κατάλογο Client/Web και την ασφαλή OTA από δημόσιο GitHub με προηγούμενο ελεγμένο backup. Πλήρες source ZIP, build inputs, manifests, hashes και οδηγίες παραδίδονται στο κανονικό GitHub release. Τοπικές disposable υπογραφές δεν παραδίδονται ως ενημέρωση.

Πλήρες exact-source CI, πραγματικό normal-APK Android/API30, browser/visual δοκιμές και original-signing gates απαιτούνται πριν δημοσίευση. Πραγματικό Note10+/backup/CA/Nova/4G/reboot/θερμική δοκιμή παραμένουν χωριστοί έλεγχοι του ιδιοκτήτη· οι συνθετικές δοκιμές δεν υποκαθιστούν αυτές τις επαληθεύσεις.
