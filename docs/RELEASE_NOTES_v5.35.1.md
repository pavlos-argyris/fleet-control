# Fleet Control v5.35.1

## Διόρθωση ενημέρωσης

- Client APK: `5.35.1` με versionCode `40`, ώστε να αναγνωρίζεται ως νεότερο από το `5.35` και να εμφανίζει prompt αυτόματης ενημέρωσης.
- Web: `5.35.1`, με νέο cache key για να φορτώνεται άμεσα η τελευταία έκδοση.
- Η μαζική «Νέα ανάγνωση όλων» ελέγχει όλα τα τιμολόγια με αποθηκευμένο PDF.
- Η πρόοδος εμφανίζεται ζωντανά στο Web και στο APK, μαζί με την καρτέλα «Σε επεξεργασία».

## Επόμενη έκδοση

Η επόμενη λειτουργική αλλαγή θα αριθμηθεί ως `5.36` και θα χρησιμοποιηθεί ταυτόχρονα για Web και Client APK.
