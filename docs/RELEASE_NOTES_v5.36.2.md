# Fleet Control v5.36.2 / Server 2.0.9 / Worker 5.0.37

Η έκδοση προσθέτει υβριδική ανάγνωση τιμολογίων service:

- Τα PDF που δημιουργούνται από QR διαβάζονται πρώτα τοπικά στον Server APK.
- Το Workers AI χρησιμοποιείται αυτόματα μόνο όταν η τοπική ανάγνωση αποτύχει ή δώσει αμφίβολα στοιχεία.
- Η επιλογή «Νέα ανάγνωση όλων» εκτελείται πλέον από τον Server, με κοινή πρόοδο σε όλες τις web/APK συνδέσεις.
- Η καρτέλα «Τιμολόγια» εμφανίζει πάντα επιλογή μεταφοράς σε άλλο μηχανάκι και συγκεκριμένο service. Μεταφέρονται μαζί το PDF, το QR και τα δεδομένα OCR.
- Όταν χρησιμοποιείται fallback, εμφανίζεται προειδοποίηση στην κάρτα τιμολογίου, στην επιβεβαίωση OCR, στο Client APK και στην ειδοποίηση του Server.
- Η τοπική ανάγνωση χρησιμοποιεί πρώτα το ζωντανό κείμενο της δυναμικής σελίδας και μετά το Unicode text layer του PDF (ToUnicode/CMap), καθαρίζει κωδικούς/ποσότητες από τις γραμμές και αποφεύγει διπλές εργασίες.
- Ο Server στέλνει και τα αποτυχημένα/αμφίβολα αποτελέσματα στον Worker ώστε το fallback να ενεργοποιείται και στη μαζική επανεπεξεργασία.

Εκδόσεις:

- Client APK: `5.36.2`, versionCode `43`.
- Server APK: `2.0.9`, versionCode `12`.
- Web: `5.36.2`.
- Cloudflare Worker: `5.0.37`.

Τοπική ανάγνωση υποστηρίζεται για τα PDF που παράγει ο Server από QR. Οι φωτογραφίες παραμένουν στη ροή Workers AI, όπως έχει συμφωνηθεί.
