# Fleet Control v5.36.1

Διορθωτική έκδοση πάνω από την εγκατεστημένη 5.36.

- Client APK: `5.36.1` με versionCode `42`, ώστε το Android να το αναγνωρίζει ως νεότερο από την `5.36`.
- Web: `5.36.1` με νέο cache key και νέα query versions για τα στατικά αρχεία.
- Worker: `5.0.36` με νέα runtime schema version.
- Διορθώθηκε η εμφάνιση `NaN%` όταν παλιό ή προσωρινό δεδομένο προόδου δεν είναι αριθμός.
- Ο κινούμενος zig-zag δακτύλιος προόδου περιορίζεται πλέον στο πραγματικό ποσοστό και δεν βάφει ολόκληρο τον κύκλο πράσινο.
- Η ζωντανή πρόοδος μεμονωμένων QR και μαζικής επανεπεξεργασίας παραμένει κοινή σε όλες τις ανοιχτές συνδέσεις Web/APK.

Δεν απαιτείται νέα έκδοση Server APK. Το υπάρχον production `wrangler.jsonc` πρέπει να διατηρηθεί.
