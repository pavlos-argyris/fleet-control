# Fleet Control 5.49.5 — κοινή ολίσθηση πλοήγησης

Client/Web 5.49.5 (69), Worker 5.10.7. Server 2.2.5 (31), χωρίς αλλαγή APK.

- Ο χρήστης επέλεξε να αντικατασταθεί η ανάπτυξη/συρρίκνωση από την ίδια μικρή ολίσθηση που χρησιμοποιούν Dashboard, Βάρδιες και οι υπόλοιπες κάτω καρτέλες.
- Το άνοιγμα μηχανής χρησιμοποιεί translateX από +22 px προς 0, η επιστροφή από −22 px προς 0. Διάρκεια 190 ms και easing cubic-bezier(.2,.7,.2,1), μέσω της ίδιας FleetMotion.slide συνάρτησης.
- Στο ενσωματωμένο Fleet/Client κινείται το viewport του iframe. Η εξωτερική κάτω μπάρα/κεφαλίδα παραμένει στη θέση της όταν εμφανίζεται. Στο αυτόνομο Fleet κινείται η νέα προβολή.
- Αφαιρούνται ο κώδικας στιγμιοτύπων View Transition, οι προσωρινές πράσινες επιφάνειες και η αλλαγή μεγέθους. Δεν χρησιμοποιείται opacity fade. Διατηρούνται η ταυτότητα καρτών όταν δεν υπάρχουν αλλαγές, οι πραγματικές ενημερώσεις δεδομένων, η θέση λίστας και το Back του Android/browser.
- Η Μείωση κίνησης παραλείπει την ολίσθηση. Γρήγορη επόμενη ενέργεια ακυρώνει την προηγούμενη κίνηση χωρίς δεύτερη εκτέλεση της πλοήγησης. Κάθε animation απομακρύνεται μετά την ολοκλήρωση/ακύρωση.
- Δεν προστίθενται αιτήματα δικτύου ή αλλαγές δεδομένων.

## Έλεγχοι

`bash scripts/check-all.sh`: πραγματικές ενέργειες DOM, σωστή κατεύθυνση/διάρκεια, καμία χρήση screenshot API, επαναφορά/εστίαση, διατήρηση καρτών και ανανέωση όταν αλλάζουν χιλιόμετρα, απουσία animation API, μειωμένη κίνηση, iframe και διακοπή.

Το υποχρεωτικό CI/publish gate εκτελεί Chromium σε Web, Portal, τοπικά αρχεία Client και Μείωση κίνησης. Παγώνει άνοιγμα και επιστροφή στη μέση και ελέγχει την πραγματική ολίσθηση 190 ms, αντίστροφη κατεύθυνση, απουσία scale/resize/clip/fade και screenshot calls, διατήρηση DOM/θέσης, απουσία οριζόντιας υπερχείλισης, επαναλαμβανόμενους κύκλους και browser Back. Μετρά LayoutCount κατά το τελικό μέρος της κίνησης και απαιτεί έως 4 passes. Διατηρεί τους ελέγχους αφής και σταθερής πράσινης ένδειξης της κάτω πλοήγησης.

Τα screenshots/results αποθηκεύονται στο artifact navigation-motion-verification. Οι δοκιμές χρησιμοποιούν συνθετικά δεδομένα και ελέγχουν τον μηχανισμό σε Chromium· η αίσθηση στο φυσικό WebView επιβεβαιώνεται στη συσκευή.

## Εγκατάσταση και ανάκτηση

Client: «Έλεγχος τώρα» και ενημέρωση πάνω στην υπάρχουσα εγκατάσταση. Web: ανανέωση σελίδας. Worker/Web δημοσιεύονται από το εξουσιοδοτημένο workflow. Δεν απαιτείται νέα εγκατάσταση Server. Δεν αλλάζει σχήμα/περιεχόμενο δεδομένων.

Στο GitHub release διατίθενται ο πλήρης πηγαίος όλων των τμημάτων, APK, Web/Worker, build inputs, οδηγίες και checksums. Διατηρούνται οι αρχικές υπογραφές Android. Τα ιδιωτικά κλειδιά παραμένουν εκτός αποθετηρίου. Η δημοσίευση δεν δημιουργεί αυτόματα backup δεδομένων· διατηρείται το συνηθισμένο εξωτερικό backup Server.
