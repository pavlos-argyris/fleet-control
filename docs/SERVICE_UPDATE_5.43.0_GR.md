# Fleet Control 5.43.0

Client/Web 5.43.0 (Android code 57), Server 2.2.0 (code 26), Worker 5.6.0.

## Νέο service

Κράτησε χιλιόμετρα και ημερομηνία. Επίλεξε εργασίες από τις μικρότερες κάρτες
δύο ανά σειρά και πρόσθεσε ελεύθερες εργασίες αν χρειάζεται. Συνεργείο και
κόστος διαβάζονται από το τιμολόγιο. Παλιές καταχωρήσεις διατηρούν τα στοιχεία
τους. Η παλαιότερη ημερομηνία/ένδειξη εξακολουθεί να ζητά επιβεβαίωση όταν
επηρεάζει τα τρέχοντα χιλιόμετρα ή τον κύκλο λαδιών.

«Αποθήκευση & επόμενο» ανοίγει καθαρή νέα καταχώρηση για το ίδιο μηχανάκι.
«Πρότυπα εργασιών» αποθηκεύει μόνο εργασίες, χωρίς ημερομηνία, χιλιόμετρα ή
τιμολόγια. Τα προσχέδια αποθηκεύονται σε αυτή τη συσκευή, ανά λογαριασμό και
μηχανάκι· πάτησε «Ανάκτηση προσχεδίου» πριν συμπληρώσεις ξανά τη φόρμα.
Έως 20 πρότυπα και έως 100 MB επιλεγμένων αρχείων σε ένα προσχέδιο.

Η καταχώρηση κλείνει μετά την τοπική αποθήκευση. Τα επιλεγμένα PDF/QR μένουν
σε αποθηκευμένη ουρά και ανεβαίνουν στο παρασκήνιο, με νέα προσπάθεια όταν
επανέλθει σύνδεση ή ανά λεπτό όσο υπάρχουν εκκρεμότητες. Η εφαρμογή πρέπει
να παραμένει/επανέρχεται ανοιχτή και συνδεδεμένη σε λογαριασμό διαχείρισης.
Μην διαγράψεις δεδομένα εφαρμογής/ιστοτόπου ενώ υπάρχουν τοπικά προσχέδια ή
τιμολόγια που δεν ανέβηκαν. Τα αρχεία έχουν σταθερό κωδικό αποστολής ώστε
επανάληψη μετά από χαμένη απάντηση να μην παράγει δεύτερο αντίγραφο.

## Έλεγχος χιλιομέτρων και απόφαση

Όταν τα χιλιόμετρα διαφέρουν, διάλεξε:

- «Διόρθωση χιλιομέτρων service»: εφαρμόζει την ένδειξη τιμολογίου.
- «Διατήρηση χιλιομέτρων service»: κρατά τη χειροκίνητη ένδειξη και καταγράφει ότι έλεγξες τη διαφορά.

Και οι δύο επιλογές ολοκληρώνουν τον συγκεκριμένο έλεγχο. Άλλη πραγματική
διαφορά, π.χ. ανεπίλυτη πινακίδα ή ασυμφωνία ποσών, εξακολουθεί να επισημαίνεται.
Στο ιστορικό εμφανίζονται service/τιμολόγιο και η αρχική καταγραφή αν διορθώθηκε.
Η ημερομηνία service παραμένει δική σου· η ημερομηνία τιμολογίου εμφανίζεται
ξεχωριστά ακριβώς από κάτω.

«Ιστορικό αποφάσεων»: έως 12 τελευταίες αποφάσεις ανά service και επιπλέον
κεντρικό audit. Αναίρεση μόνο αν το service και τα σχετικά πεδία δεν άλλαξαν
μετά την απόφαση. Μεταφορές τιμολογίων καταγράφονται αλλά δεν αναιρούνται
αυτόματα από αυτό το κουμπί. Μια παλιά επιβεβαίωση δεν καλύπτει διαφορετική
νέα ανάγνωση χιλιομέτρων ή άλλη καταχώρηση.

## Κόστος, πλήρες ιστορικό και αρχεία

Το πλήρες ιστορικό περιέχει σύνολο ανά μηχανάκι, επιλεγμένων και όλου του
ενεργού στόλου στην ίδια περίοδο. Το κόστος είναι τελικό ποσό με ΦΠΑ, σε
ακέραια λεπτά για σωστή άθροιση· πιστωτικά αφαιρούνται. Ίδιο αρχείο με ίδιο
κλειδί μετρά μία φορά. Ελλιπή ποσά και ανεπιβεβαίωτα τιμολόγια επισημαίνονται.
Το 0 είναι κανονικό ποσό και διαφέρει από την απουσία ποσού.

Διάλεξε περίοδο βάσει ημερομηνίας service ή ημερομηνίας τιμολογίου. Σε
περίοδο τιμολογίου αθροίζονται μόνο τα αρχεία που εμπίπτουν στην περίοδο.
Έλεγξε ανεπιβεβαίωτα ποσά πριν χρησιμοποιήσεις το σύνολο. Παλιό χειροκίνητο
κόστος χρησιμοποιείται όταν η καταχώρηση δεν έχει συνημμένα τιμολόγια.

«Λήψη Excel» παράγει πραγματικό XLSX με αριθμητικά ποσά. Στο Android
Client διάλεξε προορισμό αποθήκευσης. Τα πεδία κειμένου εξάγονται ως κείμενο,
ακόμη και αν αρχίζουν με `=`. Η υπάρχουσα εκτύπωση/PDF της αναφοράς παραμένει.

Στον έλεγχο τιμολογίου υπάρχουν καθαρή αξία/ποσό ΦΠΑ και σύγκριση με τελικό
ποσό. Τοπικός αναγνώστης αναζητά μόνο σαφώς επισημασμένα ποσά· δεν μετατρέπει
ποσοστό ΦΠΑ σε ποσό ούτε συμπληρώνει αξίες με εικασία.

Τα κουμπιά PDF αναζητούν πινακίδα, χιλιόμετρα, ποσό ή ημερομηνία στις πρώτες
10 σελίδες και επισημαίνουν πιθανές αντιστοιχίες κειμένου. Η επισήμανση
βοηθά τον οπτικό έλεγχο, δεν αποδεικνύει ότι είναι το σωστό πεδίο. Για εικόνες
μέσα σε σαρωμένο PDF ή μη εντοπισμένο κείμενο χρησιμοποίησε οπτικό έλεγχο.
Υπάρχει αλλαγή σελίδας και το κανονικό Άνοιγμα PDF ως εναλλακτική.

## Συντήρηση και νέα ανάγνωση

«Συντήρηση ανά εργασία» στην καρτέλα μηχανής: τελευταία εργασία βάσει
ημερομηνίας service και προαιρετικά όρια χιλιομέτρων/ημερών. Γράψε 0 για να
μη γίνεται ειδοποίηση. Παλαιό service με περισσότερα χιλιόμετρα δεν
παρουσιάζεται ως πιο πρόσφατη ημερομηνία. Οι υπάρχοντες κύκλοι λαδιών/μεγάλου
service παραμένουν διαθέσιμοι.

Η υποεπιλογή «Νέα ανάλυση από την αρχή» βρίσκεται μέσα στις πρόσθετες
επιλογές της νέας ανάγνωσης. Χρησιμοποίησέ την αν το αποθηκευμένο αποτέλεσμα
είναι λάθος ή άλλαξαν οι κανόνες. Μπορεί να χρειαστεί περισσότερο χρόνο/AI.
Η περιττή «Τελευταία λήψη δεδομένων» αφαιρέθηκε από την κανονική προβολή·
η ένδειξη προσωρινών αποθηκευμένων δεδομένων κατά τη σύνδεση παραμένει.

## Backup πριν και μετά το update

Πάτησε Backup στον Server πριν εγκαταστήσεις. Κατά την επαναφορά εμφανίζεται
προεπισκόπηση 28 πινάκων: προσθήκες, αντίστοιχες εγγραφές που αντικαθίστανται,
πρόσθετες που διατηρούνται. Η προεπισκόπηση δεν αλλάζει εγγραφές. Επιβεβαίωσε
με Admin PIN και νέο έλεγχο ότι τα δεδομένα δεν μεταβλήθηκαν. Η προστασία
προεπισκόπησης λήγει σε 5 λεπτά και ελέγχεται πριν αρχίσει η εισαγωγή cloud.

Το Fleet συγχωνεύεται με τις τρέχουσες εγγραφές. Οι πίνακες προσωπικού
κάνουν upsert: ίδιο κλειδί αντικαθίσταται από backup, πρόσθετο κλειδί
παραμένει. Audit/pay-rule versions είναι append-only. Αυτό δεν είναι πλήρης
επιστροφή κάθε εγγραφής σε παλαιότερη χρονική στιγμή.

Πριν μεταβληθούν τοπικά δεδομένα δημιουργείται αντίγραφο προ επαναφοράς.
Χρειάζεται και το συνοδευτικό αρχείο τιμολογίων για τα PDF. Η επαναφορά
τοπικού Server, cloud και αρχείων εκτελείται σε στάδια, όχι σε μία ενιαία
συναλλαγή. Αν αποτύχει στάδιο, κράτησε τα αντίγραφα και έλεγξε το μήνυμα
αποτελέσματος πριν επαναλάβεις. Ο πηγαίος κώδικας δεν είναι backup δεδομένων.

## Εγκατάσταση και ανεξάρτητη ανάπτυξη

Μετά την επιτυχή δημοσίευση: «Έλεγχος τώρα» για OTA στον Server και στον
Client, εγκατάσταση και επιβεβαίωση Android. Web/Worker δημοσιεύονται από
το GitHub workflow. Διατηρείται η αρχική υπογραφή των APK για συμβατό update.

Το ιδιωτικό GitHub περιλαμβάνει όλα τα μέρη, source ZIP, δύο APK, Web ZIP,
Worker ZIP, build inputs, manifest και SHA256SUMS. Τα ιδιωτικά κλειδιά
παραμένουν στα configured GitHub Secrets και στο αρχικό ιδιωτικό αντίγραφο.
Οι αλλαγές παραδίδονται με συνδέσμους GitHub.

Πλήρες checkout: `npm ci` στο `cloudflare-worker`,
`python3 scripts/prepare-pdf-viewer.py`, `bash scripts/check-all.sh`,
`bash scripts/unpack-toolchain.sh`, ρύθμιση ιδιωτικής υπογραφής/Server key
σύμφωνα με τις υπάρχουσες οδηγίες και `bash scripts/build-android.sh all`.
Το PDF.js 6.4.299 είναι pinned σε lockfile και επαληθευμένο vendor ZIP·
περιλαμβάνονται modules, cmaps, fonts, wasm και άδεια Mozilla.

Οι έλεγχοι χρησιμοποιούν συνθετικά δεδομένα/DOM/JVM και πραγματική ανάλυση
δοκιμαστικού PDF. Δεν εκτελείται restore παραγωγής για δοκιμή. Δεν έγινε
δοκιμή εγκατάστασης ή κύλισης σε πραγματικό S24 Ultra/Android συσκευή.
