# Fleet Control v5.29 / Server 2.0.6

## Τι διορθώνει

- Το QR URL αποθηκεύεται στο service αμέσως μόλις σταλεί στον Server για δημιουργία PDF. Δεν χάνεται πλέον όταν η δημιουργία του PDF καθυστερήσει.
- Στο Android Client τα κουμπιά `Άνοιγμα PDF`, `Λήψη PDF` και `Εκτύπωση / PDF` χρησιμοποιούν native Android λειτουργίες. Η εκτύπωση ανοίγει το Android Print Preview.
- Το ιστορικό εμφανίζει τον προμηθευτή που αναγνωρίστηκε από το τιμολόγιο. Το χειροκίνητο συνεργείο παραμένει εφεδρική τιμή όταν δεν υπάρχει προμηθευτής.
- Η κατάσταση στόλου ταξινομεί τα μηχανάκια με βάση τα χιλιόμετρα μέχρι το επόμενο service, με το πιο κοντινό πρώτο και τα εκπρόθεσμα στην κορυφή.
- Προστέθηκε ειδοποίηση για μηχανάκια χωρίς έλεγχο χιλιομέτρων για τουλάχιστον 7 ημέρες. Η ειδοποίηση εμφανίζεται στο Fleet, δημιουργείται στον Worker και μπορεί να σταλεί ως push μέσω του υπάρχοντος μηχανισμού ειδοποιήσεων.

## Συμβατότητα

- Client APK: `5.29`, versionCode `33`.
- Server APK: παραμένει `2.0.6`· δεν χρειάζεται νέα εγκατάσταση Server για αυτές τις αλλαγές.
- Το QR/PDF server-side flow, το OCR, το R2, το offline/sync και το Back του ιστορικού παραμένουν ενεργά.
