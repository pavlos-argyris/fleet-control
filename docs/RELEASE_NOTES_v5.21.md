# Fleet Control 5.21

Η έκδοση 5.21 ολοκληρώνει τη ρυθμιζόμενη μισθοδοσία και την έγκριση υπερωριών.

## Νέες δυνατότητες

- Ρυθμιζόμενες ωριαίες ζώνες από το **Μισθοδοσία → Κανόνες πληρωμής**, χωρίς επεξεργασία JSON. Κάθε ζώνη έχει περιγραφή, έναρξη, λήξη, €/ώρα, προτεραιότητα και τρόπο εφαρμογής.
- Ο βασικός κανόνας προεπιλέγεται με €6/ώρα, €10/ώρα για 00:00–01:00 και €15/ώρα για 01:00–02:00. Οι υπάρχοντες προσαρμοσμένοι κανόνες δεν αντικαθίστανται.
- Ρύθμιση ανοχής καθυστερημένου Clock In. Μετά την ανοχή εφαρμόζεται η επιλεγμένη στρογγυλοποίηση έναρξης, π.χ. 15:20 → 15:30 όταν έχει επιλεγεί «Προς τα πάνω» και βήμα 30 λεπτών.
- Η υπέρβαση της προγραμματισμένης λήξης μένει **προς έγκριση** και δεν πληρώνεται μέχρι να εγκριθεί.
- Η έγκριση υπερωρίας ζητά προαιρετική ειδική τιμή €/ώρα, καταγράφει ποιος ενέκρινε και πότε, επανυπολογίζει άμεσα τη μισθοδοσία και διατηρεί το audit trail.
- Οι ειδοποιήσεις «Υπερωρία» και «Ξεχασμένο Clock Out» οδηγούν στη συγκεκριμένη λίστα βαρδιών αντί να κλείνουν κατά λάθος χωρίς έγκριση.
- Η κάλυψη προσωπικού ξεχωρίζει τα μελλοντικά προγραμματισμένα μισάωρα από τα πραγματικά κενά. Τα μελλοντικά μισάωρα δεν υπολογίζονται ως κενά πριν ολοκληρωθεί το διάστημά τους.

## Ασφάλεια και συμβατότητα

- Οι νέες στήλες προστίθενται με additive migration και δεν διαγράφονται υπάρχοντα δεδομένα.
- Οι προηγούμενες εκδόσεις κανόνων και οι εγκεκριμένες υπερωρίες παραμένουν στο ιστορικό και στο backup.
- Web assets: έκδοση 5.21.
- Cloudflare Worker runtime/schema: 5.0.21.
- Android Client: `Fleet_Control_Client_v5.21.apk`, versionCode 26.

## Εγκατάσταση

1. Ανέβασε πρώτα τα Web assets του `Fleet_Control_Web_Update_v5.21.zip` στον φάκελο `public` του υπάρχοντος Worker.
2. Αντέγραψε τα αρχεία `src/workforce.js`, `src/workforce-core.js`, `src/worker.js` και το `package.json` στον υπάρχοντα φάκελο `cloudflare-worker`, χωρίς να αντικαταστήσεις το πραγματικό `wrangler.jsonc`.
3. Από τον φάκελο Worker εκτέλεσε `npm install` και `npm run deploy`.
4. Στο **Server → Ενημερώσεις** ανέβασε το `Fleet_Control_Client_v5.21.apk` ως ενεργό Client release.

Η πρώτη κλήση του νέου Worker ολοκληρώνει αυτόματα τις additive στήλες της βάσης. Δεν απαιτείται reset ή διαγραφή βάσης.
