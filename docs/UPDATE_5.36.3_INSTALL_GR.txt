FLEET CONTROL — ΔΙΟΡΘΩΣΗ ΚΟΙΝΗΣ ΠΡΟΟΔΟΥ ΤΙΜΟΛΟΓΙΩΝ 5.36.3

1. Client APK

Εγκατάστησε πάνω από την υπάρχουσα εφαρμογή:
`Fleet_Control_Client_v5.36.3.apk`

Έχει versionCode `44`, επομένως αναγνωρίζεται ως νεότερη από την 5.36.2. Δεν χρειάζεται απεγκατάσταση.

2. Web / Worker

Κράτησε το υπάρχον production `wrangler.jsonc`, το πραγματικό D1 ID και όλα τα bindings.
Ανέβασε από την επιλογή «Ενημερώσεις» του Server APK το:
`Fleet_Control_Web_Worker_Update_v5.36.3.zip`

Εναλλακτικά, κάνε deploy μόνο τα περιεχόμενα του:
`Fleet_Control_Web_Assets_v5.36.3.zip`

Ο Worker runtime είναι `5.0.38`. Η επανάληψη QR ξεκινά πλέον νέο χρονόμετρο και δεν χρησιμοποιεί την αρχική ημερομηνία του παλιού job. Δεν χρειάζεται αλλαγή βάσης ή R2.

3. Έλεγχος

Άνοιξε την καρτέλα «Τιμολόγια» και πάτησε «Νέα ανάγνωση όλων». Στην αρχή πρέπει να εμφανίζεται:
`0/7 · Προετοιμασία…`

Ο κύκλος πρέπει να δείχνει αριθμητικό ποσοστό (π.χ. `0%`) και να ενημερώνεται χωρίς `NaN%`. Η ίδια πρόοδος πρέπει να εμφανίζεται σε όλες τις συνδέσεις.

Ο νέος κύκλος είναι κυματιστός/κινούμενος και λειτουργεί με Canvas τόσο στο Web όσο και μέσα στο APK. Δεν χρειάζεται πρόσθετη ρύθμιση ή αλλαγή του Server APK.
