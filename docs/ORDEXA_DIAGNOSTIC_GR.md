# Fleet · Έλεγχος Ordexa0.1.0 — χειροκίνητο διαγνωστικό

Χωριστή δοκιμαστική εφαρμογή για να πάρουμε πραγματικό αποπροσωποποιημένο
δείγμα API από την εξουσιοδοτημένη σύνδεσή σου, χωρίς να περιμένουμε επίσημη
τεκμηρίωση. Το δείγμα θα αξιολογηθεί· δεν αποδεικνύει αυτόματα σημασία χρόνων,
καταστάσεων/ακυρώσεων ή πλήρη συγχρονισμό και δεν ενεργοποιεί χρεώσεις.

## Στο κινητό

1. Από το artifact **ordexa-manual-diagnostic** του ελεγμένου PR κατέβασε το
   `Fleet_Ordexa_Diagnostic_v0.1.0.apk`. Το ZIP περιέχει SHA256SUMS/signature και
   SOURCE_COMMIT. Πρόκειται για APK με χωριστή δοκιμαστική υπογραφή.
2. Εγκατάστησε το «Fleet · Έλεγχος Ordexa». Έχει διαφορετικό package/UID από
   Server και Client και δεν τα αντικαθιστά ή διαβάζει τις αποθήκες τους.
   Η τελική εγκατάσταση/Play Protect ελέγχονται από Android· δεν παρακάμπτονται.
3. Σύνδεση Ordexa μέσα στο εργαλείο, επιλογή πόλης και ημέρας, «Λήψη δείγματος».
4. «Αντιγραφή αποτελέσματος» και επικόλληση στη συνομιλία. Μην στείλεις κωδικό,
   token ή ανεπεξέργαστη απάντηση παραγγελιών. Το κουμπί αντιγράφει μόνο το
   αποπροσωποποιημένο report που φαίνεται στην εφαρμογή.

Η συνεδρία/φόρμα καθαρίζονται αν φύγεις από την εφαρμογή ή πατήσεις αποσύνδεση.
Τα πεδία δεν αποθηκεύονται σε state/preferences/αρχεία και η οθόνη έχει
FLAG_SECURE. Η αποπροσωποποιημένη αντιγραφή στο clipboard είναι ρητή ενέργεια
του χρήστη. Σε αλλαγή προσανατολισμού μπορεί να χρειαστεί νέα σύνδεση.

## Τι ακριβώς διαβάζει

Χρησιμοποιεί τις ίδιες production κλάσεις OrdexaClient/HttpsTransport,
StoreBillingProtocol και StoreBillingEngine, χωρίς δεύτερη υλοποίηση δικτύου.
Μόνο η υπάρχουσα auth POST /api/login και οι allowlisted GET cities/orders.
Δεν διαθέτει αυθαίρετη URL, remote update, WebView, Fleet/Cloudflare σύνδεση,
τοπική επιχειρησιακή βάση, service, polling ή οικονομική εγγραφή.

Μετά τη ρητή σύνδεση διαβάζει τον κατάλογο πόλεων. Κάθε ρητό δείγμα ζητά την
πρώτη σελίδα δύο φορές και τη δεύτερη μόνο αν το αριθμητικό pages δείχνει ότι
υπάρχει. Δεν σαρώνει ολόκληρη ημέρα και δεν κάνει retry μετά από HTTP error.
Επιτρέπει μόνο πόλη του τρέχοντος λογαριασμού και από/έως με διαφορά έως1ημέρα.
Οι επιλεγμένες ημερομηνίες είναι query evidence, όχι επιβεβαιωμένη ερμηνεία
του business day του παρόχου. Οι πραγματικές ώρες παραγγελιών δεν εξάγονται.

Έως3 bounded observations: πραγματικά HTTP status/media/bytes/duration,
envelope/pagination, έως2 sampled rows/24 fields ανά απάντηση, μόνο field
types και process/session/scope HMAC proof tags αντί scalar values.
Ανακατασκευάζεται η ήδη ελεγμένη allowlist πριν από αντιγραφή. Δεν εξάγονται
ονόματα, πραγματικά IDs, status values, ακριβείς ώρες, credentials ή headers.
Το report είναι έως64KiB και πάντα automaticWritesEnabled/semanticsVerified/
coverageVerified/completeSnapshot=false. Άγνωστο envelope αναφέρεται χωρίς
εικασία πεδίων. Αν λείπουν πεδία στο περιορισμένο sample δεν αποδεικνύεται ότι
ο πάροχος δεν τα διαθέτει· μπορεί να χρειαστεί συμπληρωματικός έλεγχος.

## Κατασκευή και όρια απόδειξης

`bash scripts/unpack-toolchain.sh`, `node scripts/test-ordexa-diagnostic-native.mjs`,
`bash scripts/build-ordexa-diagnostic.sh`. Καμία production secret/signing path.
Η χωριστή προσωρινή test υπογραφή δεν είναι η αρχική υπογραφή Fleet. Το εργαλείο
προορίζεται για την παρούσα χειροκίνητη λήψη, όχι ως κανάλι ενημερώσεων.
Το full source ZIP περιλαμβάνει και αυτό το component. Client5.61.0(100),
Server2.10.13(67), Worker5.18.8 δεν αλλάζουν από την προσθήκη του εργαλείου.

Τα JVM tests χρησιμοποιούν συνθετικό URL transport με την πραγματική HTTPS
κλάση, όχι πραγματική Ordexa συνεδρία. Το APK ελέγχεται ως compiled manifest,
υπογραφή και ZIP, όχι ως εκτελεσμένη φυσική Android εφαρμογή. Η συσκευή,
πραγματική πρόσβαση API και η επάρκεια του δείγματος παραμένουν προς έλεγχο.
