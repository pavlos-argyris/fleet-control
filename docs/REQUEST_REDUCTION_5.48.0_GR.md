# Fleet Control 5.48.0 — λιγότερα αιτήματα

Client/Web 5.48.0 (62), Server 2.2.4 (30), Worker 5.10.0.

## Αλλαγές

- Η κατάσταση Server ελέγχεται ανά 5 λεπτά στα υπόλοιπα ορατά μενού και ανά λεπτό στην καρτέλα Server. Τα σφάλματα δεν ενεργοποιούν συνεχείς νέους ελέγχους κάθε τοπικό tick.
- Οι ανοιχτές Web/Client εφαρμογές λαμβάνουν σήματα αλλαγής μέσω WebSocket/Durable Object με hibernation. Τα σήματα περιέχουν μόνο κατηγορίες αλλαγών, χωρίς εγγραφές, ονόματα ή τιμολόγια. Τα δεδομένα διαβάζονται από τα κανονικά API με έλεγχο δικαιωμάτων.
- Μία ορατή καρτέλα αναλαμβάνει τη σύνδεση όταν υποστηρίζονται Web Locks/BroadcastChannel. Άλλες καρτέλες και iframe της ίδιας συνεδρίας μοιράζονται τα σήματα. Κρυφή καρτέλα παραχωρεί τη σύνδεση. Αδράνεια δικτύου, λήξη σύνδεσης και αλλαγή λογαριασμού καλύπτονται με επανασύνδεση και εφεδρικούς ελέγχους. Δεν προστίθεται push στο κλειστό Android app· οι υπάρχουσες ειδοποιήσεις παρασκηνίου παραμένουν.
- Με ενεργό κανάλι οι περιοδικές αναγνώσεις στόλου/τιμολογίων αραιώνουν στα 5 λεπτά. Χωρίς κανάλι ισχύουν οι εφεδρικοί χρόνοι της 5.47.0. Νέες εγγραφές του χρήστη συγχρονίζονται άμεσα. Ειδοποιήσεις δεν ανοίγουν μενού ή αλλάζουν προσχέδιο που επεξεργάζεται ο χρήστης.
- Επιλεγμένες επιτυχείς JSON αναγνώσεις μοιράζονται cache έως 15 δευτερολέπτων, με ξεχωριστό όριο για status. Η ταυτότητα περιλαμβάνει χρήστη, δικαιώματα και SHA-256 της συνεδρίας. Δεν αποθηκεύεται το bearer token από αυτή την cache. Με αλλαγή δεδομένων ακυρώνεται η cache. Αποσύνδεση την καθαρίζει και αποκλείει καθυστερημένες απαντήσεις από επαναφορά παλιών δεδομένων. Αποτυχίες, auth, μισθοδοσία και μεταβολές δεν μπαίνουν σε shared cache.
- Οι αποθηκευμένες προβολές δεν διαγράφουν πλέον τα πρόσφατα PDF μετά από κάθε άσχετη μεταβολή. Η αποσύνδεση καθαρίζει και τα PDF.
- Τα δημόσια JS/CSS έχουν διαδρομή `assets/v5.48.0/...` και εξυπηρετούνται χωρίς εκτέλεση Worker, όπως τα δημόσια vendor αρχεία. Η εφαρμογή διατηρεί παλιότερα snapshots σε μελλοντικά updates. Οι προστατευμένες σελίδες και όλα τα API συνεχίζουν να περνούν από τον Worker. Ανύπαρκτο static αρχείο επιστρέφει 404, χωρίς SPA παράκαμψη της σύνδεσης.
- Η υπάρχουσα ανταλλαγή Server μεταφέρει δείκτη έκδοσης κανόνων και δείκτη αλλαγών αντιγράφου προσωπικού. Ο περιοδικός κύκλος παραλείπει λήψεις όταν είναι ήδη ενημερωμένα. Άγνωστος δείκτης, αναβάθμιση από παλιό Worker, χειροκίνητη επαλήθευση και backup κρατούν την ασφαλή διαδρομή λήψης. Το αντίγραφο επαληθεύεται και ανά ώρα ως εφεδρεία.

## Εγκατάσταση

1. Πάρε backup από τον Server και κράτησε αντίγραφο εκτός εφαρμογής πριν από εγκατάσταση APK. Η δημοσίευση δεν παίρνει από μόνη της backup παραγωγικών δεδομένων.
2. Το workflow αναβαθμίζει Worker/Web και διαθέτει Server 2.2.4 και Client 5.48.0 μέσω OTA. Εγκατάσταση πάνω στις υπάρχουσες εφαρμογές, χωρίς απεγκατάσταση.
3. Τα WebSocket σήματα είναι βελτίωση διανομής· τυχόν αδυναμία σύνδεσης διατηρεί την εφεδρική HTTP διαδρομή. Παλιότεροι Clients/Server συνεχίζουν τα παλιά API.
4. Η πρώτη ενεργοποίηση δημιουργεί SQLite-backed Durable Object namespace `FLEET_EVENTS` με migration `fleet-events-v1`. Δεν μεταφέρει τη βάση D1 και δεν διαγράφει παραγωγικά δεδομένα.

## Ανεξαρτησία και μετρήσεις

Η απευθείας πρόσβαση στο S24, η αντιμετώπιση CGNAT, τα tunnels προς το κινητό και το VPS αναβάλλονται σύμφωνα με την τελευταία οδηγία χρήστη. Αυτή η έκδοση διατηρεί το Cloudflare backend και προσθέτει Cloudflare Durable Objects για τα σήματα.

Η μείωση από έλεγχο status 30 δευτερολέπτων σε 5 λεπτά είναι 90% μόνο για αυτόν τον έλεγχο, σε μενού εκτός Server. Δεν αποτελεί μέτρηση συνολικής παραγωγικής κατανάλωσης. WebSocket συνδέσεις/μηνύματα/alarms έχουν ξεχωριστή μέτρηση στα Durable Objects. Τα static requests εξακολουθούν να υπάρχουν στο δίκτυο, αλλά οι αντίστοιχες διαδρομές παρακάμπτουν τον Worker.

## Έλεγχοι και ανάκτηση

- Πλήρης σουίτα `bash scripts/check-all.sh`, με πραγματικό τοπικό Workers/D1 και Durable Objects WebSocket, HMAC tickets, scoped signals, έλεγχο πρόσβασης και υπάρχοντα σενάρια service/μισθοδοσίας/backup.
- `test-shared-requests.mjs`: δύο browser contexts, μία κλειδωμένη ανάγνωση, TTL, ακύρωση, απομόνωση χρήστη/δικαιωμάτων/συνεδρίας, αποτυχίες και καθυστερημένη απάντηση μετά την αποσύνδεση.
- `test-live-changes.mjs`: μία εκλεγμένη σύνδεση, κοινά σήματα, συνένωση αλλαγών, μεταβίβαση όταν κρύβεται η καρτέλα και καθαρισμός στην αποσύνδεση.
- `test-static-routing.mjs`: πραγματικό Wrangler local routing, παράκαμψη Worker για JS, 404 για ανύπαρκτα assets και διατήρηση σύνδεσης για Fleet HTML. Εκτελείται ως υποχρεωτικό CI gate· το τοπικό sandbox δεν επιτρέπει την απαρίθμηση network interfaces που κάνει το Wrangler dev.
- Java δοκιμές πολιτικής αντιγράφων/κανόνων, υφιστάμενων OCR/HTTP/OTA/backup και κατασκευή υπογεγραμμένων APK με το αρχικό πιστοποιητικό.

Η συμπεριφορά 5G/Samsung, οι πραγματικοί χρόνοι επανασύνδεσης και η εγκατάσταση στη φυσική συσκευή επιβεβαιώνονται στη συσκευή. Πλήρης πηγή, snapshots assets, build inputs, οδηγοί και αρχεία έκδοσης στο GitHub/source ZIP. Ιδιωτικά signing/Server/Cloudflare secrets εξαιρούνται από Git και logs. Η επαναφορά δεδομένων παραμένει η υπάρχουσα διαδικασία backup/προεπισκόπησης με τους καταγεγραμμένους περιορισμούς της.
