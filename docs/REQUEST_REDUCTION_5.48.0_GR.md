# Fleet Control 5.48.0 — εγκεκριμένη εργασία

- Έλεγχος κατάστασης ανά 5 λεπτά στα υπόλοιπα μενού και συχνότερα στην καρτέλα Server.
- Αυθεντικοποιημένο κανάλι ειδοποιήσεων αλλαγών για ανοιχτές Web/Client εφαρμογές, με επανασύνδεση και εφεδρικούς ελέγχους. Μόνο σήματα αλλαγής, χωρίς προσωπικά δεδομένα στο κανάλι. Κανονικά API για δικαιώματα και δεδομένα.
- Δημόσια JS/CSS σε αμετάβλητες διευθύνσεις ανά έκδοση που εξυπηρετούνται από Static Assets χωρίς Worker. Διατήρηση προηγούμενων εκδόσεων για ασφαλή μετάβαση OTA.
- Τοπική cache αναγνώσεων ανά λογαριασμό, δικαιώματα και συνεδρία, συντονισμός καρτελών/iframe και ακύρωση cache μετά από αλλαγή.
- Δείκτες αλλαγών κανόνων τιμολογίων και αντιγράφου προσωπικού στην υπάρχουσα ανταλλαγή Server. Παράλειψη ξεχωριστής λήψης όταν δεν έχουν αλλάξει.

Η απευθείας πρόσβαση στο S24, το CGNAT, τα tunnels προς το κινητό και το VPS αναβάλλονται, σύμφωνα με την τελευταία οδηγία χρήστη. Η τρέχουσα εργασία διατηρεί το υπάρχον Cloudflare backend.

Κατάσταση: υπό υλοποίηση. Θα συμπληρωθούν τελικές εκδόσεις, έλεγχοι και οδηγίες πριν τη δημοσίευση. Πλήρης πηγή και πακέτα στο GitHub, χωρίς διαπιστευτήρια.
