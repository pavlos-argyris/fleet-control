# Για το επόμενο service · 5.50.1

- Client/Web 5.50.1 (Client versionCode 71).
- Server 2.2.7 (versionCode 33), Worker 5.11.1.

## Χρήση

Στο «Νέο σέρβις», αμέσως κάτω από τις «Άλλες εργασίες», υπάρχει πλαίσιο
«Για το επόμενο service». Γράψε πιθανές επόμενες εργασίες, μία ανά γραμμή.
Αποθηκεύονται μαζί με την καταχώρηση. Δεν θεωρούνται εργασίες που έγιναν τώρα.

Στο ίδιο πλαίσιο εμφανίζονται οι εκκρεμείς σημειώσεις αυτής της μηχανής.
Επίλεξε «Έγινε σε αυτό το service» μόνο για όσες εκτελέστηκαν: το κείμενό τους
προστίθεται στις εργασίες του πραγματικού service και οι σημειώσεις ολοκληρώνονται.
Οι υπόλοιπες παραμένουν εκκρεμείς. Δεν ολοκληρώνονται αυτόματα με την αποθήκευση,
με την ανάλυση PDF ή με την εισαγωγή παλιού service. Ο κύκλος λαδιών συνεχίζει
να εξαρτάται αποκλειστικά από τη ρητή επιλογή «Αλλαγή λαδιών».

Στην καρτέλα κάθε μηχανής υπάρχει η ίδια λίστα πριν από το ιστορικό, με δυνατότητα
προσθήκης σημειώσεων χωρίς καταχώρηση service. Η «Αφαίρεση» κρατά την εγγραφή στις
«Ολοκληρωμένες / αφαιρεμένες σημειώσεις», από όπου η «Επαναφορά» την επαναφέρει στις
εκκρεμείς. Εμφανίζονται οι 20 πιο πρόσφατες παλιές σημειώσεις· όλα τα στοιχεία
διατηρούνται στον συγχρονισμό και στο backup. Δεν αλλάζουν χιλιόμετρα, ημερομηνίες,
ραντεβού, κόστος ή μετρητές συντήρησης. Οι αλλαγές απαιτούν διαχείριση στόλου.

Τα προσχέδια κρατούν τις νέες σημειώσεις και τις επιλεγμένες ολοκληρώσεις.
Τα πρότυπα εργασιών δεν αντιγράφουν υπενθυμίσεις άλλης μηχανής. Η προσθήκη από την
καρτέλα αποθηκεύεται με το κουμπί «Προσθήκη στη λίστα». Η πληκτρολόγηση δεν σβήνεται
από ανανέωση δεδομένων στην ίδια μηχανή· άλλαξε μηχανή αφού πρώτα αποθηκεύσεις.
Μέχρι 20 νέες γραμμές ανά προσθήκη, 240 χαρακτήρες ανά γραμμή, 50 εκκρεμείς και
500 συνολικές σημειώσεις ανά μηχανή. Η εφαρμογή ενημερώνει πριν ξεπεραστεί όριο.

## Αποθήκευση και συμβατότητα

Το `nextServiceNotes` είναι προσθετικό πεδίο της μηχανής. Κάθε σημείωση έχει
δικό της UUID, κατάσταση, χρόνους δημιουργίας/ενημέρωσης και συνδέσεις με την
καταχώρηση προέλευσης ή ολοκλήρωσης. Η συγχώνευση γίνεται ανά σημείωση σε Web,
Worker και Server. Οι ολοκληρωμένες/αφαιρεμένες εγγραφές διατηρούνται ώστε παλιό
αντίγραφο να μην τις αναστήσει. Σε ίδιους χρόνους υπερισχύει η πιο προχωρημένη
κατάσταση και υπάρχει σταθερή επίλυση ισοπαλίας. Δεν προστίθενται περιοδικά αιτήματα
ούτε πίνακες βάσης: χρησιμοποιείται ο υφιστάμενος συγχρονισμός ανά μηχανή και το
πλήρες/διαφορικό αντίγραφο Server. Παλιός Client που παραλείπει το πεδίο δεν το σβήνει.

## Ενημέρωση και ανάκτηση

1. Κράτησε κανονικό πλήρες backup δεδομένων από τον Server πριν από ενημέρωση.
2. Εγκατάστησε Server 2.2.7 και Client 5.50.1 πάνω από τις υπάρχουσες εφαρμογές,
   με τις ίδιες υπογραφές, χωρίς απεγκατάσταση. Ο νέος Server συγχωνεύει τις σημειώσεις
   ανά εγγραφή και εντοπίζει σημειώσεις τοπικής ανάκτησης ακόμη κι αν άλλαξε το ιστορικό.
3. Web και Worker ενεργοποιούνται από τη διαδικασία δημοσίευσης. Κλείσε και ξανάνοιξε
   την καρτέλα για να φορτωθεί η νέα έκδοση.
4. Δοκίμασε μία σημείωση σε μία μηχανή και δες τη στο «Νέο σέρβις» της ίδιας μηχανής.

Το ZIP πηγαίου κώδικα περιλαμβάνει όλα τα τμήματα, scripts, lockfiles και οδηγίες.
Τα build inputs και τα checksums διατίθενται στο ίδιο GitHub Release.
Ιδιωτικά κλειδιά και πραγματικά δεδομένα δεν περιλαμβάνονται. Ο κώδικας δεν είναι
backup δεδομένων. Η επαναφορά χρειάζεται έγκυρο backup και PIN και πρέπει να
προηγείται η προεπισκόπηση. Δεν απαιτείται επαναφορά για τη νέα λειτουργία.

## Έλεγχοι

- Πραγματικό μοντέλο Worker: συγχώνευση, παλιός Client, ολοκλήρωση, επαναφορά,
  αποφυγή διπλοτύπων, όρια και αμετάβλητοι μετρητές.
- Πραγματική φόρμα DOM: προσχέδιο, παλιό service, διατήρηση μη επιλεγμένων,
  απομόνωση μηχανών, αφαίρεση/επαναφορά και αποτυχία τοπικής αποθήκευσης.
- Worker με SQLite/R2 προσομοίωση: πραγματικά API συγχρονισμού, system export,
  preview/import backup και διατήρηση καταστάσεων. Μόνο συνθετικά δεδομένα.
- Native Java: συγχώνευση Server και πολιτική αποστολής τοπικών σημειώσεων.
- Chromium σε Web και file:// Client: πραγματική διεπαφή, καταχώρηση service,
  εμφάνιση επόμενων εργασιών και διάταξη 390 px. Εικόνες στο CI artifact.
- Οι προηγούμενοι έλεγχοι πλοήγησης και κύλισης παραμένουν ενεργοί.

Δεν έχει γίνει δοκιμή σε φυσικό τηλέφωνο ούτε έχει ληφθεί παραγωγικό backup από
αυτή τη διαδικασία. Τα αποτελέσματα CI και τα APK δημοσιεύονται από το workflow.

## Διανομή

Η 5.50.0 αποθηκεύτηκε στο GitHub, αλλά η ενεργοποίηση έληξε με timeout.
Η 5.50.1 είναι η έκδοση εγκατάστασης αυτής της λειτουργίας. Τα μεγάλα APK
μεταφέρονται διαδοχικά και τα Web αρχεία με έως τρεις παράλληλες αποστολές.
Ο έλεγχος αντικειμένων πριν από την ατομική ενεργοποίηση ελέγχει κάθε αρχείο
σε ομάδες τεσσάρων, με τους ίδιους ελέγχους SHA-256/μεγέθους. Οι αποτυχίες
σταματούν νέες μεταφορές και εμποδίζουν την ενεργοποίηση. Τα logs αναφέρουν
πρόοδο και ακριβή διαδρομή σε timeout χωρίς διαπιστευτήρια.

Η πραγματική δοκιμή Client επαναλαμβάνεται σε τρία ανεξάρτητα περιβάλλοντα,
με την κανονική επιβεβαίωση `saved: true` του API και υποστήριξη του παραθύρου
προεπισκόπησης. Αποθηκεύεται διαγνωστικό στιγμιότυπο αν η φόρμα δεν ολοκληρωθεί.
