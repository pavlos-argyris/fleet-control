FLEET CONTROL 5.20 — ΟΔΗΓΙΕΣ ΕΓΚΑΤΑΣΤΑΣΗΣ

Περιλαμβάνονται:
- εσωτερικός έλεγχος και ασφαλής εγκατάσταση νέου Client APK,
- εφαρμογή της μόνιμης μηχανής ως προεπιλογής στο πρόγραμμα,
- προειδοποίηση και απόρριψη επικαλυπτόμενων βαρδιών για την ίδια μηχανή,
- διόρθωση αφαίρεσης μόνιμης μηχανής από εργαζόμενο.
- επιλογή «Ιδιόκτητο μηχανάκι — χωρίς χιλιόμετρα» για εργαζομένους,
- συγχώνευση της καταχώρησης «Ανά διανομέα» στο ίδιο Πρόχειρο εβδομάδας.
- ταχύτερη απόκριση Worker/D1, χωρίς μείωση ιστορικών ή πληροφοριών.

1. CLOUDFLARE WORKER

Στον υπάρχοντα φάκελο cloudflare-worker κράτησε ανέπαφα:
- wrangler.jsonc,
- το πραγματικό D1 database_id,
- τα bindings DB, RELEASES και ASSETS,
- τα secrets και τα υπάρχοντα δεδομένα.

Αντικατάστησε μόνο τα αρχεία που περιλαμβάνονται στο πακέτο:
- src/worker.js
- src/workforce.js
- public/index.html
- public/portal.html
- public/portal.js
- public/portal.css

Χρησιμοποίησε το package.json του πακέτου ή κράτησε το υπάρχον μόνο αν έχεις
ήδη τις διορθωμένες εξαρτήσεις Wrangler/sharp από το npm audit fix.

Από το Command Prompt του υπάρχοντος project:

  npm install
  npm run deploy

Μην κάνεις DROP TABLE, migration reset ή αλλαγή database_id/bucket.

2. ΕΓΚΑΤΑΣΤΑΣΗ CLIENT v5.20

Εγκατάστησε το Fleet_Control_Client_v5.20.apk πάνω από την υπάρχουσα έκδοση.
Μην απεγκαταστήσεις την παλιά εφαρμογή: έτσι διατηρούνται οι ρυθμίσεις και
τα τοπικά δεδομένα. Το package name και η υπογραφή είναι ίδια με το v5.17.

3. ΕΝΕΡΓΟΠΟΙΗΣΗ ΑΥΤΟΜΑΤΩΝ UPDATES

Μετά το deploy:
- άνοιξε Server → Ενημερώσεις,
- ανέβασε το Fleet_Control_Client_v5.20.apk ως ενεργό Client release.

Οι επόμενες εκδόσεις θα ελέγχονται από την εφαρμογή στην εκκίνηση, στην
επιστροφή στο προσκήνιο και ανά 15 λεπτά. Το APK ελέγχεται με SHA-256,
package name και version πριν ανοίξει ο Android installer. Ο χρήστης πρέπει
να επιβεβαιώσει την εγκατάσταση. Σε Android 8+ μπορεί να ζητηθεί μία φορά
η άδεια «Εγκατάσταση άγνωστων εφαρμογών» για το Fleet Control.

4. ΕΛΕΓΧΟΣ ΔΙΟΡΘΩΣΕΩΝ

- Εργαζόμενοι: αφαίρεσε το μηχανάκι, αποθήκευσε και ξαναάνοιξε την καρτέλα.
  Πρέπει να εμφανίζεται «Χωρίς ανάθεση».
- Πρόγραμμα: αν δύο εργαζόμενοι έχουν την ίδια μόνιμη μηχανή και οι βάρδιες
  επικαλύπτονται, η αποθήκευση Πρόχειρου απορρίπτεται με προειδοποίηση.
- Το ίδιο μηχανάκι επιτρέπεται σε διαφορετικές, μη επικαλυπτόμενες ώρες.
- Η επιλογή «Χωρίς μηχανάκι» είναι ρητή εξαίρεση και υπερισχύει της μόνιμης
  ανάθεσης.
- Στην καρτέλα Εργαζόμενοι ενεργοποίησε «Ιδιόκτητο μηχανάκι — χωρίς
  χιλιόμετρα». Στο Clock In/Out ο εργαζόμενος δεν επιλέγει μηχανάκι και δεν
  πληκτρολογεί αρχικά/τελικά χιλιόμετρα. Οι ώρες και η μισθοδοσία συνεχίζουν
  να καταγράφονται κανονικά.
- Στην «Ανά διανομέα» πάτησε «Αποθήκευση» μετά από κάθε εργαζόμενο. Όλοι
  παραμένουν στο ίδιο Πρόχειρο· πάτησε «Δημοσίευση» μόνο όταν ολοκληρώσεις
  ολόκληρη την εβδομάδα.
- Στον απλό εργαζόμενο το κουμπί κλειδώνει προσωρινά κατά την καταχώρηση,
  ώστε να μην υπάρξουν διπλά πατήματα. Το ιδιόκτητο μηχανάκι δεν ζητά
  χιλιόμετρα και δεν ενημερώνει το μητρώο στόλου.
