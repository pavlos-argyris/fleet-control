# Φίλτρα τιμολογίων και ολίσθηση ουρών · 5.51.2

Client/Web 5.51.2 (Client versionCode 74), Server 2.2.10 (versionCode 36), Worker 5.12.2.

## Αλλαγές και χρήση

- Το «Όλες οι πινακίδες» έχει δική του πλήρη σειρά στο κινητό, χωρίς περικοπή της φράσης από τα γειτονικά κουμπιά. Στη μεγάλη οθόνη διατηρείται η οριζόντια γραμμή εργαλείων.
- Η επιλογή πινακίδας ανοίγει παράθυρο με τα κοινά χρώματα, πλαίσια και κουμπιά της εφαρμογής. Η τρέχουσα επιλογή επισημαίνεται με πράσινο και ✓. Η αναζήτηση εξισώνει ελληνικά/λατινικά γράμματα, κενά και παύλες.
- Το «Βασικές ουρές» ανοίγει αντίστοιχο παράθυρο με επεξήγηση. Οι βασικές ουρές αντιστοιχούν στα τρία κουμπιά «Σε επεξεργασία», «Χρειάζονται έλεγχο», «Ολοκληρωμένα». Τα υπόλοιπα φίλτρα περιορίζουν τα αποτελέσματα σε νέα, προς έλεγχο, προειδοποιήσεις ή σφάλματα.
- Τα παράθυρα κλείνουν με επιλογή, «Πίσω», Escape ή την υπάρχουσα πλοήγηση Πίσω του Android. Το πληκτρολόγιο δεν ανοίγει αυτόματα. Υπάρχουν πλήκτρα βελών/Home/End και ορατή εστίαση για χρήση χωρίς αφή.
- Η αλλαγή βασικής ουράς χρησιμοποιεί το ίδιο εφέ ολίσθησης 22px/190ms με την κάτω πλοήγηση, με κατεύθυνση ανάλογη της θέσης της επιλογής. Το πράσινο πλαίσιο κινείται από κουμπί σε κουμπί σε 220ms. Η ανανέωση δεδομένων στην ίδια ουρά δεν επαναλαμβάνει το εφέ. Η προτίμηση μειωμένης κίνησης απενεργοποιεί τα εφέ.

## Τεχνικά και έλεγχοι

Τα υπάρχοντα πεδία επιλογής και τα συμβάντα αλλαγής παραμένουν η μοναδική πηγή φιλτραρίσματος. Τα νέα ορατά κουμπιά συγχρονίζονται με τις δυναμικές επιλογές και τις προγραμματιστικές αλλαγές. Οι επιλογές δημιουργούνται με ασφαλή απόδοση κειμένου. Δεν προστίθεται polling, κλήση API, εξάρτηση ή αλλαγή στην ανάλυση PDF. Η ολίσθηση χρησιμοποιεί το υπάρχον FleetMotion με ακύρωση προηγούμενου animation στις γρήγορες αλλαγές.

Οι έλεγχοι καλύπτουν πραγματικό Chromium σε desktop, 390px, 320px και τοπικά πακεταρισμένο Client: πλήρη ετικέτα, εφαρμογή φίλτρων, ελληνική αναζήτηση, κανένα αποτέλεσμα, επιστροφή εστίασης, Πίσω/Escape, πλοήγηση πληκτρολογίου, πραγματικά καρέ/διάρκεια ολίσθησης, τελική θέση πράσινου πλαισίου, μειωμένη κίνηση και απουσία επανάληψης εφέ σε ανανέωση. Διατηρούνται οι συνολικοί έλεγχοι Fleet, PDF, ιστορικού, service και Server.

## Πλήρης κώδικας, εγκατάσταση και επαναφορά

Η έκδοση GitHub περιλαμβάνει πλήρη πηγαίο κώδικα όλων των τμημάτων, Client/Server APK, Web/Worker ZIP, build inputs, manifest και SHA-256. Τα ιστορικά immutable assets παραμένουν στον κώδικα και στο static deployment. Το Web ZIP και το OTA manifest χρησιμοποιούν κοινή πλήρη απογραφή τρέχουσας και δύο προηγούμενων εκδόσεων.

Για κατασκευή ισχύουν οι οδηγίες README, τα scripts προετοιμασίας PDF/assets, `bash scripts/check-all.sh` και οι οδηγίες Android/OTA. Τα αρχικά signing credentials παραμένουν ιδιωτικά. Απαιτούνται οι υπάρχοντες λογαριασμοί GitHub/Cloudflare και τα ιδιωτικά κλειδιά για ανεξάρτητη παραγωγική δημοσίευση.

Μετά την επιτυχή δημοσίευση χρησιμοποίησε «Έλεγχος τώρα» στον Client και στον Server, χωρίς απεγκατάσταση. Web και Worker ενημερώνονται από τη δημοσίευση. Δεν αλλάζουν δεδομένα, σχήματα, χιλιόμετρα, κόστη, αρχεία ή οι μορφές backup. Η προηγούμενη έκδοση διατηρείται στο GitHub· το Android δεν επιτρέπει συνήθη εγκατάσταση χαμηλότερου versionCode πάνω από νεότερο APK. Η επαναφορά δεδομένων ακολουθεί τις υπάρχουσες οδηγίες συμβατού backup. Δεν λήφθηκε νέο backup παραγωγικών δεδομένων από τον βοηθό. Δεν έγινε φυσική δοκιμή σε S24 Ultra: οι δοκιμές UI χρησιμοποιούν συνθετικά δεδομένα και πακεταρισμένα αρχεία.
