# Fleet Control 5.49.4 — ομαλότερη επιστροφή

Client/Web 5.49.4 (68), Worker 5.10.6. Server 2.2.5 (31), χωρίς αλλαγή APK.

- Η επιστροφή διατηρεί την πράσινη επιφάνεια, την πινακίδα και το εικονίδιο μηχανής. Η γεωμετρία του πλαισίου μετριέται/σταθεροποιείται πριν από την κίνηση. Κατά την αναπαραγωγή αλλάζουν μόνο transforms, αντί για left/top/width/height σε κάθε καρέ.
- Το πράσινο φόντο κλιμακώνεται/μετατοπίζεται και το περιεχόμενο μετατοπίζεται με το ίδιο easing και κοινό startTime. Τα κέντρα τους ακολουθούν την ίδια διαδρομή. Κείμενο και εικονίδιο δεν κλιμακώνονται, ώστε να μην παραμορφώνονται.
- Άνοιγμα και κλείσιμο διαρκούν 300 ms. Η ένδειξη κάτω πλοήγησης διατηρεί τη δική της διάρκεια 220 ms.
- Οι κάρτες της λίστας δεν αναδημιουργούνται όταν το παραγόμενο περιεχόμενό τους είναι ίδιο. Ο έλεγχος βασίζεται στο πλήρες παραγόμενο markup, όχι μόνο σε timestamps. Αν αλλάξουν δεδομένα/κατάσταση/προειδοποιήσεις, η λίστα ενημερώνεται κανονικά.
- Διατηρούνται η επαναφορά θέσης, Μείωση κίνησης και ο καθαρισμός μετά από διακοπή/resize. Δεν προστίθενται αιτήματα δικτύου ή αλλαγές δεδομένων.

## Έλεγχοι

`bash scripts/check-all.sh`: πλοήγηση, δύο επίπεδα με transform-only keyframes/διάρκεια 300 ms, διατήρηση ταυτότητας DOM σε αμετάβλητη λίστα, αλλαγή χιλιομέτρων που ενημερώνει την κάρτα, διακοπή και Back/Forward.

Το υποχρεωτικό CI/publish browser gate εκτελεί Chromium σε Web, Portal, τοπικά αρχεία Client και Μείωση κίνησης. Ελέγχει πράσινη επιφάνεια χωρίς screenshot λεπτομερειών, κοινό κέντρο κειμένου/εικονιδίου/φόντου, εικονίδιο 32×32 χωρίς κλιμάκωση, δύο animations 300 ms χωρίς layout properties, διατήρηση DOM της λίστας και σωστή θέση. Με CDP Performance.getMetrics μετρά LayoutCount από τη μέση της κίνησης μέχρι τον καθαρισμό και απαιτεί έως 4 layout passes, αντί για συνεχή επανυπολογισμό ανά καρέ. Οι μετρήσεις αποθηκεύονται στο results.json του navigation-motion-verification artifact.

Οι μετρήσεις Chromium ελέγχουν τον μηχανισμό και δεν αποτελούν μέτρηση FPS στη φυσική Samsung/WebView. Η ομαλότητα στη συσκευή επιβεβαιώνεται μετά την εγκατάσταση. Τα δεδομένα browser είναι συνθετικά.

## Εγκατάσταση και ανάκτηση

Client: «Έλεγχος τώρα» και ενημέρωση πάνω στην υπάρχουσα εγκατάσταση. Web: ανανέωση σελίδας. Worker/Web δημοσιεύονται από το εξουσιοδοτημένο workflow. Δεν απαιτείται νέα εγκατάσταση Server. Δεν αλλάζει σχήμα ή περιεχόμενο δεδομένων.

Στο GitHub release διατίθενται πλήρης πηγαίος όλων των τμημάτων, APK, Web/Worker, build inputs, οδηγίες και checksums με τις αρχικές υπογραφές Android. Τα ιδιωτικά κλειδιά δεν δημοσιεύονται. Η δημοσίευση δεν λαμβάνει αυτόματα backup παραγωγικών δεδομένων· διατηρείται το συνηθισμένο εξωτερικό backup Server.
