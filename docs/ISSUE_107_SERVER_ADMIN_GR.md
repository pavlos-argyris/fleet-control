# #107 — Διαχείριση Direct Server από τον Client

Η καρτέλα του Android Client ανοίγει για τον Owner / Super Admin. Η ίδια πολιτική ισχύει στις αναγνώσεις και στις εντολές του Direct API. Οι επιτρεπόμενες εργασίες είναι έλεγχος έκδοσης, συγχρονισμός σημερινών και χθεσινών παρουσιών από Ordexa, δημιουργία ή επανάληψη αποστολής backup και αλλαγή των ρυθμίσεών του. Η ανάγνωση Ordexa χρησιμοποιεί την υπάρχουσα διαδρομή του Android Server.

Τα αιτήματα καταγράφονται με ταυτότητα ενέργειας και λογαριασμό. Η εργασία ξεκινά μετά το commit της SQLite και παρακολουθείται στην καρτέλα. Η ένδειξη «Υποβλήθηκε» αφορά την έναρξη των υποκείμενων ασύγχρονων εργασιών. Η πραγματική έκβαση του backup ή της ενημέρωσης εμφανίζεται από την αντίστοιχη κατάσταση. Ακυρωμένες συνεδρίες χάνουν άμεσα πρόσβαση στο API και οι εκκρεμείς εντολές τους ακυρώνονται πριν από την έναρξη. Η ουρά τιμολογίων παραπέμπει στην υπάρχουσα καρτέλα για επιλεκτική επανάληψη. Η αλλαγή ρύθμισης backup συγκρίνει τις προηγούμενες τιμές πριν αποθηκευτεί.

Επιλογή φακέλου, αλλαγή δικτύου και πιστοποιητικού, ανάκτηση και εγκατάσταση APK χρησιμοποιούν τα υπάρχοντα τοπικά εργαλεία Android. Το API διαχειριστή δεν εκθέτει κωδικούς Ordexa, ιδιωτικά κλειδιά ή περιεχόμενα παραγωγικών backup.

## Τεχνική πρόσβαση Agent

Η υλοποίηση αυτή προσφέρει διαχείριση για τον ιδιοκτήτη. Η δοκιμή δημόσιου HTTPS από το τρέχον περιβάλλον επέστρεψε HTTP 503 και δεν υπάρχει διαθέσιμος connector με επαληθευμένη ασφαλή αποθήκευση ταυτότητας για το Direct domain. Η απαίτηση L παραμένει εκκρεμής. Μια συμβατή διασύνδεση μπορεί να χρησιμοποιήσει τοπικό Codex με MCP, μόνο εφόσον μπορεί να επαληθεύσει το HTTPS. Ο ιδιοκτήτης εξουσιοδοτεί χωριστή ταυτότητα με OAuth και αποθηκεύει την εξουσιοδότηση στον έμπιστο υπολογιστή του. Μετά την επαλήθευση, οι πρώτες λειτουργίες περιορίζονται σε έκδοση, listener, ουρές και μετρήσεις χωρίς οικονομικά ή προσωπικά στοιχεία. Νέες διορθωτικές ενέργειες χρειάζονται χωριστά scopes, καταγραφή και πραγματική δοκιμή λήξης και ανάκλησης. Η [τεκμηρίωση MCP του Codex](https://developers.openai.com/codex/mcp) και η [τεκμηρίωση εξουσιοδότησης](https://developers.openai.com/plugins/build/auth) ορίζουν τη συμβατή σύνδεση.

Πέρασε η εκτέλεση των πραγματικών bundled handlers σε Java/Rhino και SQLite με Owner, Manager, εργαζόμενο και ανώνυμο αίτημα. Ελέγχθηκαν απόρριψη μη υποστηριζόμενης ή μη έγκυρης εντολής, επανάληψη μετά από χαμένη απάντηση και μία καταχώρηση ουράς ανά ενέργεια. Πέρασε η κατασκευή των δύο APK με δοκιμαστική υπογραφή. Χρειάζεται πραγματικός έλεγχος της καρτέλας μέσα από ενημερωμένο Client στον Direct Server.
