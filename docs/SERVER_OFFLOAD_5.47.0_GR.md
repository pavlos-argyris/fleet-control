# Fleet Control 5.47.0 — εργασία στον Server και λιγότερα αιτήματα

## Εγκεκριμένη εργασία

- Ενιαία τοπική ανάγνωση QR, ανεβασμένων PDF/εικόνων και μεμονωμένων επανελέγχων. Workers AI όταν η τοπική ανάγνωση είναι αβέβαιη ή ζητηθεί ρητά.
- Αποθηκευμένη ουρά στον Android Server, συνδυασμένη παραλαβή εργασιών/συγχρονισμού και αραιότεροι έλεγχοι σε αδράνεια.
- Προετοιμασία συνολικού ελέγχου στόλου και κόστους από το τοπικό αντίγραφο. Τα αποτελέσματα συνδέονται με την έκδοση δεδομένων και δεν αλλάζουν αυτόματα καταχωρήσεις.
- Διαφορικό αντίγραφο προσωπικού/προγράμματος/μισθοδοσίας: πρώτη πλήρης λήψη, έπειτα μόνο αλλαγμένες ή διαγραμμένες εγγραφές.
- Παύση περιττών ελέγχων Web/Client όταν η οθόνη είναι κρυμμένη και αραιότερη ανανέωση χωρίς ενεργές αναγνώσεις.

Ο Worker εξακολουθεί να ελέγχει σύνδεση, δικαιώματα και τελικές εγγραφές. Η καταχώρηση εργασίας και το ωράριο προσωπικού παραμένουν διαθέσιμα όταν το κινητό Server είναι εκτός σύνδεσης.

## Παράδοση

Πλήρης πηγαίος κώδικας όλων των τμημάτων στο GitHub, υπογεγραμμένα APK με το αρχικό πιστοποιητικό, Web/Worker, οδηγίες και έλεγχοι. Αυτόματη δημοσίευση μόνο μετά την επιτυχία των ελέγχων του τελικού source commit.

Κατάσταση: υπό υλοποίηση. Οι τελικές εκδόσεις, μετρήσεις και οδηγίες θα συμπληρωθούν μετά την επαλήθευση.
