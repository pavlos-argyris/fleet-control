# Fleet Control 5.47.0 — τοπική επεξεργασία στον Server

Client/Web 5.47.0 (61), Server 2.2.3 (29), Worker 5.9.0.

## Οι τέσσερις αλλαγές

- Αποθηκευμένα PDF/εικόνες και μεμονωμένες επαναλήψεις μπαίνουν στην τοπική διαδρομή PDFBox/Tesseract του Server, όπως τα QR. Το Workers AI χρησιμοποιείται σε αβέβαιο αποτέλεσμα ή με τη ρητή επιλογή Workers AI. Η παράκαμψη cache παραμένει διαθέσιμη στην επανάληψη.
- Η ουρά αποθηκεύεται στη SQLite του Server πριν εκτελεστεί. Μετά από επανεκκίνηση επιβεβαιώνει ποιες εργασίες είναι ακόμη ενεργές. Τα αποτελέσματα τοπικής ανάγνωσης αρχείων διατηρούνται μέχρι επιβεβαίωση. Οι ακυρώσεις ελέγχονται στον κοινό συγχρονισμό και ξανά στον Worker πριν αποθηκευτεί αποτέλεσμα.
- Ο Server υπολογίζει συγκεντρωτικό έλεγχο: κόστος ανά μηχανάκι και συνολικά, service χωρίς τιμολόγιο, ιστορικό χιλιομέτρων, διαφορετικές ενδείξεις τιμολογίου και πιθανά διπλότυπα. Άνοιγμα από τις Εκκρεμότητες → «Συνολικός έλεγχος από Server». Η αναφορά δεν τροποποιεί δεδομένα, έχει Πίσω/Ανανέωση και εμφανίζεται μόνο για την τρέχουσα έκδοση στόλου. Κόστη χωρίς ποσό επισημαίνονται, δεν θεωρούνται μηδενική χρέωση. Πιθανά διπλά παραστατικά χρειάζονται έλεγχο· μόνο ίδιο κλειδί αρχείου εξαιρείται από δεύτερη άθροιση.
- Το αντίγραφο των 28 πινάκων προσωπικού λαμβάνει πλήρη βάση την πρώτη φορά και έπειτα μόνο αλλαγές/διαγραφές, σε σελίδες έως 20 εγγραφών. Διακοπή λήψης δεν αντικαθιστά το τελευταίο πλήρες τοπικό αντίγραφο. Ληγμένος δείκτης αλλαγών προκαλεί νέα πλήρη λήψη.

## Μείωση αιτημάτων

Ο Server συνδυάζει κατάσταση, αλλαγές στόλου, ουρά, επιβεβαιώσεις, πρόοδο και αναφορά σε μία ανταλλαγή. Σε αδράνεια φτάνει σε ένα αίτημα ανά λεπτό, ενώ με ενεργά τιμολόγια ελέγχει ανά 10 δευτερόλεπτα. Οι επαναλήψεις σύνδεσης αραιώνουν μετά από σφάλμα. Δεν ζητά άδεια ουρά κάθε 3 δευτερόλεπτα. Το ανεξάρτητο σήμα σύνδεσης λειτουργεί μόνο αν καθυστερήσει η κύρια ανταλλαγή.

Η καρτέλα τιμολογίων ελέγχει ενεργές εργασίες ανά 5 δευτερόλεπτα και αδράνεια ανά λεπτό. Η οθόνη στόλου συγχρονίζει ανά λεπτό όταν είναι ορατή· η κρυφή καρτέλα/ενσωματωμένη οθόνη δεν κάνει περιοδικές αναγνώσεις. Οι τοπικές αποστολές που εκκρεμούν συνεχίζονται.

Τα 1.440 αιτήματα/ημέρα είναι θεωρητικός υπολογισμός μόνο για την κύρια ανταλλαγή Server σε μόνιμη αδράνεια. Δεν είναι μέτρηση παραγωγής ούτε όριο συνολικών αιτημάτων: επιπλέον υπάρχουν χρήστες, QR/PDF, αλλαγές, αντίγραφα, OCR/AI και OTA. Το Cloudflare παραμένει η κεντρική βάση για τελικές εγγραφές, δικαιώματα, βάρδιες και μισθοδοσία.

## Ενημέρωση και επαναφορά

1. Πάρε backup από τον Server πριν εγκαταστήσεις APK και κράτησέ το εκτός της εφαρμογής. Η δημοσίευση δεν δημιουργεί από μόνη της αντίγραφο παραγωγικών δεδομένων.
2. Το workflow ενημερώνει Worker/Web και διαθέτει τα υπογεγραμμένα APK μέσω OTA. Εγκατάστησε Server 2.2.3 και Client 5.47.0 πάνω στις υπάρχουσες εφαρμογές, χωρίς απεγκατάσταση.
3. Ο νέος Worker παραμένει συμβατός με τον προηγούμενο Server. Η τοπική ανάγνωση αρχείων ενεργοποιείται όταν επικοινωνήσει ο νέος Server. Μέχρι τότε ισχύει η προηγούμενη διαδρομή. Όταν ο Server είναι εκτός σύνδεσης οι τοπικές εργασίες περιμένουν· η ρητή επιλογή Workers AI παραμένει διαθέσιμη.
4. Η πρώτη λήψη αντιγράφου προσωπικού είναι πλήρης. Οι επόμενες διαφορικές. Δεν διαγράφονται τα δεδομένα παραγωγής και δεν απαιτείται restore κατά την ενημέρωση.
5. Επιστροφή σε προηγούμενο APK δεν είναι αυτόματη επαναφορά δεδομένων. Διατήρησε ελεγμένο backup και τα ιδιωτικά στοιχεία υπογραφής. Η επαναφορά παραμένει η υπάρχουσα διαδικασία προεπισκόπησης/επιβεβαίωσης, με τους καταγεγραμμένους περιορισμούς συγχώνευσης.

## Επαληθεύσιμοι έλεγχοι

- `bash scripts/check-all.sh`: Web/Worker, API, δικαιώματα, μισθοδοσία, υπηρεσίες, αντίγραφα και νέα διαδρομή ουράς/AI/αναφορών.
- `node scripts/test-offload-d1.mjs`: πραγματικό τοπικό Workers/D1 runtime, δημιουργία 84 triggers, εξωτερικό UPSERT, ενημέρωση/διαγραφή και κοινή ανταλλαγή. Τα δεδομένα είναι συνθετικά.
- `node scripts/test-server-system-mirror.mjs`: πραγματικός αλγόριθμος Java, σελίδες, ενημερώσεις, διαγραφές, αποτυχία λήψης χωρίς μεταβολή προηγούμενου αντιγράφου.
- `node scripts/test-server-offload-native.mjs`: ουρά Java μετά από επανεκκίνηση, αποθηκευμένο αποτέλεσμα, ακύρωση/επιβεβαίωση, χρόνοι polling, υπολογισμός 9+50, πιστωτικά και επιβεβαιωμένα χιλιόμετρα. Η υποδομή JSON αυτών των JVM δοκιμών είναι ρητά test fixture· η κατασκευή APK ελέγχει τα πραγματικά Android APIs.
- Τα workflows κατασκευάζουν και τα δύο APK. Το workflow δημοσίευσης χρησιμοποιεί το αρχικό ιδιωτικό πιστοποιητικό και παράγει source ZIP, APK, Web, Worker, build inputs, manifest και SHA-256.

Η εγκατάσταση, οι περιορισμοί μπαταρίας Samsung και οι χρόνοι OCR στη φυσική συσκευή ελέγχονται στη συσκευή. Οι συνθετικές δοκιμές και η επιτυχία δημοσίευσης δεν πιστοποιούν από μόνες τους αυτά τα αποτελέσματα.
