# Fleet Control 5.40.0 — Πρόοδος και ανάγνωση PDF

Client/Web 5.40.0 (code 52), Server 2.1.5 (code 21), Worker 5.3.2. Διατηρούνται η αρχική υπογραφή Android, τα κλειδιά, η βάση και οι διορθώσεις 5.39.1.

## Πρόοδος

- Διατηρείται το πράσινο φωτισμένο ζιγκ-ζαγκ, με βραδύτερη κίνηση. Η φωτισμένη διαδρομή περιστρέφεται και γύρω από τον κύκλο, δεξιόστροφα, με περίοδο περίπου 8,3 δευτερολέπτων.
- Η αριθμητική πρόοδος και το μήκος της διαδρομής εξακολουθούν να προέρχονται από την εργασία. Η αλλαγή δεν καθυστερεί την πραγματική επεξεργασία.
- Ο κυματισμός κλείνει ομαλά στο σημείο που συμπληρώνεται ο κύκλος. Τα ολοκληρωμένα και τα σφάλματα δεν περιστρέφονται. Με μειωμένη κίνηση ολόκληρο το σχέδιο μένει στατικό.
- Γίνεται μία αρχική μέτρηση μεγέθους Canvas και νέα μέτρηση σε αλλαγή πλάτους ή κλίμακας, αντί για layout reads σε κάθε frame.

## Αναγνώστης

- Προσαρμογές για ηλεκτρονικά τιμολόγια με text layer όπως το δείγμα Impact/eInvoicing. Εξακολουθούν να απαιτούνται Workers AI για εικόνες, ανεπαρκές κείμενο ή αμφίβολη ανάγνωση.
- Αποφεύγονται επαναλαμβανόμενα αντίγραφα ολόκληρου του PDF, αποκωδικοποιήσεις ίδιων streams/font maps, regex compilations και σαρώσεις όλων των προηγούμενων γραμμών.
- Γίνεται ανάγνωση πολλών Contents streams και μέχρι 128.000 χαρακτήρων για εξαγωγή πεδίων, ενώ το rawText αποτελέσματος παραμένει έως 6.000 χαρακτήρες. Έτσι τα σχόλια στο τέλος μεγαλύτερου παραστατικού δεν χάνονται πρόωρα.
- Ημερομηνία Έκδοσης αντί αποστολής/παράδοσης/αδειοδότησης, με πραγματικό έλεγχο ημερολογίου. Μη έγκυρη ημερομηνία έκδοσης οδηγεί σε αμφίβολο αποτέλεσμα.
- Συνολική Αξία με ΦΠΑ αντί καθαρού ποσού ή υπολοίπου πελάτη. Όταν δεν υπάρχει σαφές συνολικό ποσό, δεν επιλέγεται αυθαίρετα ένα άλλο ποσό.
- Πινακίδα και χιλιόμετρα από σχόλια που σπάνε σε γραμμές. Τα 3–4 ψηφία της πινακίδας αφαιρούνται πριν την αναζήτηση χιλιομέτρων. Πολλαπλοί διαφορετικοί αριθμοί στα σχόλια δεν αντιμετωπίζονται ως βέβαια χιλιόμετρα.
- Διαφωνία PDF και κειμένου της σελίδας σε κρίσιμα πεδία μειώνει τη βεβαιότητα και ζητά πρόσθετη ανάγνωση AI. Δεν προστίθενται όροι πληρωμής στις εργασίες και διατηρούνται οι επιβεβαιωμένες διορθώσεις.
- Οι οδηγίες Workers AI εξηγούν ρητά τη δομή, τη συνένωση γραμμών ενός είδους και τη διάκριση συνολικής αξίας/υπολοίπου. Δεν έχει μετρηθεί πραγματική ακρίβεια AI σε παραγωγή.

## Έλεγχοι

- Πραγματικά Fleet/Portal Canvas functions σε VM: περιστροφή, ακριβές μήκος προόδου, κλειστός κύκλος, cache διαστάσεων, αλλαγή μεγέθους, ολοκλήρωση και μειωμένη κίνηση.
- Πραγματικός Java parser με μικρά JSON fixtures εξαρτήσεων: CMaps/Contents arrays, περιγραφές/σχόλια σε γραμμές, μη έγκυρες ημερομηνίες, μεικτές μορφές ποσού/πινακίδας, σύγκρουση πηγών και σχόλια πέρα από 6.000 χαρακτήρες.
- Ιδιωτικό PDF δείγματος: πινακίδα, χιλιόμετρα, ημερομηνία, συνολική αξία και τέσσερα είδη διαβάστηκαν σωστά. Το έγγραφο δεν ενσωματώνεται στον κώδικα ή στο GitHub.
- Μέτρηση τοπικής εξαγωγής του ίδιου PDF μετά από προθέρμανση, 20 επαναλήψεις: πριν περίπου 21,9 ms, μετά περίπου 16,4–17,7 ms. Ο πλήρης χρόνος δημιουργίας PDF/δικτύου/AI δεν έχει μετρηθεί και το S24 Ultra μπορεί να έχει άλλους χρόνους.
- Πλήρης προηγούμενη σουίτα, συνθετικά backup/restore, κατασκευή APK με αρχικές υπογραφές και Wrangler dry-run. Δεν υπάρχουν browser screenshots/εγκατάσταση σε φυσική συσκευή ή backup παραγωγής από τον βοηθό.

## Ενημέρωση και ανάκτηση

Η αυτόματη δημοσίευση αναπτύσσει Worker 5.3.2 και ενεργοποιεί Server/Client/Web μαζί. Στον Server ολοκλήρωσε OTA 2.1.5, πάνω από την υπάρχουσα εφαρμογή, με επιλεγμένο φάκελο backup. Στον Client ολοκλήρωσε OTA 5.40.0. Αν το Web κρατά παλιά assets, κάνε ανανέωση. Η βελτίωση τοπικής ανάγνωσης απαιτεί τον νέο Server· η νέα κίνηση απαιτεί νέο Web/Client. Δεν εκκινείται αυτόματα νέα ανάγνωση όλων των πραγματικών τιμολογίων κατά τη δημοσίευση.

Διατήρησε πρόσφατο backup παραγωγικών δεδομένων. Η OTA κρατά το απαιτούμενο backup πριν από την εγκατάσταση. Η προειδοποίηση Play Protect δεν θεωρείται λυμένη χωρίς ακριβές μήνυμα/έλεγχο συσκευής.

Ολόκληρος ο κώδικας Android Client/Server, κοινό OTA, Web/Portal, Worker, tests, build scripts, manifests/assets, lockfiles, τεκμηρίωση και toolchain υπάρχει στο GitHub/source ZIP. Το source ZIP δεν περιλαμβάνει πραγματικά κλειδιά, δεδομένα παραγωγής ή τιμολόγια. Για νέα κατασκευή συμβατών APK χρησιμοποίησε το υπάρχον ιδιωτικό αντίγραφο ανάκτησης υπογραφής. Προηγούμενες υπογεγραμμένες εκδόσεις παραμένουν στα GitHub releases. Η υποβάθμιση μπορεί να απαιτεί απεγκατάσταση και συμβατό backup για επαναφορά· δεν γίνεται αυτόματη διαγραφή ή restore παραγωγής.
