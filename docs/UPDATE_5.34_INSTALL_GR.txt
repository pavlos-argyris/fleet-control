FLEET CONTROL — ΟΔΗΓΙΕΣ ΕΝΗΜΕΡΩΣΗΣ 5.34

1. Κράτησε αντίγραφο του υπάρχοντος φακέλου `cloudflare-worker`.

2. Από το `Fleet_Control_Web_Worker_Update_v5.34.zip` αντέγραψε τα νέα `src`, `public`, `package.json`, `package-lock.json` και τις οδηγίες μέσα στον υπάρχοντα φάκελο Worker.

3. Μην αντικαταστήσεις το υπάρχον production `wrangler.jsonc`. Κράτησε το δικό σου D1 ID και τα υπάρχοντα bindings.

4. Άνοιξε CMD στον Worker και εκτέλεσε:

   `npm install`

   `npm run deploy`

5. Έλεγξε ότι εμφανίζονται τα bindings `DB`, `RELEASES`, `SERVICE_DOCS`, `AI` και `ASSETS`.

6. Ανέβασε στο Server APK, στην επιλογή ενημερώσεων, το:

   - `Fleet_Control_Client_v5.34.apk`
   - `Fleet_Control_Web_Assets_v5.34.zip`

   Το Server APK παραμένει στην έκδοση `2.0.8` και δεν χρειάζεται επανεγκατάσταση για αυτές τις δύο αλλαγές.

7. Μετά τη σύνδεση στην καρτέλα «Τιμολόγια service» θα δεις:

   - `Διαγραφή` σε κάθε τιμολόγιο,
   - `↻ Νέα ανάγνωση` για ένα παλιό PDF,
   - `↻ Νέα ανάγνωση παλιών` για όλα τα αποθηκευμένα PDF.

   Η νέα ανάγνωση εφαρμόζει αναδρομικά την αφαίρεση κωδικών/SKU, τη διόρθωση `[object Object]`, τη συγχώνευση διπλών εργασιών και τα bullets. Η πρόοδος και ο χρόνος ενημερώνονται αυτόματα στο Web και στο Client χωρίς refresh.

Η νέα ανάγνωση γίνεται σειριακά, ώστε να μην επιβαρύνεται απότομα ο Worker. Τα χειροκίνητα επιβεβαιωμένα στοιχεία διατηρούνται.
