# Fleet Control 5.23 / Worker 5.0.23

Η έκδοση προσθέτει τον νέο κύκλο ελέγχου Clock In/Clock Out και απλοποιεί τους κανόνες μισθοδοσίας.

## Νέα λειτουργικότητα

- Προεπιλεγμένη ανοχή καθυστερημένου Clock Out 30 λεπτά, ρυθμιζόμενη ανά κανόνα.
- Ο προγραμματισμένος χρόνος λήξης είναι το ανώτατο πληρωτέο όριο μέχρι να εγκριθεί υπερωρία.
- Η έγκριση υπερωρίας καταγράφει ποιος την έκανε, πότε, την τιμή €/ώρα και τα εγκεκριμένα λεπτά.
- Η μισθοδοσία μπορεί να υπολογίσει μόνο τα εγκεκριμένα λεπτά υπερωρίας.
- Καταργήθηκε η στρογγυλοποίηση διάρκειας από τον ενεργό υπολογισμό· τα πληρωτέα λεπτά είναι ακριβή.
- Προστέθηκε στο Admin → Βάρδιες το «Χειροκίνητο Clock In» για ξεχασμένες καταχωρήσεις.
- Οι ειδικές ωριαίες ζώνες αποθηκεύονται και φορτώνονται σωστά ακόμη και από παλαιότερα payloads.

## Έλεγχοι

- Worker, payroll, schedule και UI regression checks: επιτυχία.
- Admin simulation: χειροκίνητο Clock In, ιδιόκτητο μηχανάκι, ειδικές ζώνες και έγκριση 30 λεπτών υπερωρίας: επιτυχία.
- Client APK 5.23: υπογραφή v1/v2/v3 επαληθεύτηκε.
- Δεν έγινε έλεγχος σε φυσική Android συσκευή ή emulator.
