# #107 — Ανάκαμψη οθόνης Android Server

Η αρχικοποίηση της Direct βάσης γίνεται εκτός του νήματος της οθόνης. Η προετοιμασία εμφανίζει εγγενές μήνυμα μέχρι να ανοίξει το dashboard. Ο JavaScript bridge επιστρέφει αμέσως την τελευταία κατάσταση και επιτρέπει μία ανανέωση SQLite τη φορά στο παρασκήνιο. Οι ενέργειες που απαιτούν επιβεβαιωμένες ρυθμίσεις περιμένουν την πρώτη επιτυχημένη ανάγνωση.

Σε αποτυχία φόρτωσης ή τερματισμό του WebView renderer γίνεται μία αυτόματη επαναφόρτωση της οθόνης. Επόμενη αποτυχία εμφανίζει «Άνοιγμα ξανά». Η διαδικασία αφορά μόνο την Activity και το WebView. Το logcat με tag FleetServerUi καταγράφει την κατηγορία αστοχίας. Ο μηχανισμός ανάκτησης Direct SQLite παραμένει υπεύθυνος για εκκρεμείς επαναφορές.

Το ολοκληρωμένο APK κατασκευάστηκε με δοκιμαστική υπογραφή. Ο έλεγχος πακεταρίσματος επιβεβαιώνει ότι το callback υπάρχει και ότι ο τύπος υπογραφής από το SDK χρησιμοποιείται μόνο στη μεταγλώττιση. Η επαναφορά λευκής οθόνης σε πραγματικό Samsung και η λειτουργία HTTPS στη διάρκειά της χρειάζονται φυσική επαλήθευση.

Η ιδιωτική σύνδεση της οθόνης με τη διεργασία Direct απελευθερώνεται μετά από κάθε αίτημα. Μια επανεκκίνηση της διεργασίας Direct επιστρέφει ελεγχόμενο σφάλμα στην οθόνη, η οποία μπορεί να διαβάσει ξανά τα στοιχεία μόλις επανέλθει η υπηρεσία.
