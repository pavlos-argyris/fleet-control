FLEET CONTROL 5.26 — ΕΓΚΑΤΑΣΤΑΣΗ

1. Worker

Κράτησε αντίγραφο του υπάρχοντος φακέλου cloudflare-worker.

Από το αρχείο Worker update αντέγραψε μόνο:
  src
  public
  package.json

ΜΗΝ αντικαταστήσεις το υπάρχον wrangler.jsonc. Πρέπει να μείνει το πραγματικό
D1 database_id και τα δικά σου bindings.

Στον υπάρχοντα wrangler.jsonc πρέπει να υπάρχουν:
  env.DB
  env.RELEASES
  env.SERVICE_DOCS
  env.AI
  env.ASSETS

Μετά εκτέλεσε μέσα στον φάκελο του Worker:
  npm install
  npm run deploy

2. Web

Από το Server APK, στην επιλογή Ενημερώσεις, ανέβασε το:
  Fleet_Control_Web_Assets_v5.26.zip

Το Web release θα ενεργοποιηθεί από το Server APK όπως και οι προηγούμενες
εκδόσεις.

3. Client APK

Από το Server APK, στην επιλογή Ενημερώσεις, ανέβασε το:
  Fleet_Control_Client_v5.26.apk

Οι συσκευές με παλαιότερο Client θα εμφανίσουν εσωτερικά το prompt ενημέρωσης.

4. Νέα λειτουργία τιμολογίων

Κατά τη μεταφόρτωση φωτογραφίας τιμολογίου η εφαρμογή προσπαθεί να διαβάσει
το QR, την ηλεκτρονική σελίδα και το OCR. Πριν αποθηκευτούν οι πληροφορίες
στο service θα εμφανιστεί παράθυρο επιβεβαίωσης.

Στο ιστορικό υπάρχει πλέον Προβολή, Λήψη και Αναλυτικά αποτελέσματα OCR.
Στην εξαγωγή ιστορικού δημιουργείται καθαρό QR από το αποθηκευμένο URL του
ηλεκτρονικού τιμολογίου.
