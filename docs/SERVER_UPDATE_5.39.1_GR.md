# Fleet Control 5.39.1 — Server, OTA και σύνδεση

Client/Web 5.39.1 (Client versionCode 51), Server 2.1.4 (versionCode 20), Worker 5.3.1. Δεν αλλάζουν το σχήμα βάσης, τα κλειδιά και οι υπογραφές Android.

## Τι αλλάζει

- Η ανανέωση της οθόνης κάθε δευτερόλεπτο ενημερώνει την κατάσταση χωρίς να αντικαθιστά τις ρυθμίσεις που επεξεργάζεσαι. Η επιτυχής αποθήκευση ολοκληρώνει την επεξεργασία· σε σφάλμα τα πεδία διατηρούνται.
- Ο Server ελέγχει OTA κάθε 60 δευτερόλεπτα όταν η αυτόματη ενημέρωση είναι ενεργή. Το άνοιγμα της καρτέλας ενημερώσεων ή ο χειροκίνητος έλεγχος ζητά άμεσο έλεγχο. Η λήψη γίνεται σε ανεξάρτητο thread.
- Μια έτοιμη ενημέρωση αποκτά προτεραιότητα μετά από ολοκληρωμένο αποτέλεσμα τιμολογίου. Δεν ακυρώνονται ήδη εκτελούμενες τοπικές αναγνώσεις. Η ουρά παραμένει στον Worker, ο δείκτης αποθηκεύεται και η νέα έκδοση συνεχίζει από το επόμενο τιμολόγιο. Πριν από το backup ανανεώνονται τα διαθέσιμα mirrors. Το backup, η επαλήθευση SHA-256, package, έκδοσης και αρχικής υπογραφής διατηρούνται. Αποτυχημένη αυτόματη εγκατάσταση ξαναδοκιμάζεται μετά από 15 λεπτά· χειροκίνητο αίτημα μπορεί να ξαναδοκιμάσει νωρίτερα.
- Η κάρτα OTA δείχνει λήψη με πραγματικά bytes/ποσοστό. Έλεγχος, backup και εγκατάσταση εμφανίζουν απροσδιόριστη πρόοδο, χωρίς επινοημένο ποσοστό. Αν απαιτείται ενέργεια Android υπάρχει σαφής ένδειξη και κουμπί επιβεβαίωσης. Η αναμονή επιβεβαίωσης δεν σταματά μόνιμα τον συγχρονισμό.
- Οι αλλαγές εμφανίζονται με bullets, μία ανά γραμμή, στον Server και Client. Οι παλαιότερες σημειώσεις που χωρίζονταν με κόμματα μετατρέπονται για προβολή.
- Ένας ανεξάρτητος παλμός σύνδεσης κάθε 30 δευτερόλεπτα συνεχίζεται όσο η υπηρεσία λειτουργεί, ακόμη και όταν δέκα τιμολόγια αναλύονται ή γίνεται πλήρης συγχρονισμός. Ο έλεγχος σύνδεσης χρησιμοποιεί προστατευμένο, ελαφρύ endpoint χωρίς ανάγνωση ολόκληρου του fleet snapshot. Ο διαγνωστικός έλεγχος δεν δηλώνει online μια σταματημένη υπηρεσία.
- Τα GET επαναλαμβάνονται έως δύο φορές σε HTTP 429/502/503/504, με καθυστέρηση ενός και δύο δευτερολέπτων. Αιτήματα αλλαγής δεδομένων και σφάλματα ταυτοποίησης δεν επαναλαμβάνονται αυτόματα. Οι συνδέσεις κλείνουν και οι ανακατευθύνσεις απενεργοποιούνται. Όπου είναι διαθέσιμος εμφανίζεται ο κωδικός Cloudflare Ray για διάγνωση.
- Νέο κουμπί στο κάτω μέρος του Fleet «Σειρά τελευταίων service»: ενεργά μηχανάκια από το πιο πρόσφατο προς το παλαιότερο βάσει ημερομηνίας service, με ημερομηνία/χιλιόμετρα και τελευταία αλλαγή λαδιών. Το ανέβασμα παλιού τιμολογίου ή μεγαλύτερα χιλιόμετρα δεν αλλάζουν τη χρονολογική σειρά. Αρχικές ενδείξεις και έλεγχοι χιλιομέτρων εξαιρούνται. Αν η καρτέλα υπολογίζει περισσότερα χιλιόμετρα λαδιών από τη χρονολογικά τελευταία αλλαγή, εμφανίζεται επισήμανση για έλεγχο. Το Πίσω επιστρέφει στο Fleet και στην προηγούμενη θέση κύλισης· από καρτέλα μηχανής επιστρέφει πρώτα στη λίστα. Η λίστα είναι ενημερωτική και δεν αλλάζει αυτόματα χιλιόμετρα/όρια service.
- Σταθεροποίηση κύλισης σε Fleet/Portal/Server: σταθερά ύψη viewport, κατάργηση ελαστικής κύλισης και μεταφοράς scrolling μεταξύ παραθύρου/σελίδας/iframe, ένα βασικό σημείο κύλισης ανά παράθυρο, κλείδωμα υποβάθρου με ανοικτό dialog, λιγότερα βαριά εφέ σε οθόνες αφής. Η εμφάνιση πληκτρολογίου και περιστροφή εξακολουθούν να προσαρμόζουν το διαθέσιμο ύψος. Ο controller δεν εκτελεί εργασία layout σε κάθε scroll.
- Η ένδειξη γράφει Server S24 Ultra.

## Εγκατάσταση

1. Διατήρησε πρόσφατο backup παραγωγικών δεδομένων με τα υπάρχοντα εργαλεία. Ο βοηθός δεν έχει λάβει backup από τη συσκευή σου.
2. Η δημοσίευση στο GitHub αναπτύσσει τον Worker 5.3.1 και ενεργοποιεί Server/Client/Web. Δεν απαιτείται χειροκίνητη αντιγραφή του Worker.
3. Στον υπάρχοντα Server άνοιξε τις ενημερώσεις και πάτησε έλεγχο. Εγκατάστησε τον Server 2.1.4 πάνω από την τρέχουσα εφαρμογή. Μην απεγκαταστήσεις για κανονικό update. Πρέπει να υπάρχει επιλεγμένος φάκελος backup και άδεια εγκατάστασης. Ολοκλήρωσε την επιβεβαίωση Android αν ζητηθεί.
4. Οι νέοι χρόνοι και η νέα κάρτα ισχύουν αφού εγκατασταθεί ο Server 2.1.4. Η παλιά έκδοση εξακολουθεί να χρησιμοποιεί τον προηγούμενο κύκλο OTA μέχρι τότε.
5. Στον Client έλεγξε/ολοκλήρωσε την ενημέρωση 5.39.1 για τη νέα μορφή σημειώσεων. Στο Web κάνε ανανέωση αν κρατά παλιά assets.
6. Έλεγξε ότι μια αλλαγή στο διάστημα συγχρονισμού παραμένει στην οθόνη για περισσότερα από λίγα δευτερόλεπτα και αποθηκεύεται. Στην επόμενη φυσιολογική ανάγνωση τιμολογίων έλεγξε σύνδεση και πρόοδο. Ο βοηθός δεν εκκινεί μαζική επανεπεξεργασία πραγματικών τιμολογίων.

## Προειδοποίηση επιβλαβούς εφαρμογής

Δεν έχει δοθεί το ακριβές μήνυμα ή screenshot. Δεν μπορεί ακόμη να διαπιστωθεί αν πρόκειται για αίτημα σάρωσης, χαρακτηρισμό επιβλαβούς εφαρμογής ή άλλη προειδοποίηση Android/Play Protect. Η διατήρηση της υπογραφής επιβεβαιώνει συμβατότητα ενημέρωσης και δεν αποδεικνύει από μόνη της ότι μια εφαρμογή είναι ασφαλής. Η παρούσα έκδοση δεν παρακάμπτει ή απενεργοποιεί Play Protect. Η διάγνωση/τυχόν αναθεώρηση χαρακτηρισμού χρειάζεται το ακριβές μήνυμα και στοιχεία APK.

## Ανάκτηση και συνέχιση ανάπτυξης

Ο πλήρης κώδικας όλων των τμημάτων αποθηκεύεται στο GitHub και στο source ZIP: Android Client, Server, κοινό OTA, Web/Portal, Worker, manifests/assets, lockfiles, scripts, tests, τεκμηρίωση και portable toolchain. Πραγματικά κλειδιά, λογαριασμοί και παραγωγικά δεδομένα δεν περιλαμβάνονται· χρησιμοποίησε το υπάρχον ιδιωτικό αντίγραφο ανάκτησης υπογραφής. Το source ZIP δεν είναι backup δεδομένων.

Η παλαιότερη υπογεγραμμένη έκδοση παραμένει στο προηγούμενο release. Η υποβάθμιση Android μπορεί να χρειαστεί απεγκατάσταση, η οποία διαγράφει τοπικά δεδομένα. Επαναφορά γίνεται μόνο από διαθέσιμο, συμβατό backup με τις υπάρχουσες οδηγίες backup/restore. Δεν εκτελείται αυτόματη επαναφορά ή διαγραφή παραγωγικών δεδομένων.

## Πραγματικοί έλεγχοι και όρια

- VM στα πραγματικά Server JavaScript: πρόχειρες ρυθμίσεις κατά polling, επιτυχία/αποτυχία αποθήκευσης, escaping/bullets, πραγματικό ποσοστό λήψης, μη αριθμητική πρόοδος backup, κουμπί Android επιβεβαίωσης και HTML IDs.
- Java στα πραγματικά OTA policy και HTTP: χρόνοι, άδειες/backup, περιορισμένες επαναλήψεις GET, μη επανάληψη 401/POST/PUT, κλείσιμο συνδέσεων, λήψη PDF, ανακατευθύνσεις και Ray diagnostics.
- Πραγματικά Worker routes με συνθετικά D1/R2: ταυτοποίηση, ελαφρύς έλεγχος χωρίς αλλαγή last seen, ανεξάρτητος παλμός και συνέχεια ουράς από αποθηκευμένο δείκτη.
- Πλήρης υπάρχουσα σουίτα service/τιμολογίων/μισθοδοσίας/προγράμματος/OTA, συνθετικά backup/restore, κατασκευή APK και έλεγχος αρχικής υπογραφής, Wrangler dry-run.
- Η λήψη Chromium δεν ήταν διαθέσιμη στο περιβάλλον. Δεν έχουν εκτελεστεί browser screenshots, εγκατάσταση σε φυσική συσκευή, πραγματικό backup ή επεξεργασία δέκα παραγωγικών PDF από τον βοηθό. Το αναφερόμενο HTTP 503 δεν αναπαράχθηκε· το δημόσιο endpoint απάντησε HTTP 200 στον έλεγχο 09/10/2026 22:30 UTC. Η αλλαγή περιορίζει προσωρινά σφάλματα και διορθώνει την κατάσταση σύνδεσης, χωρίς υπόσχεση εξάλειψης κάθε εξωτερικού 503.
