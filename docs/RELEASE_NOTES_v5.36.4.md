# Fleet Control v5.36.4 / Server 2.0.10 / Worker 5.0.39

Η έκδοση βελτιώνει την ανάγνωση των τιμολογίων Impact και προσθέτει ελεγχόμενο χειροκίνητο fallback στο Workers AI.

- Ο Server ανασυνθέτει τα κενά ανάμεσα στις στήλες του Chromium PDF, ώστε κωδικοί, περιγραφές και ποσότητες να μη συγχωνεύονται σε μία ακατάλληλη γραμμή.
- Ο τοπικός αναγνώστης αναγνωρίζει και γραμμές που ξεκινούν απευθείας με περιγραφή, όπως `ΛΑΔΙ`, `ΛΑΣΤΙΧΑ`, `ΣΙΑΓΩΝΕΣ` και `ΑΛΥΣΙΔΑ`, ακόμη κι αν το PDF δεν παρέχει κωδικό στην αρχή της γραμμής.
- Η τοπική ανάγνωση θεωρείται αξιόπιστη μόνο όταν υπάρχουν βασικά στοιχεία τιμολογίου (ημερομηνία, σύνολο και εργασίες). Αν όχι, συνεχίζει αυτόματα στο Workers AI.
- Στην καρτέλα «Τιμολόγια» υπάρχει πλέον το κουμπί `⚡ Workers AI` για χειροκίνητη ανάγνωση ενός συγκεκριμένου PDF. Η ενέργεια καταγράφεται και εμφανίζεται καθαρά ως χειροκίνητο fallback.
- Η ίδια λειτουργία ισχύει για νέα και παλιά τιμολόγια. Η «Νέα ανάγνωση όλων» συνεχίζει να χρησιμοποιεί πρώτα τον τοπικό αναγνώστη του Server και κάνει fallback μόνο όπου χρειάζεται.
- Διατηρείται ο κινούμενος Canvas wiggly progress ring σε Web και Client APK. Δεν προστέθηκε Compose dependency, επειδή η εφαρμογή χρησιμοποιεί WebView.

Εκδόσεις:

- Client APK: `5.36.4`, versionCode `45`.
- Server APK: `2.0.10`, versionCode `13`.
- Web: `5.36.4`.
- Cloudflare Worker runtime: `5.0.39`.
