# Fleet Control v5.30 / Server 2.0.6

## Τι διορθώνει

- Διορθώθηκε σφάλμα στην αρχική φόρτωση του Fleet Control στο Android Client. Η αρχική κάρτα εμφάνιζε 0 μηχανάκια, ενώ το «Σύνολο στόλου» μπορούσε να τα εμφανίσει κανονικά.
- Η ειδοποίηση «μηχανάκια πλησιάζουν το service» είναι πλέον πατήσιμη και ανοίγει τη σχετική λίστα.
- Η ειδοποίηση «μηχανάκια χρειάζονται έλεγχο χιλιομέτρων» είναι πλέον πατήσιμη και ανοίγει μόνο τα μηχανάκια που χρειάζονται έλεγχο.
- Στη λίστα στόλου εμφανίζεται εικονίδιο «Έλεγχος» στις μηχανές χωρίς έλεγχο χιλιομέτρων για τουλάχιστον 7 ημέρες.
- Στις ειδοποιήσεις προστέθηκε «Ολοκλήρωση όλων» για τις απλές ειδοποιήσεις. Αιτήματα διόρθωσης, υπερωρίες και ξεχασμένα Clock Out παραμένουν ανοικτά μέχρι να ελεγχθούν/εγκριθούν.
- Ανεβαίνει η έκδοση cache-busting των Web assets ώστε η διόρθωση να φορτώνεται άμεσα.

## Συμβατότητα

- Client APK: `5.30`, versionCode `34`.
- Server APK: παραμένει `2.0.6`· δεν χρειάζεται νέα εγκατάσταση Server για αυτή τη διόρθωση.
- Δεν αλλάζουν το D1, τα δεδομένα στόλου, το R2, το OCR ή το QR/PDF flow.
