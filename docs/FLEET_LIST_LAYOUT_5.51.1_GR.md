# Fleet ως ενιαίος χώρος και πλήρες περιεχόμενο Server · 5.51.1

Client/Web 5.51.1 (Client versionCode 73), Server 2.2.9 (versionCode 35), Worker 5.12.1.

## Χρήση

- Η συνοπτική λίστα είναι η μοναδική εμφάνιση μηχανών σε Web και APK. Αφαιρούνται τα κουμπιά Καρτών/Λίστας και η παλιά τοπική προτίμηση δεν επηρεάζει πλέον την εμφάνιση.
- Οι γραμμές αξιοποιούν το διαθέσιμο πλάτος. Παραμένουν πινακίδα, τωρινά χιλιόμετρα, επόμενο service και κατάσταση. Η αναζήτηση συνεχίζει να εξισώνει ελληνικά/λατινικά γράμματα, κενά και παύλες.
- Το Fleet χρησιμοποιεί τον χώρο ανάμεσα στην κοινή κεφαλίδα και την κάτω πλοήγηση, χωρίς εξωτερική κάρτα/παράθυρο, διπλά πλαϊνά περιθώρια ή δεύτερη εξωτερική σελίδα που σκρολάρει. Το περιττό χωριστό πλαίσιο διαθεσιμότητας δεν εμφανίζεται κάτω από τη λίστα. Η ανάθεση/κατάσταση μηχανών παραμένει στις Βάρδιες και στους Εργαζομένους.
- Τα εφέ, η καρτέλα μηχανής, το πλήρες ιστορικό, τα PDF, οι επόμενες εργασίες και η επιστροφή στην ίδια θέση διατηρούνται. Η καρτέλα μηχανής και οι οθόνες καταχώρησης συνεχίζουν να αξιοποιούν ολόκληρο το παράθυρο.
- Στον Server όλες οι καρτέλες έχουν αρκετό κάτω χώρο, ώστε να είναι προσβάσιμο όλο το περιεχόμενο πάνω από τη σταθερή πλοήγηση. Το ύψος της μπάρας μετριέται ξανά όταν αλλάζει μέγεθος, γραμματοσειρά ή προσανατολισμός.

## Αιτία και υλοποίηση

Το κοινό stylesheet της 5.51.0 αντικατέστησε το παλιό κάτω περιθώριο `6rem` του Server με `18px` σε κινητό. Η σταθερή μπάρα, περίπου 70px ή περισσότερο με μεγάλες γραμματοσειρές, κάλυπτε το τέλος του περιεχομένου. Η 5.51.1 κρατά πραγματικό ύψος μπάρας συν 24px με ελάχιστο ασφαλές fallback. Το ίδιο μέτρημα καθορίζει τον διαθέσιμο χώρο του Fleet στην εφαρμογή.

Ο κώδικας Fleet παραμένει απομονωμένος σε iframe για να μην αναμιχθούν οι υπάρχουσες φόρμες, τα styles και η αποθήκευσή του με το Portal. Η εμφάνισή του όμως είναι ενιαίος χώρος εφαρμογής: ο γονέας χρησιμοποιεί flex layout και το iframe καταλαμβάνει ακριβώς τον διαθέσιμο χώρο, με έναν χώρο κύλισης. Δεν χρησιμοποιείται μεταβαλλόμενο ύψος ίσο με όλο το περιεχόμενο, ώστε οι διάλογοι και η επιστροφή στην αρχική θέση να παραμένουν σταθερά.

Η μέτρηση μπάρας γίνεται με ResizeObserver και εγγραφή CSS variable μόνο όταν αλλάζει το ύψος. Δεν προστίθεται polling, αίτημα δικτύου ή εργασία σε κάθε scroll.

## Πακέτα και αποθήκευση κώδικα

Η προηγούμενη έκδοση είχε φτάσει 511/512 Web αρχεία ανά OTA manifest λόγω συσσώρευσης immutable snapshots. Η 5.51.1 χρησιμοποιεί κοινή απογραφή (`scripts/web_release_files.py`) για το OTA και το Web ZIP: τρέχουσα έκδοση και δύο δηλωμένες προηγούμενες, μαζί με όλα τα κοινά αρχεία και τον PDF viewer. Η απογραφή αποτυγχάνει αν λείπει απαραίτητο asset από το HTML.

Δεν διαγράφεται κανένα παλιό immutable αρχείο από τον πηγαίο κώδικα ή από το πλήρες Cloudflare ASSETS deployment. Παλιές ανοικτές σελίδες συνεχίζουν να διαβάζουν τα ίδια bytes από τα προηγούμενα URL χωρίς εκτέλεση Worker. Δεν αλλάζουν τα όρια ασφαλείας 512 αρχείων/128 KiB ούτε οι έλεγχοι SHA-256/ατομικής ενεργοποίησης. Τα προηγούμενα R2 releases παραμένουν διαθέσιμα.

Το πλήρες source ZIP περιλαμβάνει όλα τα τμήματα και όλα τα παλιά snapshots. Το φορητό Web ZIP και το OTA manifest περιέχουν ακριβώς την ίδια πλήρη απογραφή της νέας έκδοσης. Για κατασκευή: `python scripts/prepare-pdf-viewer.py`, `python scripts/prepare-static-assets.py`, `bash scripts/check-all.sh` και οι υπάρχουσες οδηγίες Android/OTA. Τα αρχικά signing credentials διατηρούνται ιδιωτικά.

## Έλεγχοι και εγκατάσταση

- Πραγματικές δοκιμές Chromium σε Web/Client, έλεγχοι πλάτους λίστας, ενιαίου viewport, απουσίας επιλογών εμφάνισης και παλιάς προτίμησης «cards».
- Διατηρούνται οι δοκιμές επιστροφής στην ίδια θέση, γρήγορων εναλλαγών, σημειώσεων service και PDF.
- Τέλος και των τεσσάρων καρτελών Server σε 390×844, 320×640 και 844×390, με γραμματοσειρά 100% και 140%.
- Έλεγχος ότι παλιά static URL εξακολουθούν να επιστρέφουν τα αρχικά bytes χωρίς Worker, και ότι ZIP/OTA manifest έχουν κοινή πλήρη απογραφή.
- Κατασκευή των δύο APK και επαλήθευση των αρχικών υπογραφών κατά τη δημοσίευση.

Μετά την επιτυχή δημοσίευση κάνε OTA έλεγχο σε Server και Client. Δεν χρειάζεται απεγκατάσταση. Web/Worker διανέμονται αυτόματα. Δεν αλλάζει το σχήμα, τα χιλιόμετρα, τα κόστη ή τα τιμολόγια. Δεν έχει ληφθεί νέο backup παραγωγικών δεδομένων από τον βοηθό και δεν έχει γίνει φυσική δοκιμή στο S24 Ultra· οι έλεγχοι χρησιμοποιούν συνθετικά δεδομένα.
