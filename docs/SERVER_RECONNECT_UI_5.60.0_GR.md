# Fleet Control 5.60.0 · Server 2.9.0

Η πρώτη σύνδεση μετά την αναβάθμιση γίνεται από Ρυθμίσεις → Ordexa → Στοιχεία σύνδεσης. Η επιλογή αυτόματης επανασύνδεσης αποθηκεύει τα στοιχεία κρυπτογραφημένα με AES/GCM και κλειδί Android Keystore στον ιδιωτικό χώρο fleet_ordexa_secure. Οι παλιές έγκυρες συνεδρίες συνεχίζουν να λειτουργούν, αλλά χρειάζεται μία νέα καταχώριση κωδικού για αυτόματη ανανέωση.

Η ίδια υπηρεσία καλύπτει παρουσίες, προεπισκόπηση, έλεγχο σύνδεσης, καταστήματα και σελίδες παραγγελιών. Σε HTTP401 γίνεται μία σύνδεση και μία επανάληψη ανάγνωσης, με διατήρηση πόλης, αυτόματου συγχρονισμού, generation, receipts, ιστορικού και εργασιών καταστημάτων. Η αμοιβαία εξαίρεση αποφεύγει ταυτόχρονες επανασυνδέσεις. Απόρριψη κωδικού/νέας συνεδρίας σταματά τις προσπάθειες μέχρι νέα επιτυχή καταχώριση. Προσωρινή αστοχία εφαρμόζει επίμονη εκθετική αναμονή30δευτ.–15λεπτά· η επανάληψη γίνεται στον επόμενο επιλέξιμο κύκλο. HTTP403 δεν προκαλεί login. Η αλλαγή λογαριασμού ακυρώνει παλιούς clients πριν από δικτυακή αποστολή και επανεκκινεί την επιλογή πόλης.

Τα στοιχεία και tokens δεν περιλαμβάνονται σε native status, διάγνωση, backup, Cloudflare ή logs. Το Android διατηρεί allowBackup=false και το custom backup εξάγει μόνο τις επιτρεπόμενες γενικές ρυθμίσεις. Η σύνδεση γίνεται στη συσκευή· το Ordexa παραμένει μόνο ανάγνωσης εκτός της απαραίτητης αυθεντικοποίησης.

## Καρτέλες Server

- Κατάσταση: μετρήσεις, συγχρονισμός, τιμολόγια και υγεία συσκευής. Προχωρημένη διάγνωση σε χωριστή ενότητα.
- Αντίγραφα: φάκελος/πρόγραμμα, πάντα ορατή πρόοδος/δημιουργία, χωριστός έλεγχος και επαναφορά με τις υπάρχουσες επιβεβαιώσεις.
- Ενημερώσεις: κύρια ενημέρωση Server, χωριστές χειροκίνητες μεταφορτώσεις και προηγούμενες εκδόσεις. Διατηρούνται οι ωριαίοι έλεγχοι/ασφαλή checkpoints.
- Ρυθμίσεις: Ordexa, Fleet, τιμολόγια, πρόγραμμα αντιγράφων, λειτουργία/ασφάλεια και διαγνωστικά. Διατηρούνται οι τιμές, τα προσχέδια και η προστασία μη φορτωμένων ρυθμίσεων. Η επικύρωση ανοίγει τις κλειστές ενότητες με μη έγκυρα πεδία.

Η εφεδρική πρόσβαση χωρίς D1 δεν φορτώνεται ούτε εμφανίζεται στο Server UI και δεν προσθέτει polling. Δεν διαγράφονται υποκείμενος κώδικας/δεδομένα ή ρυθμίσεις.

Το όριο31 ημερών είναι μέγιστο εύρος ανά αίτημα, όχι χρόνος διατήρησης. Μεγαλύτερο ιστορικό εισάγεται σε διαδοχικά αιτήματα. Ο κανόνας για παραγγελίες που επιβεβαιωμένα απουσιάζουν από το Ordexa, με εξαίρεση διατήρησης ανά κατάστημα default κλειστή, παραμένει ανεξάρτητος.

## Επαλήθευση και παράδοση

Νέοι έλεγχοι: test-ordexa-reconnect-native.mjs, test-server-reconnect-ui.mjs και test-server-reconnect-browser.mjs. Εκτελούνται πραγματικοί OrdexaSync/OrdexaClient και AES/GCM με συνθετικό Keystore/HTTPS, χωρίς παραγωγική πρόσβαση. Καλύπτονται migration, refresh, restart, διατήρηση πηγής/ρυθμίσεων, replay, backoff, λάθος κωδικός,403 και απομόνωση λογαριασμών. Browser έλεγχοι καλύπτουν όλες τις καρτέλες σε320/390/768/1100px και μεγάλα γράμματα.

Τα τοπικά APK έχουν αποκλειστικά δοκιμαστική υπογραφή. Η παραγωγική αρχική υπογραφή χρησιμοποιείται μόνο μέσω του υπάρχοντος ελεγμένου μηχανισμού δημοσίευσης/GitHub Secrets. Δεν έγινε παραγωγικό backup, διαγραφή/restore, αλλαγή Ordexa ή φυσική εγκατάσταση στους τοπικούς ελέγχους. Πλήρες source όλων των τμημάτων, οδηγίες και build inputs διατίθενται στο GitHub/source ZIP. Το source ZIP δεν υποκαθιστά backup παραγωγικών δεδομένων. Αναβάθμιση πάνω στην υπάρχουσα εγκατάσταση· δεν συνιστάται απεγκατάσταση/downgrade.
