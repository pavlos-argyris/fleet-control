FLEET CONTROL — ΕΝΗΜΕΡΩΣΗ 5.36.5 / SERVER 2.0.11

1. Στον Server APK ανέβασε πρώτα το:
   Fleet_Control_Client_v5.36.5.apk

2. Εγκατάστησε το:
   Fleet_Control_Server_v2.0.11.apk

   Έχει versionCode 14 και εγκαθίσταται πάνω από τον Server 2.0.10 χωρίς απεγκατάσταση.

3. Για τον Worker, κράτησε το υπάρχον δικό σου `wrangler.jsonc` με το πραγματικό D1 ID και τα υπάρχοντα bindings. Αντέγραψε μόνο τα νέα `src`, `public` και `package.json`/`package-lock.json` από το πακέτο και βεβαιώσου ότι υπάρχουν τα `SERVICE_DOCS` και `AI` bindings.

4. Στον φάκελο `cloudflare-worker` εκτέλεσε:
   npm install
   npm run deploy

5. Στο τέλος έλεγξε τα bindings `env.DB`, `env.RELEASES`, `env.SERVICE_DOCS`, `env.AI`, `env.ASSETS` και άνοιξε το `/api/status`.

Η νέα ένδειξη του Server εμφανίζεται στην καρτέλα «Κατάσταση» όταν υπάρχει ενεργή ή πρόσφατα ολοκληρωμένη νέα ανάγνωση τιμολογίων.

Η μαζική ανάγνωση επεξεργάζεται πλέον τα τιμολόγια διαδοχικά στον ίδιο κύκλο, οπότε δεν περιμένει 30″ μεταξύ δύο αρχείων. Η ρύθμιση συγχρονισμού συνεχίζει να επηρεάζει τους υπόλοιπους συγχρονισμούς.
