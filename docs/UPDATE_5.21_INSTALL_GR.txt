FLEET CONTROL 5.21 — ΟΔΗΓΙΕΣ ΕΓΚΑΤΑΣΤΑΣΗΣ

1. WEB / WORKER

Αντέγραψε τα περιεχόμενα του Fleet_Control_Web_Update_v5.21.zip στον φάκελο:
cloudflare-worker/public

Αντέγραψε από το πακέτο ανάπτυξης τα αρχεία:
cloudflare-worker/src/workforce.js
cloudflare-worker/src/workforce-core.js
cloudflare-worker/src/worker.js
cloudflare-worker/package.json

Μην αντικαταστήσεις το πραγματικό wrangler.jsonc. Πρέπει να παραμείνουν τα δικά σου database_id, D1 binding, R2 binding και assets binding.

Στον φάκελο cloudflare-worker εκτέλεσε:
npm install
npm run deploy

Η αναβάθμιση της βάσης είναι additive. Δεν κάνει DROP, reset ή διαγραφή δεδομένων.

2. ANDROID CLIENT

Στο Server → Ενημερώσεις ανέβασε το:
Fleet_Control_Client_v5.21.apk

Διάλεξε Client release και κάν’ το ενεργό. Οι συσκευές με ενεργό auto-update θα εμφανίσουν την εσωτερική ενημέρωση. Εναλλακτικά εγκατέστησε το APK χειροκίνητα πάνω από την προηγούμενη έκδοση.

3. ΝΕΕΣ ΡΥΘΜΙΣΕΙΣ ΜΙΣΘΟΔΟΣΙΑΣ

Μισθοδοσία → Κανόνες πληρωμής:
- Κανονική αμοιβή: €6/ώρα.
- Πρόσθεσε ζώνη 00:00–01:00 με €10/ώρα.
- Πρόσθεσε ζώνη 01:00–02:00 με €15/ώρα.
- Ρύθμισε την ανοχή καθυστερημένου Clock In και τη στρογγυλοποίηση έναρξης.

Οι βάρδιες που τελειώνουν μετά το πρόγραμμά τους εμφανίζονται ως υπερωρίες προς έγκριση. Μέχρι την έγκριση πληρώνονται μόνο μέχρι την προγραμματισμένη λήξη. Από την Έγκριση μπορείς να αφήσεις τις ζώνες του κανόνα ή να δώσεις άλλη τιμή €/ώρα.

4. ΕΛΕΓΧΟΣ

Έλεγξε μία δοκιμαστική βάρδια 15:20–01:30 με πρόγραμμα 15:00–01:00:
- με ανοχή 0 και στρογγυλοποίηση προς τα πάνω ανά 30 λεπτά, το Clock In υπολογίζεται από 15:30,
- χωρίς έγκριση πληρώνεται έως 01:00,
- μετά την έγκριση υπολογίζεται και το 01:00–01:30,
- η μισθοδοσία εμφανίζει τον εγκρίνοντα και την ώρα έγκρισης.
