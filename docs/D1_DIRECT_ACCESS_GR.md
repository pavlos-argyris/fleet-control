# Εφεδρική πρόσβαση στον Server — υποψήφια 5.58.0 / Server2.7.0

## Τι λειτουργεί χωρίς D1

Η νέα εφεδρική είσοδος ελέγχει τον προσωπικό κωδικό στο κινητό Server και δημιουργεί τοπική συνεδρία στην ιδιωτική SQLite. Ο Client/Web επικοινωνεί με το κινητό μέσω ασφαλούς εξερχόμενου WebSocket. Δεν χρειάζεται δημόσια IP, άνοιγμα θυρών router ή εγκατάσταση VPN. Το υπάρχον Cloudflare Durable Object μεταφέρει μόνο κρυπτογραφημένα πακέτα· δεν εκτελεί ερωτήματα D1 και δεν αποθηκεύει τα σώματα αιτημάτων/αποκρίσεων. Η φυσική σύζευξη καρφιτσώνει την ταυτότητα του Server (ECDH P-256/AES-GCM ανά αίτημα). Κωδικοί, tokens και επιχειρησιακά δεδομένα αποκρυπτογραφούνται μόνο στα δύο άκρα, όχι στο relay.

Η παρούσα αλλαγή παρέχει **είσοδο και προβολή**, με τα υφιστάμενα δικαιώματα λογαριασμού:

- Μηχανάκια και βασικά στοιχεία συντήρησης.
- Εργαζόμενους χωρίς κωδικούς, hashes ή εσωτερικά πεδία ασφάλειας.
- Αποθηκευμένο πρόγραμμα, με τα ονόματα των εργαζομένων.
- Αρχικές παρουσίες Ordexa από την ενεργή πόλη, με αμετάβλητα Clock In/Out.
- Καταστήματα της ενεργής σύνδεσης και ημερήσια αποτελέσματα μόνο από ολοκληρωμένη δημοσίευση, με συμβατή έκδοση καταστήματος. Ατελή/παλιά staging rows δεν εμφανίζονται ως έτοιμες χρεώσεις.

Οι συνηθισμένες καταχωρίσεις/διορθώσεις, οι εισαγωγές Ordexa, η μισθοδοσία και η κανονική cloud εφαρμογή **δεν μεταφέρονται όλες σε αυτή την έκδοση**. Συνεχίζουν να απαιτούν τις υπάρχουσες υπηρεσίες/D1. Δεν υπάρχει ακόμη ουρά τοπικών επιχειρησιακών αλλαγών με επανασυγχρονισμό/CAS. Γι' αυτό οι επιχειρησιακές εγγραφές στην εφεδρική διαδρομή απορρίπτονται ρητά. Η πλήρης ανεξαρτησία και η επιτάχυνση εισαγωγής παραμένουν ανοικτές στα #52/#51.

## Πρώτη ρύθμιση

1. Μετά την επιβεβαιωμένη δημοσίευση, εγκατάστησε την κανονική ενημέρωση **Server2.7.0** και έπειτα **Client5.58.0**. Οι αρχικές υπογραφές διατηρούνται από το υπάρχον release workflow. Δεν χρειάζεται απεγκατάσταση.
2. Στον Server άνοιξε **Ρυθμίσεις → Εφεδρική πρόσβαση χωρίς D1 → Ενεργοποίηση**. Η υπηρεσία Server πρέπει να λειτουργεί.
3. Επίλεξε **Κοινοποίηση σύνδεσης**, ή αντέγραψε τον κωδικό σύζευξης. Το link περιέχει τον κωδικό στο fragment (`#pair=`), που αφαιρείται από τη διεύθυνση μόλις διαβαστεί και δεν αποστέλλεται ως URL στον Worker.
4. Στο Client άνοιξε **Εφεδρική πρόσβαση στον Server χωρίς D1** από τη σελίδα σύνδεσης. Στο Web είναι διαθέσιμο το `/direct.html`, ακόμη και όταν η κανονική σελίδα δεν φορτώνει λόγω D1.
5. Διατήρησε σωστή αυτόματη ημερομηνία/ώρα στις δύο συσκευές. Συμπλήρωσε ολόκληρο τον κωδικό σύζευξης και τον υπάρχοντα προσωπικό λογαριασμό Fleet. Ο κωδικός σύζευξης δεν υποκαθιστά το username/password και δεν δίνει ρόλο Owner.

Η πρώτη σύνδεση/προβολή χρειάζεται πραγματικά ολοκληρωμένο τοπικό αντίγραφο χρηστών και δικαιωμάτων. Αν δεν υπάρχει, δεν δημιουργείται αυτόματα νέος διαχειριστής. Εμφανίζεται σαφές μήνυμα στον χρήστη.

## Φρεσκάδα και ανάκληση

- Κάθε προβολή αναφέρει την ώρα του τοπικού αντιγράφου. Δεν χαρακτηρίζεται τρέχουσα εικόνα παραγωγής.
- Για την εξουσιοδότηση απαιτείται επιτυχές αντίγραφο των τελευταίων **24 ωρών**. Παλαιότερο ή μη έγκυρο αντίγραφο απορρίπτεται. Αυτό περιορίζει το διάστημα άγνωστων ανακλήσεων όταν το cloud δεν είναι προσβάσιμο.
- Η ταυτότητα Server δημιουργείται στη φυσική συσκευή, σφραγίζεται με AndroidKeyStore σε χωριστές ιδιωτικές ρυθμίσεις και δεν εξάγεται στο data backup. Μετά από μεταφορά/επαναφορά σε άλλη συσκευή χρειάζεται νέα σύζευξη. Η αρχική υπογραφή APK και το υφιστάμενο server key δεν αλλάζουν.
- Οι τοπικές συνεδρίες ισχύουν έως **4 ώρες**, με ανώτατη λήξη στο όριο των24ωρών του αντιγράφου. Αποθηκεύονται μόνο hashes των τυχαίων tokens, όχι προσωπικοί κωδικοί.
- Ο Server επανελέγχει ενεργό λογαριασμό, ενεργοποιημένη είσοδο, διαγραφή, αλλαγή κωδικού, `force_logout_after` και τρέχοντα τοπικά δικαιώματα σε κάθε αίτημα. Μια αλλαγή cloud γίνεται γνωστή όταν ολοκληρωθεί νέο αντίγραφο· δεν υπόσχεται άμεση ανάκληση χωρίς επικοινωνία.
- Η απενεργοποίηση στη φυσική συσκευή Server ανακαλεί τις τοπικές συνεδρίες και αλλάζει τον κωδικό σύζευξης. Κάθε νέα ενεργοποίηση επίσης δημιουργεί νέο κωδικό.
- Κάθε κρυπτογραφημένο αίτημα έχει βραχύ χρόνο ισχύος και μοναδικό αναγνωριστικό. Επαναλήψεις απορρίπτονται και μετά από restart. Μια λάθος ταυτότητα Server ή αλλοίωση ciphertext απορρίπτεται πριν από το login.
- Οι τοπικές είσοδοι/αποτυχίες/αποσυνδέσεις και απορρίψεις δικαιωμάτων καταγράφονται σε περιορισμένο ιδιωτικό αρχείο SQLite έως500 συμβάντων. Δεν αντιγράφονται στη D1.
- Αποτυχημένες προσπάθειες περιορίζονται ανά λογαριασμό και συνολικά. Ο μηχανισμός παραμένει ενεργός μετά από επανεκκίνηση.

## Υποδομή, πόροι και παράδοση

Χρησιμοποιείται το ήδη υπάρχον `FLEET_EVENTS` Durable Object· δεν προστίθεται νέα υπηρεσία/συνδρομή ή νέα migration κλάσης. Η εφεδρική διαδρομή έχει **μηδενικά ερωτήματα/εγγραφές D1**, αλλά εξακολουθεί να καταναλώνει αιτήματα/μεταφορά και ενδεχόμενη ενεργή εκτέλεση Cloudflare για το relay. Το heartbeat χρησιμοποιεί την ήδη ρυθμισμένη WebSocket auto-response/hibernation. Η SQLite προβάλλει μόνο τους αναγκαίους πίνακες/σελίδες· η είσοδος δεν υλοποιεί όλο το JSON ιστορικού/παραγγελιών στη Java μνήμη. Δεδομένα και ώρα αντιγράφου διαβάζονται ατομικά. Ο Server αναλαμβάνει PBKDF2, συνεδρίες, εξουσιοδότηση, επιλογή/μορφοποίηση δεδομένων και σελιδοποίηση.

Η υπηρεσία απαιτεί Internet και στα δύο κινητά. Απουσία Server επιστρέφει503. Διακοπή/λήξη προθεσμίας εμφανίζεται ρητά· δεν γίνεται αυτόματη επανάληψη login ή επιχειρησιακής ενέργειας. Τα tokens της κανονικής σύνδεσης δεν αντικαθίστανται από τις εφεδρικές συνεδρίες.

Η υπάρχουσα παραγωγή/ενεργοποίηση εκδόσεων και η παλιά διανομή ενημερώσεων εξακολουθούν να εξαρτώνται από D1. Αν η D1 έχει ήδη εξαντληθεί κατά τη δημοσίευση, η ενεργοποίηση πρέπει να περιμένει την επαναφορά διαθεσιμότητάς της. Αυτό δεν παρακάμπτεται με μη ελεγμένη ενεργοποίηση.

Τα source ZIP περιλαμβάνουν όλα τα τμήματα, scripts και οδηγίες. Δεν αποτελούν backup πραγματικών δεδομένων. Δεν λήφθηκε παραγωγικό backup/restore και δεν έγινε εγκατάσταση ή πραγματική σύνδεση μεταξύ των φυσικών κινητών από τον βοηθό. Η τελική ενεργοποίηση/υπογραφές/CI αναφέρονται χωριστά στο κοινό handoff μόνον όταν επιβεβαιωθούν.
