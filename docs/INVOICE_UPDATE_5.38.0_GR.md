# Ενημέρωση 5.38.0 — τιμολόγια service

Εκδόσεις: Client/Web 5.38.0, Client code 49, Server 2.1.2/code 18, Worker 5.2.0. Τα APK έχουν τα ίδια package names και υπογράφονται με το αρχικό πιστοποιητικό. Δεν αλλάζει η δομή D1 ή τα υπάρχοντα κλειδιά.

## Τι διορθώθηκε

1. Η καρτέλα service και οι πλήρεις αναφορές αθροίζουν το κόστος κάθε συνημμένου τιμολογίου. 9 € και 50 € δίνουν 59,00 €. Το συνοπτικό invoiceData και το χειροκίνητο συνολικό κόστος δεν προστίθενται ξανά στα ίδια τιμολόγια. Το χειροκίνητο κόστος παραμένει fallback όταν δεν έχει διαβαστεί κανένα επιμέρους ποσό. Αν λείπει ποσό από κάποιο συνημμένο, εμφανίζεται επισήμανση εκκρεμότητας δίπλα στο γνωστό άθροισμα. Προτιμώνται τα ελεγμένα στοιχεία του συγκεκριμένου αρχείου από τα παλαιότερα QR στοιχεία του.
2. Οι όροι/τρόπος πληρωμής και το «Τοίς Μετρητοίς» αφαιρούνται από τις εργασίες σε Server, Worker, Web και Client. Αν η φράση έχει προστεθεί στο τέλος μιας πραγματικής εργασίας, διατηρείται η εργασία. Το πλήρες αρχικό κείμενο OCR παραμένει διαθέσιμο για έλεγχο.
3. Η «Κράτηση στο τρέχον» καταγράφει ρητή επιβεβαίωση χρήστη για τη συγκεκριμένη πινακίδα και το συγκεκριμένο μηχανάκι. Η προειδοποίηση πινακίδας αφαιρείται, το τιμολόγιο μπαίνει στα Ολοκληρωμένα όταν δεν υπάρχει άλλη ανεπίλυτη διαφορά και εμφανίζεται μικρή ένδειξη «Διορθώθηκε από χρήστη». Η αρχική ανάγνωση δεν διαγράφεται. Νέα διαφορετική πινακίδα ή σύνδεση με άλλο μηχανάκι δεν κληρονομεί την παλιά αποδοχή.
4. Η αυτόματη ανάγνωση δέχεται τρία γράμματα από ΑΒΕΖΗΙΚΜΝΟΡΤΥΧ/τα αντίστοιχα λατινικά και 3–4 ψηφία, με σαφή αναφορά πινακίδας/κυκλοφορίας ή σχολίων. Κωδικοί ειδών/μοντέλων/παραστατικών απορρίπτονται. ΞΝ-131, ADE-6472 και SH-125 δεν αναγνωρίζονται ως πινακίδες. Κενά, παύλες, πεζά/κεφαλαία και ομόμορφα ελληνικά/λατινικά θεωρούνται ίδια. Ανοχή ενός γράμματος εφαρμόζεται μόνο με σαφή συμφραζόμενα, ίδια ψηφία και ένα μοναδικό κοντινό μηχανάκι του στόλου. Υπαρκτή άλλη πινακίδα ή αμφιβολία δεν διορθώνεται αυτόματα. Τα ψηφία δεν μαντεύονται. Μη τυπικές πινακίδες μπορούν να καταχωριστούν/επιβεβαιωθούν χειροκίνητα.
5. Στον Έλεγχο/διόρθωση, όταν τα χιλιόμετρα τιμολογίου διαφέρουν, η αποθήκευση ζητά επιβεβαίωση παλιάς → νέας τιμής. Ακύρωση δεν αποθηκεύει αλλαγή. Αποδοχή ενημερώνει το χειροκίνητο service και επανυπολογίζει τις ενδείξεις ιστορικού/λαδιών/μεγάλου service, διατηρώντας τα μεταγενέστερα km ιστορικού και το όριο από βάρδιες. Καταγράφονται παλιά/νέα τιμή και ο ελεγκτής. Αν το service αλλάξει ταυτόχρονα, απαιτείται νέος έλεγχος αντί για σιωπηλή αντικατάσταση. Όλα τα τιμολόγια του ίδιου service βλέπουν τη νέα τιμή.
6. Στο πλήρες ιστορικό/αναφορά PDF η στήλη Ημερομηνία δείχνει πρώτα την ημερομηνία service που καταχώρισες. Ακριβώς από κάτω εμφανίζονται οι ημερομηνίες τιμολογίων με την ένδειξη «Τιμολόγιο:». Η ημερομηνία service δεν αντικαθίσταται από OCR.

Οι επιβεβαιωμένες διορθώσεις διατηρούνται σε νέο έλεγχο τιμολογίου και συγχρονισμό. Η επιβεβαίωση ενός τιμολογίου δεν κρύβει διαφορετική ανεπίλυτη προειδοποίηση σε άλλο τιμολόγιο.

## Διάθεση / εγκατάσταση

Χρειάζονται ενημέρωση **Server, Client, Web και Worker**. Ο Worker περιλαμβάνει τους ελέγχους/αποθήκευση, ο Server τη νέα τοπική ανάγνωση και ο Client/Web την εμφάνιση και επιβεβαίωση. Η [αυτόματη δημοσίευση](AUTOMATIC_PUBLISH_GR.md) τα διαθέτει μαζί όταν δοθεί η ρητή εντολή «δημοσίευσε την έκδοση 5.38.0». Το συνηθισμένο push αποθηκεύει πηγές και τρέχει ελέγχους.

1. Κράτησε εξωτερικό backup Server πριν από την ενημέρωση. Η τοπική συνθετική δοκιμή restore δεν είναι backup της παραγωγής.
2. Μετά την επιτυχή δημοσίευση, ο Server λαμβάνει το 2.1.2 με την υπάρχουσα διαδικασία OTA/backup. Αν ζητηθεί επιβεβαίωση Android, ολοκλήρωσέ την στη συσκευή. Χειροκίνητα εγκαθιστάς το νέο APK πάνω στο υπάρχον.
3. Οι Clients ενημερώνονται σε 5.38.0 από τον έλεγχο ενημερώσεων. Το Web φορτώνει τη νέα έκδοση/cache. Δεν απεγκαθιστάς την εφαρμογή για κανονικό update.
4. Σε υπάρχον τιμολόγιο με λάθος πινακίδα πάτησε Έλεγχος/διόρθωση και Κράτηση στο τρέχον. Σε λάθος km επιβεβαίωσε τη διόρθωση όταν εμφανιστεί το σχετικό μήνυμα. Για παλιές αναγνώσεις που χρειάζονται βελτίωση μπορείς να ζητήσεις νέα ανάγνωση.

Για ανάπτυξη από άλλο εργαλείο χρησιμοποίησε το πλήρες source ZIP ή clone του GitHub, τα [build instructions](BUILD_AND_HANDOFF_GR.md) και το ξεχωριστό ιδιωτικό αντίγραφο αρχικής υπογραφής. Για Worker deploy χρησιμοποιούνται τα ίδια υπάρχοντα D1/R2 bindings και secrets. Δεν δημιουργείς νέα βάση ή νέα υπογραφή. Το πακέτο αρχείων περιλαμβάνει τα υπογεγραμμένα APK, Web ZIP, Worker ZIP, manifest και SHA-256· η δημοσίευση μέσω workflow είναι η ενιαία διαδικασία ενεργοποίησής τους.

## Έλεγχοι

- Τοπικές δοκιμές Worker/API/συγχρονισμού και προσομοιώσεις διαχείρισης: δύο τιμολόγια, κόστος/ημερομηνίες ανά αρχείο, αποδοχή πινακίδας, ολοκλήρωση, διόρθωση km, απόρριψη stale επιβεβαίωσης και διατήρηση χειροκίνητων επιλογών μετά από reprocess.
- Εκτέλεση των πραγματικών Java μεθόδων του LocalInvoiceReader για συμφραζόμενα πινακίδων, απόρριψη των τριών παραδειγμάτων και αφαίρεση πληρωμής από τον parser εργασιών.
- Δοκιμές του κώδικα Web/Portal για 9+50=59, ακρίβεια λεπτών, QR/OCR προτεραιότητα, διατήρηση διαφορετικών ημερομηνιών και επιβεβαίωση/ακύρωση διόρθωσης km.
- Υπάρχοντες έλεγχοι service/QR στο background, βαρδιών, μισθοδοσίας, διαχείρισης, OTA/atomic activation και συνθετικό backup/restore 27 πινάκων.
- Build και έλεγχος αρχικής υπογραφής/package/version των δύο APK. Τα πραγματικά τιμολόγια του χρήστη και η εγκατάσταση στη συσκευή απαιτούν έλεγχο μετά τη διάθεση. Η OCR αναγνώριση δεν είναι αλάνθαστη.
- Τα στατικά UI checks πέρασαν. Δεν εκτελέστηκαν browser screenshots, επειδή το περιβάλλον δεν διαθέτει Chromium. Δεν έγινε παραγωγικό deploy από την απλή αλλαγή κώδικα.
