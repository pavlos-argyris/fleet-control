# Fleet Control v5.33 / Server 2.0.8

## Νέα έκδοση

- Η δημιουργία PDF από QR ενημερώνει πλέον στάδιο, ποσοστό, χρόνο, προσπάθειες και τελευταίο σφάλμα.
- Ο Server επαναλαμβάνει προσωρινά την εργασία έως τρεις φορές. Μετά εμφανίζεται ασφαλές κουμπί «Επανάληψη» στο ιστορικό και στο Admin Panel.
- Το ιστορικό service και η καρτέλα τιμολογίων εμφανίζουν ομαλό, κινούμενο progress ring αντί για στατικό μήνυμα.
- Τα νέα τιμολόγια έχουν ένδειξη `ΝΕΟ` μέχρι να ανοιχτούν για έλεγχο και κατόπιν ταξινομούνται ανά μηχανάκι και χιλιόμετρα.
- Διορθώθηκε η εμφάνιση γραμμών OCR που έφταναν ως αντικείμενα και γίνονταν `[object Object]`.
- Η εξαγωγή πλήρους ιστορικού στόλου μεταφέρθηκε στο τέλος της σελίδας Μηχανάκια και η επιλογή πολλών μηχανών έγινε με κάρτες, επιλογή όλων και μετρητή.
- Η νέα web cache έκδοση είναι `5.33`.

## Εκδόσεις

- Cloudflare Worker: `5.0.33`
- Web / Client APK: `5.33` (versionCode `37`)
- Server APK: `2.0.8` (versionCode `11`)

## Σημαντικό

Πριν από deploy ή εγκατάσταση κράτησε backup. Μην αντικαταστήσεις τυφλά το υπάρχον `wrangler.jsonc`: κράτησε το πραγματικό D1 ID και τα παραγωγικά bindings. Το APK Server `2.0.8` πρέπει να εγκατασταθεί πριν δοκιμαστεί η νέα ροή QR.
