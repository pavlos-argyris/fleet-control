# Fleet Control v5.32 / Server 2.0.7

## Τι αλλάζει

- Το ιστορικό service και τα εξαγόμενα ιστορικά PDF ταξινομούνται ανά μηχανάκι με φθίνουσα σειρά χιλιομέτρων, ανεξάρτητα από τη σειρά μεταφόρτωσης.
- Οι εργασίες από το τιμολόγιο μεταφέρονται στη στήλη «Εργασίες», εμφανίζονται με bullets και deduplicate· οι εργασίες λαδιών συγχωνεύονται σε μία γραμμή με την ακριβή ονομασία προϊόντος.
- Η καρτέλα «Τιμολόγια service» ομαδοποιεί ανά πινακίδα, έχει φίλτρο πινακίδας και διαδραστικές κάρτες κατάστασης.
- Σε διαφορετική πινακίδα, ο Admin μπορεί να μεταφέρει το τιμολόγιο σε άλλο service ή να το κρατήσει στο τρέχον, με καταγραφή Audit Log.
- Το QR/new service κλείνει αμέσως το παράθυρο και η δημιουργία/ανάγνωση PDF συνεχίζει στο παρασκήνιο.
- Το backup περιλαμβάνει πλέον manifest και τα τοπικά PDF/εικόνες τιμολογίων. Η επαναφορά τα αποκαθιστά τοπικά και τα ανεβάζει ξανά στο ιδιωτικό R2.
- Το Worker χρησιμοποιεί Wrangler 4.148.0 με override του sharp 0.35.5· ο τελικός έλεγχος npm audit --audit-level=high δεν επέστρεψε vulnerabilities.

## Εκδόσεις

- Cloudflare Worker: `5.0.32`
- Web / Client APK: `5.32` (versionCode `36`)
- Server APK: `2.0.7` (versionCode `10`)

## Σημαντικό

Πριν από deploy ή εγκατάσταση κράτησε χειροκίνητο backup. Κράτησε το υπάρχον `wrangler.jsonc`, το D1 ID, τα secrets και τα bindings. Το Server APK `2.0.7` πρέπει να εγκατασταθεί πριν δοκιμαστεί επαναφορά backup με τιμολόγια.
