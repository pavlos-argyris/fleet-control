# Fleet Control 5.49.0 — κίνηση και επιστροφή στη λίστα

Client/Web 5.49.0 (64), Worker 5.10.2. Ο Server παραμένει 2.2.5 (31), χωρίς αλλαγές APK.

- Πατώντας μια κάρτα δικύκλου στη λίστα, η αναλυτική προβολή αναπτύσσεται από τη θέση της με στρογγυλεμένο περίγραμμα. Στην επιστροφή συρρικνώνεται προς την κάρτα. Η μετάβαση διαρκεί 220 ms και δεν χρησιμοποιεί σβήσιμο διαφάνειας.
- Αποθηκεύονται η θέση κύλισης, η ταυτότητα του επιλεγμένου δικύκλου και η θέση της κάρτας στην οθόνη. Το «Πίσω» επαναφέρει την ίδια κάρτα, ακόμη και αν προηγούμενες κάρτες άλλαξαν ύψος. Αν η κάρτα αφαιρέθηκε, επαναφέρεται η προηγούμενη θέση όσο επιτρέπει η λίστα.
- Η επαναφορά καλύπτει το κουμπί της καρτέλας και το ιστορικό browser/Android. Η αυτόματη κύλιση του browser απενεργοποιείται μόνο στο έγγραφο Fleet. Η αρχική λίστα δεν αναδημιουργείται μέσω νέας πλοήγησης Portal.
- Στο ενσωματωμένο Fleet η μετάβαση εκτελείται στο εξωτερικό έγγραφο, ώστε η αλλαγή ύψους του iframe να μη διακόπτει την κίνηση. Ο Portal κρατά τη δική του θέση κύλισης και ενημερώνει το Fleet μετά την επαναφορά της διάταξης.
- Dashboard, Βάρδιες, Εργαζόμενοι και οι υπόλοιπες επιτρεπόμενες ενότητες αποκτούν ολίσθηση 22 px / 190 ms, με κατεύθυνση ανάλογη της σειράς πλοήγησης. Η κάτω μπάρα παραμένει σταθερή. Αρχική φόρτωση και επανεπιλογή της ίδιας ενότητας δεν προσθέτουν κίνηση.
- Η «Μείωση κίνησης» της συσκευής παραλείπει τα εφέ, διατηρώντας την επαναφορά θέσης. Browser χωρίς View Transitions χρησιμοποιεί κανονική άμεση πλοήγηση. Γρήγορη επόμενη ενέργεια ολοκληρώνει την προηγούμενη αλλαγή μία φορά και ακυρώνει το προηγούμενο εφέ.

## Έλεγχοι

`bash scripts/check-all.sh` περιλαμβάνει πραγματικά DOM clicks και Back/Forward, θέση με βάση την κάρτα, εστίαση, διακοπή μετάβασης, καθαρισμό προσωρινών ονομάτων, μειωμένη κίνηση και απουσία API. Διατηρούνται οι προηγούμενοι έλεγχοι service, τιμολογίων, μισθοδοσίας, συγχρονισμού και backup.

Το `node scripts/test-navigation-motion-browser.mjs` είναι υποχρεωτικό CI/publish gate. Εκτελεί το παραδιδόμενο HTML/CSS/JS σε πραγματικό Chromium με 35 συνθετικά δίκυκλα, σε αυτόνομο και ενσωματωμένο Fleet, στα τοπικά αρχεία του Client μέσω file URL και σε μειωμένη κίνηση. Ελέγχει πραγματικό clip animation, απουσία opacity fade, επαναφορά κάρτας με ανοχή 3 px, Back από το ιστορικό, σταθερή κάτω μπάρα χωρίς οριζόντια υπερχείλιση και διαδοχικές επιλογές. Αποθηκεύει εικόνες και αποτελέσματα ως artifact `navigation-motion-verification`.

Δεν χρησιμοποιούνται παραγωγικά δεδομένα ή πραγματικές μεταβολές στη δοκιμή browser. Η αίσθηση της κίνησης στη φυσική Samsung/WebView επιβεβαιώνεται στη συσκευή. Το τοπικό περιβάλλον δεν διαθέτει Chromium και η λήψη του πακέτου browser δεν ολοκληρώθηκε· ο πραγματικός browser έλεγχος εκτελείται στο GitHub CI.

## Εγκατάσταση και ανάκτηση

Ενημέρωσε τον Client σε 5.49.0 από τον έλεγχο ενημερώσεων, πάνω στην υπάρχουσα εφαρμογή. Worker/Web δημοσιεύονται από το εξουσιοδοτημένο workflow. Δεν απαιτείται εγκατάσταση νέου Server APK. Οι αλλαγές αφορούν πλοήγηση/παρουσίαση και δεν αλλάζουν σχήμα ή περιεχόμενο δεδομένων.

Πριν από ενημερώσεις κράτησε το συνηθισμένο backup Server εκτός εφαρμογής. Η δημοσίευση δεν λαμβάνει από μόνη της backup παραγωγικών δεδομένων. Πηγή όλων των τμημάτων, build inputs, APK, checksums και οδηγίες διατίθενται στο GitHub release. Τα ιδιωτικά κλειδιά παραμένουν εκτός αποθετηρίου.
