# Fleet Control 5.24

## Τιμολόγια service

- Προσθήκη τιμολογίου σε νέο ή παλιό service.
- Υποστήριξη PDF, JPG, PNG και WEBP έως 15 MB.
- Ιδιωτική αποθήκευση σε ξεχωριστό R2 bucket.
- Προβολή τιμολογίου μέσα από το ιστορικό.
- Τοπικό mirror στον Server APK και κρυπτογραφημένο archive στο Google Drive backup.
- OCR εικόνων με Workers AI ως προσχέδιο που χρειάζεται επιβεβαίωση admin.
- Εξαγωγή ιστορικού service σε PDF για ένα ή περισσότερα μηχανάκια.

## Έλεγχοι

Πέρασαν οι Worker, schedule, payroll, admin simulation και static Web UI έλεγχοι. Browser screenshots δεν εκτελέστηκαν επειδή το περιβάλλον build δεν περιείχε Chromium.
