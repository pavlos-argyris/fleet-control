# Fleet Control 5.36.6 / Server 2.0.12 / Worker 5.0.41

## Νέα ρύθμιση

- Ο Server APK επιτρέπει ρύθμιση παράλληλης επεξεργασίας τιμολογίων από 1 έως 10.
- Προεπιλογή: 4 ταυτόχρονα τιμολόγια, προτεινόμενη για Samsung S24 Ultra.
- Η τοπική λήψη/OCR γίνεται παράλληλα, ενώ η καταχώρηση στον κοινό snapshot γίνεται σειριακά για αποφυγή συγκρούσεων.
- Η οθόνη κατάστασης εμφανίζει τα ενεργά τιμολόγια και το στάδιο της παράλληλης ανάγνωσης.

## Εκδόσεις

- Server APK: `2.0.12`, versionCode `15`.
- Cloudflare Worker runtime: `5.0.41`.

Για το S24 Ultra προτείνεται αρχικά η τιμή 4. Οι τιμές 6–10 είναι turbo επιλογές και πρέπει να δοκιμάζονται σταδιακά.
