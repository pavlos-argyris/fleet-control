# Ξεχωριστή ενημέρωση αντιγράφου προσωπικού

Η 5.51.5 / Server 2.2.13 δημοσιεύθηκε και ενεργοποιήθηκε πριν ξεκινήσει η διάγνωση, σύμφωνα με την εντολή του χρήστη.

Η αιτία του HTTP 500 αναπαράχθηκε στη διαφορική λήψη: D1_ERROR: too many terms in compound SELECT: SQLITE_ERROR. Η διόρθωση της 5.51.6 αποφεύγει το UNION ALL και διατηρεί όλες τις εγγραφές και τους δείκτες λήψης.

Αναλυτική περιγραφή, έλεγχοι, εγκατάσταση και όρια: [MIRROR_HTTP500_5.51.6_GR.md](MIRROR_HTTP500_5.51.6_GR.md).
