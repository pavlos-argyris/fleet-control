# Fleet Control v5.36

## Κοινή πρόοδος νέας ανάγνωσης τιμολογίων

- Client APK: `5.36` με versionCode `41`.
- Web: `5.36` με νέο cache key.
- Worker: `5.0.35`.
- Η «Νέα ανάγνωση όλων» δημιουργεί κοινή batch εργασία στον Worker.
- Web και APK ενημερώνουν την ίδια πρόοδο από τον D1 περίπου ανά δευτερόλεπτο.
- Όλες οι συνδέσεις εμφανίζουν ταυτόχρονα `x/y`, ποσοστό, τρέχον τιμολόγιο, χρόνο και σφάλματα.
- Ο κύκλος έχει κινούμενη φωτεινή διαδρομή/zig-zag όσο η εργασία βρίσκεται σε εξέλιξη.

## Μεμονωμένο QR / τιμολόγιο

- Κάθε νέο QR που αποθηκεύεται εμφανίζεται και στις άλλες ανοιχτές συνδέσεις στην καρτέλα «Τιμολόγια» χωρίς χειροκίνητο refresh.
- Η πρόοδος του μεμονωμένου PDF ανανεώνεται ζωντανά από τον Worker και ο ατομικός κύκλος έχει το ίδιο κινούμενο φωτεινό zig-zag εφέ.
- Η ενημέρωση συνεχίζεται μέχρι να δημιουργηθεί το PDF ή να εμφανιστεί σφάλμα/«Επανάληψη».
- Προστέθηκε ασφαλής κανονικοποίηση ποσοστού, ώστε παλιές ή μη έγκυρες τιμές να εμφανίζονται ως κανονικό ποσοστό και όχι ως `NaN%`.

## Ασφάλεια και συμπεριφορά

- Επιτρέπεται μία ενεργή μαζική νέα ανάγνωση κάθε φορά, ώστε να μη γίνονται διπλές επεξεργασίες.
- Αν η σύνδεση που ξεκίνησε τη διαδικασία σταματήσει να ενημερώνει για 20 λεπτά, η εργασία χαρακτηρίζεται ως σφάλμα και μπορεί να ξαναξεκινήσει.
