# Fleet Control v5.35

## Αλλαγή Client APK

- Ο Client ελέγχει για ενημέρωση στην εκκίνηση.
- Ελέγχει ξανά όταν επιστρέφει στο προσκήνιο.
- Όσο παραμένει ανοιχτός, επαναλαμβάνει τον έλεγχο κάθε 15 λεπτά.
- Αν η εφαρμογή μείνει στο παρασκήνιο, ο περιοδικός έλεγχος σταματά και συνεχίζεται στην επόμενη επιστροφή.
- Το prompt της ίδιας έκδοσης εμφανίζεται ξανά μετά από 12 ώρες αν επιλεγεί «Αργότερα».

## Εκδόσεις

- Client APK: `5.35` (versionCode `39`)
- Server APK: παραμένει `2.0.8`
- Worker API: δεν χρειάζεται αλλαγή, εφόσον έχει ήδη εγκατασταθεί η έκδοση που περιλαμβάνει το endpoint επανεπεξεργασίας.
- Web: `5.35`, με ορατό κινούμενο κύκλο συνολικής προόδου στη «Νέα ανάγνωση όλων».
- Η Web καρτέλα δείχνει ποιο τιμολόγιο επεξεργάζεται, `x/y`, ποσοστό, ολοκλήρωση και τυχόν σφάλματα χωρίς refresh.
- Η μαζική εντολή επανελέγχει από την αρχή όλα τα τιμολόγια που έχουν αποθηκευμένο PDF, όχι μόνο τα παλαιότερα.
