# Fleet Control 5.39.0 — Τιμολόγια και νέα ανάγνωση

Client/Web 5.39.0 (Client versionCode 50), Server 2.1.3 (versionCode 19), Worker 5.3.0. Δεν αλλάζει το σχήμα της βάσης, τα κλειδιά ή η υπογραφή Android.

## Αλλαγές

1. Το «Νέα ανάγνωση όλων» ανοίγει παράθυρο με δύο κάρτες επιλογής, στο ύφος του Portal:
   - **Server πρώτα**: τοπική ανάγνωση των αποθηκευμένων PDF και Workers AI όταν το αποτέλεσμα δεν είναι αξιόπιστο.
   - **Μόνο Workers AI**: κάθε PDF στέλνεται για εξαγωγή μέσω Workers AI. Ο νέος Server παρακάμπτει την τοπική ανάγνωση. Ο Worker επιβάλλει την αποθηκευμένη επιλογή ακόμη και αν ένας παλαιότερος Server στείλει αξιόπιστα τοπικά στοιχεία. Σε αποτυχία AI εμφανίζεται σφάλμα· δεν γίνεται σιωπηλή αποδοχή της τοπικής ανάγνωσης.
   Η ουρά συνεχίζεται μέσω του συνδεδεμένου Server και η πρόοδος συγχρονίζεται σε όλες τις συνδέσεις. Οι επιβεβαιωμένες διορθώσεις διατηρούνται.
2. Οι ομάδες ανά πινακίδα κρατούν την επιλογή ανοίγματος/κλεισίματος κατά την αυτόματη ανανέωση, αλλαγή φίλτρου και ενημέρωση της προόδου. Υπάρχει ομαλή κίνηση 350 ms, σωστό aria-expanded και απενεργοποίηση των κρυμμένων ελέγχων. Με ενεργή μειωμένη κίνηση η μετάβαση παραλείπεται. Η επιλογή παραμένει όσο είναι ανοιχτή η σύνδεση, όχι μετά από πλήρες reload.
3. Η υποκαρτέλα **Λίστα τιμολογίων** περιλαμβάνει όλα τα διαθέσιμα PDF ανεξάρτητα από κατάσταση ελέγχου. Ομαδοποιούνται με την πινακίδα του συνδεδεμένου service και ταξινομούνται ανά ημερομηνία τιμολογίου, από παλαιότερο προς νεότερο. Άγνωστες ημερομηνίες μπαίνουν στο τέλος. Δεν εμφανίζονται εργασίες, ποσά, προειδοποιήσεις ή άλλα στοιχεία: μόνο ονομασία αρχείου και Άνοιγμα/Λήψη. Υπάρχουν φίλτρο πινακίδας και αναζήτηση αρχείου/πινακίδας. Η πρόσβαση χρησιμοποιεί την υπάρχουσα ταυτοποίηση και τα Android εργαλεία προβολής/λήψης.

## Εγκατάσταση και επαναφορά

Η δημοσίευση μέσω GitHub αναπτύσσει τον Worker και ενεργοποιεί μαζί Server/Client/Web. Στον Server και Client έλεγξε τις ενημερώσεις και ολοκλήρωσε την εγκατάσταση Android όταν ζητηθεί. Μην απεγκαταστήσεις για κανονικό update. Κάνε ανανέωση στο Web αν διατηρεί παλιά assets. Ο Server πρέπει να ενημερωθεί σε 2.1.3 για να παρακάμπτει και το τοπικό στάδιο στη λειτουργία Μόνο Workers AI.

Διατήρησε αντίγραφο παραγωγικών δεδομένων πριν από εγκατάσταση, με τα υπάρχοντα εργαλεία backup. Το source ZIP περιέχει όλα τα τμήματα και το portable toolchain, όχι παραγωγικά δεδομένα/τιμολόγια ή πραγματικά κλειδιά. Οδηγίες κατασκευής και ιδιωτικά στοιχεία ανάκτησης παραμένουν οι υπάρχουσες. Δεν εκτελείται επαναφορά ή μαζική επανεπεξεργασία πραγματικών τιμολογίων ως μέρος της δημοσίευσης.

## Έλεγχοι

- VM στα πραγματικά Portal functions: κλειστή ομάδα μετά από polling/νέα στοιχεία, αναμονή ολοκλήρωσης animation, ανεξάρτητες προβολές, μοναδικά PDF, ελληνικές/λατινικές πινακίδες, ημερομηνίες ISO/ελληνικές/μη έγκυρες, σύντομες γραμμές, δύο τρόποι ανάγνωσης και προστασία διπλού κλικ.
- Προσομοίωση πραγματικών API με D1/R2: default Server πρώτα, χωρίς AI σε αξιόπιστη ανάγνωση, fallback σε αμφίβολη ανάγνωση, υποχρεωτικό AI παρά αξιόπιστο local OCR, αποτυχία AI χωρίς αποδοχή local, άκυρη επιλογή.
- Πλήρεις υπάρχοντες έλεγχοι source, OTA, service, μισθοδοσίας, προγράμματος, διαχείρισης και συνθετικών backup/restore.
- Κατασκευή και έλεγχος αρχικής υπογραφής και των δύο APK, ταύτιση Client assets με Web και Wrangler dry-run.
- Static UI checks. Δεν υπάρχει Chromium στο τοπικό περιβάλλον, επομένως δεν εκτελούνται screenshot/browser tests. Δεν έχει παρατηρηθεί εγκατάσταση σε πραγματική συσκευή ή ληφθεί πραγματικό backup από τον βοηθό.

## Συνέχιση ανάπτυξης

Ολόκληρο το έργο αποθηκεύεται στο GitHub και στο release source ZIP. Περιλαμβάνει Android Client, Server, κοινό κώδικα OTA, Web/Portal, Worker, tests, build scripts, manifests, lockfile, τεκμηρίωση και toolchain. Τα μυστικά παραμένουν ιδιωτικά. Η παραγωγική δημοσίευση επιβεβαιώνεται από επιτυχημένο Publish Fleet update και activated=true για το αντίστοιχο source SHA.
