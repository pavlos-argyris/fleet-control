FLEET CONTROL — ΕΝΗΜΕΡΩΣΗ 5.36

1. Κράτησε backup του υπάρχοντος `cloudflare-worker` και μην αντικαταστήσεις τυφλά το δικό σου `wrangler.jsonc`. Κράτησε το πραγματικό D1 ID, τα secrets και τα bindings `DB`, `RELEASES`, `SERVICE_DOCS`, `AI`, `ASSETS`. Αντέγραψε μόνο `src/`, `public/`, `package.json` και `package-lock.json` από το update.

2. Κάνε deploy τον νέο Worker από τον φάκελο `cloudflare-worker`:

   `npm install`

   `npm run deploy`

3. Από το Server APK άνοιξε «Ενημερώσεις» και ανέβασε/ενεργοποίησε:

   `Fleet_Control_Web_Assets_v5.36.zip`

4. Ανέβασε/ενεργοποίησε το Client APK:

   `Fleet_Control_Client_v5.36.apk`

   Έχει versionCode `41`, επομένως είναι νεότερο από το `5.35.1` και θα εμφανιστεί στο prompt αυτόματης ενημέρωσης.

5. Στο Web κάνε μία φορά `Ctrl+F5`. Στο APK ο έλεγχος ενημέρωσης γίνεται στην εκκίνηση, στην επιστροφή στο προσκήνιο και περιοδικά.

6. Μετά την ενημέρωση, όταν πατήσεις «Νέα ανάγνωση όλων», η πρόοδος θα εμφανίζεται ταυτόχρονα σε όλες τις ανοιχτές συνδέσεις Web/APK.

7. Το ίδιο ισχύει και για μεμονωμένο QR: μόλις αποθηκευτεί, οι ανοιχτές καρτέλες «Τιμολόγια» ανιχνεύουν αυτόματα τη νέα εργασία, εμφανίζουν το ποσοστό και ανανεώνουν τον κινούμενο κύκλο μέχρι να ολοκληρωθεί ή να αποτύχει.

8. Η έκδοση περιλαμβάνει επίσης διόρθωση για πιθανή ένδειξη `NaN%` σε παλιές ή προσωρινά μη έγκυρες τιμές προόδου.
