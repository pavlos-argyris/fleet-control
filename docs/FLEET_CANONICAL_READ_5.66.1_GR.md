# Μηχανάκια — πλήρης ανάγνωση κύριας βάσης, 5.66.1

Η πραγματική Direct βάση αναφέρει29 ορατές μηχανές ενώ η Web5.66.0 εμφανίζει0/Συγχρονίστηκε. Τα bytes της πραγματικής app/service-model5.66.0 συμφωνούν με τον πηγαίο κώδικα. Η συγκεκριμένη ιδιωτική sync απάντηση/αρχική εξαίρεση δεν έχει παραληφθεί, επομένως δεν αποδίδουμε βέβαιη φυσική αιτία σε quota ή CursorWindow.

Μεταβολή έκδοσης/πλήθους απορρίπτεται αντί να συνδυάζονται διαφορετικά στιγμιότυπα. Δεν αφαιρείται ιστορικό για να μικρύνει η μεταφορά.

Web/Client ολοκληρώνουν και επαληθεύουν όλες τις σελίδες πριν εφαρμόσουν τον στόλο/νέα έκδοση. Αποτυχία στη μέση διατηρεί την προηγούμενη πλήρη λίστα και εμφανίζει επανάληψη.401 σε οποιαδήποτε σελίδα χρησιμοποιεί την υπάρχουσα διαδρομή αποσύνδεσης. Παραμένει συμβατότητα με παλιότερες πλήρεις απαντήσεις και unchanged μετά από πραγματική εφαρμογή.

Η παλιά συγκεντρωτική διαδρομή δεν υποκαθιστά πλέον ανύπαρκτη γραμμή/στήλη με `[]`. Αυτό το αναπαραγόμενο σφάλμα μπορούσε να παρουσιαστεί ως επιτυχής κενός στόλος.
