# Fleet Control v5.25

- Προστέθηκε διαγραφή τιμολογίου μόνο από λογαριασμό διαχείρισης.
- Η διαγραφή αφαιρεί το αρχείο από το ιδιωτικό R2 και την καταχώρηση από το service.
- Τα συνημμένα τιμολόγια πλέον διατηρούνται σωστά στον canonical snapshot του Worker.
- Προστέθηκε OCR για PDF μέσω Workers AI Markdown Conversion και δομημένη εξαγωγή στοιχείων τιμολογίου.
- Το OCR για PDF και εικόνες παραμένει υπό επιβεβαίωση από τον διαχειριστή πριν χρησιμοποιηθεί ως επίσημη καταχώρηση.
- Αντικαταστάθηκε το απλό file input με ομοιόμορφο κουμπί μεταφόρτωσης που εμφανίζει το επιλεγμένο αρχείο.
- Το Client APK ελέγχει αυτόματα νέες εκδόσεις και εμφανίζει νέο ασφαλές prompt ενημέρωσης με έκδοση, σημειώσεις και μέγεθος αρχείου.
