# Fleet Control 5.49.1 — πράσινη ένδειξη κάτω πλοήγησης

Client/Web 5.49.1 (65), Worker 5.10.3. Ο Server παραμένει 2.2.5 (31), με το ίδιο APK.

- Ένα κοινό πράσινο πλαίσιο με απαλό γέμισμα ολισθαίνει στο επιλεγμένο κάτω κουμπί σε 220 ms. Η κίνηση ακολουθεί τη θέση του κουμπιού, ακόμη και με γρήγορα διαδοχικά πατήματα.
- Αφαιρείται το μπλε native tap highlight του browser από τα κουμπιά της κάτω πλοήγησης. Η εστίαση πληκτρολογίου έχει πράσινο περίγραμμα.
- Η αρχική επιλογή, η επανεμφάνιση της κάτω μπάρας και οι αλλαγές μεγέθους ευθυγραμμίζουν το πλαίσιο απευθείας. Η Μείωση κίνησης παραλείπει την ολίσθηση.
- Το πλαίσιο δεν δέχεται αγγίγματα και δεν αλλάζει το μέγεθος των κουμπιών. Το επιλεγμένο κουμπί έχει `aria-current="page"`. Δεν προστίθενται αιτήματα δικτύου.

Ο υποχρεωτικός browser έλεγχος χρησιμοποιεί πραγματικά touch events σε mobile Chromium, σε Web και στα τοπικά αρχεία Client. Ελέγχει ενεργή μετάβαση transform 220 ms, διαφανές tap highlight, μία μόνο ένδειξη, τελική ευθυγράμμιση μετά από γρήγορες επιλογές, αλλαγή μεγέθους και Μείωση κίνησης. Διατηρούνται οι έλεγχοι της 5.49.0 για ανάπτυξη κάρτας, Back και θέση κύλισης. Στιγμιότυπα και αποτελέσματα αποθηκεύονται στο GitHub Actions artifact `navigation-motion-verification`.

Εγκατάσταση: ενημέρωσε μόνο τον Client από τον έλεγχο ενημερώσεων, πάνω στην υπάρχουσα εφαρμογή. Web/Worker ενημερώνονται από το workflow· στο Web κάνε ανανέωση. Δεν απαιτείται νέα εγκατάσταση Server. Δεν αλλάζουν δεδομένα ή σχήμα βάσης. Η δημοσίευση δεν λαμβάνει backup παραγωγικών δεδομένων· διατήρησε τα συνηθισμένα αντίγραφα εκτός εφαρμογής.

Πλήρης κώδικας όλων των τμημάτων, πακέτα, checksums και build inputs διατίθενται στο GitHub release. Η αίσθηση του εφέ στη φυσική συσκευή επιβεβαιώνεται μετά την εγκατάσταση.
