# #107 — Ενημερώσεις Android Server και Client

Η κανονική έκδοση fleet-v5.67.1 διαθέτει δημόσιο manifest και ξεχωριστά APK. Η ανάγνωση μέσω του GitHub latest manifest επέστρεψε Client 5.67.1 (114) και Server 2.16.1 (87), με μέγεθος και SHA-256 που συμφωνούν με τα δημοσιευμένα αρχεία.

Στον Client ο downloader άλλαζε ρυθμίσεις του HttpURLConnection αφού η κοινή μέθοδος είχε ήδη ακολουθήσει τις ανακατευθύνσεις. Οι ρυθμίσεις εφαρμόζονται τώρα πριν από κάθε σύνδεση και ο έλεγχος διαθέσιμης ενημέρωσης συγκρίνει versionCode. Η προετοιμασία του PackageInstaller εκτελείται στο νήμα ενημέρωσης.

Στον Server ένα προβληματικό πακέτο ή αποτυχημένη εγκατάσταση μπορούσε να αφήσει την υπηρεσία σε παύση και να επανεκκινήσει την προετοιμασία backup. Η επαλήθευση προηγείται πλέον της νέας προετοιμασίας. Μετά από αποτυχία Android, οι εργασίες συνεχίζονται και εμφανίζεται δυνατότητα νέας προσπάθειας. Και τα δύο APK ελέγχονται ως προς μέγεθος, package ID, versionCode, SHA-256 και την υπογραφή της ήδη εγκατεστημένης εφαρμογής.

Πέρασαν τα Java tests για metadata, ανακατεύθυνση και χρονισμό OTA, τα tests των οθονών ενημέρωσης και η κατασκευή των APK με δοκιμαστική υπογραφή. Η αναβάθμιση στη συσκευή απαιτεί αρχικά υπογεγραμμένα APK. Για τον Client 5.67.1 η πρώτη μετάβαση μπορεί να χρειαστεί εγκατάσταση του υπογεγραμμένου APK από το GitHub Releases επάνω στην υπάρχουσα εγκατάσταση, επειδή ο παλιός downloader περιέχει την αστοχία. Η επόμενη δοκιμή OTA χρειάζεται νεότερο υπογεγραμμένο build.
