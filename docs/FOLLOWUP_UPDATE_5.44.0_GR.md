# Fleet Control 5.44.0 — συμφωνημένες προσθήκες

Ο χρήστης επέλεξε στις 11/10/2026 τις προτάσεις 1, 2, 3, 5 και 6:

- Service χωρίς τιμολόγιο: φίλτρα ημερομηνίας/πινακίδας, άμεση προσθήκη QR και «Δεν αναμένεται τιμολόγιο» με εξήγηση.
- Ενιαίος πίνακας εκκρεμοτήτων: έλεγχος, σφάλματα/καθυστερήσεις ανάλυσης και τοπικά αρχεία που περιμένουν αποστολή, με συγκεκριμένη ενέργεια.
- Διαδοχικός έλεγχος τιμολογίων: «Αποθήκευση & επόμενο», διατήρηση φίλτρων, ασφαλής παύση/παράλειψη χωρίς απώλεια αποτυχημένης αποθήκευσης.
- Χρονολογικός έλεγχος χιλιομέτρων: σύγκριση διαφορετικών ημερών και επιβεβαίωση «Είναι σωστό» με εξήγηση, συνδεδεμένη με τις συγκεκριμένες ενδείξεις.
- Κατάσταση τελευταίου επιτυχούς backup και έλεγχος αναγνωσιμότητας δεδομένων/συνοδευτικών PDF χωρίς επαναφορά.

Δεν περιλαμβάνεται η πρόταση 4 (κοινό τιμολόγιο για πολλά μηχανάκια).
Διατηρούνται η αρχική υπογραφή Android, η παράδοση όλου του κώδικα στο ιδιωτικό GitHub και η συμφωνημένη αυτόματη δημοσίευση μετά από επιτυχές CI.

Client/Web 5.44.0 (Android code 58), Server 2.2.1 (code 27), Worker 5.7.0.

## Πού βρίσκονται οι επιλογές

Στο κάτω μέρος του Fleet υπάρχουν «Service χωρίς τιμολόγιο», «Εκκρεμότητες» και
«Έλεγχος ιστορικού χιλιομέτρων». Στα Τιμολόγια υπάρχουν «Εκκρεμότητες στόλου»
και «Διαδοχικός έλεγχος». Οι νέες ενέργειες απαιτούν λογαριασμό διαχείρισης στόλου.

Οι τρεις λίστες έχουν κοινά φίλτρα μηχανής και ημερομηνιών service. Με «Εμφάνιση
εξαιρέσεων / ελεγμένων» βλέπεις τις αιτιολογημένες αποφάσεις. Μηχανές στον κάδο
δεν εμφανίζονται ως ενεργές εκκρεμότητες. Τα φίλτρα διατηρούνται μέχρι αποσύνδεση.
Η φόρτωση γίνεται κατά το άνοιγμα ή την Ανανέωση· δεν προστίθεται συνεχής polling.

## Service χωρίς τιμολόγιο

Εμφανίζονται service χωρίς αποθηκευμένο αρχείο. Αποστολές PDF/QR που περιμένουν
στη συσκευή και ενεργές αναγνώσεις εμφανίζονται στις Εκκρεμότητες.
«Προσθήκη QR / αρχείου» ανοίγει την ίδια υπάρχουσα καταχώρηση, χωρίς νέο service.
«Δεν αναμένεται τιμολόγιο» ζητά εξήγηση, καταγράφει χρήστη/ώρα και αφαιρεί τη
συγκεκριμένη εκκρεμότητα. Δεν διαγράφει εργασίες ή κόστος. Από την προβολή
εξαιρέσεων μπορείς να επαναφέρεις την απαίτηση τιμολογίου.

## Ενιαία λίστα

Συγκεντρώνει τιμολόγια προς έλεγχο, προειδοποιήσεις, καθυστερήσεις/σφάλματα
ανάλυσης και τοπικά αρχεία προς αποστολή. Δείχνει το διαθέσιμο στάδιο ή σφάλμα
και ενέργεια ελέγχου, ανοίγματος PDF ή νέας προσπάθειας. Δεν διαγράφει δεδομένα.
Οι τοπικές ουρές αφορούν αυτή τη συσκευή και τον λογαριασμό· άλλη συσκευή δεν
μπορεί να ανακτήσει τα μη απεσταλμένα αρχεία. Μην καθαρίζεις δεδομένα εφαρμογής
όσο υπάρχουν τέτοιες αποστολές. Η ουρά συνεχίζει όταν η εφαρμογή είναι ανοιχτή
και συνδεδεμένη. Η λίστα εμφανίζει ρητά τυχόν αποτυχία φόρτωσης.

## Διαδοχικός έλεγχος

Επιλέγεις πρώτα τα φίλτρα στα Τιμολόγια και πατάς «Διαδοχικός έλεγχος».
Συμπεριλαμβάνονται διαθέσιμα PDF προς έλεγχο, όχι αρχεία ακόμη σε επεξεργασία
ή ήδη ολοκληρωμένα. Η αρχική σειρά κωδικών παραμένει σταθερή ακόμη και με polling.

- «Αποθήκευση & επόμενο»: προχωρά μόνο μετά από επιτυχή αποθήκευση.
- «Παράλειψη»: δεν αποθηκεύει αλλαγές και αφήνει το τιμολόγιο προς έλεγχο.
- «Παύση»: κλείνει τη διαδικασία. Οι αποθηκευμένες αποφάσεις παραμένουν.
- Η κανονική «Αποθήκευση» ολοκληρώνει μόνο το τρέχον και σταματά τη σειρά.

Αν αποτύχει αποθήκευση, η φόρμα παραμένει ανοιχτή με τα στοιχεία σου.
Οι υπάρχουσες επιλογές πινακίδας, χιλιομέτρων και μεταφοράς συνεχίζουν να ισχύουν.

## Χρονολογικός έλεγχος χιλιομέτρων

Ελέγχονται service και χειροκίνητοι έλεγχοι χιλιομέτρων με έγκυρη ημερομηνία.
Μια ένδειξη συγκρίνεται με τη μεγαλύτερη ένδειξη της αμέσως προηγούμενης ημέρας
καταγραφής. Καταχωρήσεις της ίδιας ημέρας δεν ταξινομούνται αυθαίρετα μεταξύ
τους, επειδή η ημερομηνία service δεν περιέχει ώρα.

«Είναι σωστό» ζητά εξήγηση, π.χ. αλλαγή κοντέρ. Η απόφαση συνδέεται με τους
δύο κωδικούς, ημερομηνίες και ενδείξεις. Αν αλλάξει οποιοδήποτε από αυτά ή
μεσολαβήσει άλλη ημέρα καταγραφής, ο έλεγχος υπολογίζεται ξανά.
Δεν αλλάζει πραγματικά χιλιόμετρα, κύκλους συντήρησης ή μισθοδοσία.
Υπάρχει κεντρικό audit και προστασία από ταυτόχρονη/παλιά αποθήκευση.
Οι νέες αποφάσεις διαβάζουν/ενημερώνουν μόνο την αντίστοιχη μηχανή, χωρίς
επεξεργασία των άσχετων ιστορικών ολόκληρου του στόλου.

## Backup στον Server

Η καρτέλα Backup δείχνει την τελευταία επιτυχή αποθήκευση ανεξάρτητα από
μεταγενέστερη αποτυχία, αριθμό αναμενόμενων/περιλαμβανόμενων PDF και τυχόν
απουσία συγχρονισμένου αντιγράφου προσωπικού/συστήματος.

«Έλεγχος τελευταίου backup» διαβάζει το τελευταίο νέο αντίγραφο.
«Έλεγχος άλλου αρχείου» επιτρέπει επιλογή παλαιότερου .fcbackup.
Ο έλεγχος αποκρυπτογραφεί, ελέγχει δομή δεδομένων και μετρά εγγραφές.
Αναζητά το αντίστοιχο .fcdocs στον επιλεγμένο φάκελο backup, διαβάζει όλα τα
αρχεία ZIP/CRC και συγκρίνει αναμενόμενα κλειδιά και μεγέθη.
Τα νέα αντίγραφα περιέχουν SHA-256 ανά αρχείο και συνοδευτικού ZIP.
Τα παλιότερα ελέγχονται με τις διαθέσιμες πληροφορίες και δηλώνεται η απουσία
συνολικού SHA-256. Ελλιπή ή μη αναγνώσιμα αντίγραφα επισημαίνονται.

Δεν εκτελείται επαναφορά, εγγραφή βάσης ή εγκατάσταση PDF. Αποθηκεύεται μόνο
το αποτέλεσμα του ελέγχου στις ρυθμίσεις. Η αναγνωσιμότητα δεν αποδεικνύει
ότι έχουν συγχρονιστεί όλα τα νεότερα cloud δεδομένα: το backup αφορά την
αποθηκευμένη κατάσταση του Server. Συγχρόνισε πριν δημιουργήσεις νέο αντίγραφο.
Το αρχείο πηγής στο GitHub δεν αντικαθιστά backup παραγωγικών δεδομένων.

## Εγκατάσταση και έλεγχοι

Πριν το update πάρε Backup. Μετά τη δημοσίευση πάτησε «Έλεγχος τώρα» σε Server
και Client και επιβεβαίωσε εγκατάσταση Android. Web/Worker ενεργοποιούνται από
το workflow. Ο αρχικός τρόπος υπογραφής διατηρείται.

Ο πλήρης κώδικας όλων των τμημάτων και τα build inputs διατίθενται στο ιδιωτικό
GitHub και στο source ZIP. Οι οδηγίες ανεξάρτητης κατασκευής της 5.43.0
εξακολουθούν να ισχύουν. Το Worker ZIP περιλαμβάνει και αυτόν τον οδηγό.

Έλεγχοι: πλήρης suite DOM/API/D1/R2 με συνθετικά δεδομένα, πραγματικές κλήσεις
νέου API (auth, εξήγηση, stale guard, fingerprint, audit, συμβατότητα παλιού
Client), διαδοχικός έλεγχος με αποτυχία/παράλειψη/παύση, και πραγματικός JVM
αναγνώστης ZIP με CRC/SHA/μέγεθος και αλλοιωμένα/ελλιπή αρχεία.
Κατασκευάζονται και επαληθεύονται τα δύο APK. Δεν εκτελείται restore παραγωγής
για δοκιμή ούτε δοκιμή Android Drive provider σε πραγματική συσκευή.
