# Πραγματική δοκιμή OTA Server 2.1.0 → 2.1.1

Η έκδοση πακέτου είναι 5.37.1 και η νέα έκδοση Server είναι 2.1.1 (`versionCode` 17). Ο Server 2.1.0 έχει code 16. Αλλάζουν μόνο οι αριθμοί έκδοσης στον manifest και η αναφερόμενη έκδοση στο ServerConfig. Τα αρχεία εφαρμογής, τα assets, η λειτουργία, το package, το αρχικό κλειδί Server και η υπογραφή διατηρούνται. Client/Web παραμένουν 5.37.0 και Worker 5.1.0.

## Πριν από τη δημοσίευση

1. Επιβεβαίωσε **από τις πληροφορίες εφαρμογής του Android** ότι είναι εγκατεστημένος ο Server 2.1.0. Η λίστα διαθέσιμων εκδόσεων στην εφαρμογή δείχνει δημοσιευμένες εκδόσεις και δεν αποδεικνύει ποια είναι εγκατεστημένη.
2. Πάρε και κράτησε εξωτερικό backup, μαζί με το συνοδευτικό `.fcdocs` όταν υπάρχει. Βεβαιώσου ότι η δημιουργία ολοκληρώθηκε επιτυχώς. Αυτό το βήμα το εκτελείς στη συσκευή· οι δοκιμές με συνθετικά δεδομένα δεν είναι παραγωγικό backup.
3. Σημείωσε το πλήθος μηχανών/εργαζομένων, ένα υπάρχον service με τιμολόγιο, τις ρυθμίσεις συγχρονισμού και τον φάκελο backup.
4. Στην καρτέλα **Ενημερώσεις** ενεργοποίησε **Αυτόματη λήψη και εγκατάσταση**. Επιβεβαίωσε τον εξωτερικό φάκελο backup, τις άδειες ειδοποιήσεων και εγκατάστασης ενημερώσεων. Το κουμπί **Εγκατάσταση ενημέρωσης** ανοίγει την άδεια εγκατάστασης αν λείπει.
5. Πάτησε **Έλεγχος τώρα**. Πριν δημοσιευτεί η νέα έκδοση πρέπει να γράφει **Ο Server έχει την τελευταία διαθέσιμη έκδοση.**

## Δημοσίευση

Στο [GitHub Actions](https://github.com/pavlos-argyris/fleet-control/actions) επίλεξε **Publish Fleet update → Run workflow → main → Run workflow** αφού έχουν περάσει οι έλεγχοι του νέου commit. Το workflow δημιουργεί το `fleet-v5.37.1`, αποθηκεύει πλήρη κώδικα και υπογεγραμμένα αρχεία και ενεργοποιεί το νέο manifest στο Cloudflare.

Περίμενε επιτυχία και του τελευταίου βήματος **Upload and activate verified Server, Client and Web together**. Η δημιουργία του GitHub release από μόνη της δεν αποδεικνύει ενεργοποίηση στο Cloudflare. Οι ήδη ενεργές εκδόσεις Client/Web αναδημοσιεύονται με τα ίδια αρχεία και αριθμούς έκδοσης· δεν χρειάζεται χειροκίνητη ενημέρωσή τους.

## Δοκιμή στη συσκευή

- Άφησε τον Server ενεργό και συνδεδεμένο στο Internet. Ο περιοδικός έλεγχος γίνεται ανά 15 λεπτά. Για επιτάχυνση μπορείς να πατήσεις **Έλεγχος τώρα**· τότε δοκιμάζεται ο ίδιος μηχανισμός λήψης και εγκατάστασης, με χειροκίνητη εκκίνηση του ελέγχου.
- Η εφαρμογή πρέπει να εμφανίσει λήψη Server 2.1.1 και **Έτοιμη η έκδοση 2.1.1. Θα προηγηθεί backup.**
- Μετά από επιτυχή κύκλο συγχρονισμού πρέπει να δημιουργήσει backup στον επιλεγμένο φάκελο και να ξεκινήσει εγκατάσταση. Με αποτυχημένο συγχρονισμό, αποτυχημένο backup ή ελλιπείς άδειες η εγκατάσταση δεν προχωρά. Δες το μήνυμα της καρτέλας και διόρθωσε την αιτία.
- Αν το Android ζητήσει επιβεβαίωση, άνοιξε την ειδοποίηση ή πάτησε **Εγκατάσταση ενημέρωσης** και αποδέξου την εγκατάσταση. Αυτό καταγράφεται ως OTA με επιβεβαίωση. Αν εγκατασταθεί χωρίς πάτημα, καταγράφεται ως αυτόματη εγκατάσταση.
- Για αυτή τη δοκιμή μην εγκαταστήσεις χειροκίνητα το APK 2.1.1 και μην απεγκαταστήσεις τον Server. Αφήνουμε την ήδη εγκατεστημένη 2.1.0 να ολοκληρώσει τη διαδρομή OTA.

## Κριτήρια επιτυχίας

| Έλεγχος | Αναμενόμενο αποτέλεσμα |
|---|---|
| Εγκατεστημένη έκδοση στις πληροφορίες Android | 2.1.1 |
| Backup πριν από την εγκατάσταση | Νέο αρχείο στον εξωτερικό φάκελο και αντίστοιχο όνομα στην καρτέλα Ενημερώσεις |
| Επανεκκίνηση/συγχρονισμός υπηρεσίας | Επιτυχής νέος συγχρονισμός μετά το update |
| Μηχανές, εργαζόμενοι, παλιό service/τιμολόγιο | Ίδια στοιχεία με πριν από το update |
| Ρυθμίσεις και φάκελος backup | Διατηρούνται |
| Νέος έλεγχος ενημερώσεων | Ο Server έχει την τελευταία διαθέσιμη έκδοση. |

Η πραγματική εγκατάσταση και η διατήρηση δεδομένων δεν θεωρούνται επιβεβαιωμένες πριν ολοκληρωθούν οι παραπάνω έλεγχοι στο S24 Ultra. Το εξωτερικό backup φυλάσσεται· δεν κάνουμε δοκιμή restore ή απεγκατάσταση για αυτόν τον έλεγχο OTA. Η υπάρχουσα επαναφορά συγχωνεύει δεδομένα και δεν εγγυάται ακριβή επαναφορά όλου του Cloudflare σε προηγούμενη χρονική στιγμή.
