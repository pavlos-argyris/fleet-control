# Fleet Control 5.41.0 — συγχρονισμός, επανάληψη QR και OTA Client

Client/Web 5.41.0 (versionCode 54), Server 2.1.7 (versionCode 23), Worker 5.4.0. Ίδιες αρχικές υπογραφές και ίδιο runtime schema 5.1.0. Οι αλλαγές 5.40.1 διατηρούνται.

## Τι εντοπίστηκε

Στον έλεγχο παραγωγής οι διαδρομές snapshot, pending και system-export απάντησαν HTTP 200. Το πλήρες system-export είχε περίπου 2,35 MB και χρόνο Worker περίπου 5 δευτερολέπτων στον συγκεκριμένο έλεγχο. Το snapshot περίπου 795 KB. Αυτές είναι μεμονωμένες παρατηρήσεις, όχι συγκριτικό benchmark ή CPU χρόνοι. Δεν ήταν διαθέσιμο το ακριβές σφάλμα από το φυσικό S24 Ultra.

Ο προηγούμενος κύκλος Server περίμενε διαδοχικά ολόκληρο το snapshot, όλες τις ελλείπουσες λήψεις PDF, το πλήρες προσωπικό/πρόγραμμα, την ουρά τιμολογίων και την τελική επιβεβαίωση. Μια αποτυχία του αντιγράφου προσωπικού μπορούσε να κρατά την ένδειξη «Καθυστέρηση συγχρονισμού» παρότι ο στόλος είχε ήδη ληφθεί. Πρόκειται για τεκμηριωμένο πρόβλημα της ροής, όχι επιβεβαίωση της αιτίας κάθε σφάλματος της συσκευής.

## Αλλαγές

- Ο συγχρονισμός στόλου εκτελείται ανεξάρτητα από την επεξεργασία τιμολογίων και το αντίγραφο προσωπικού. Οι ουρές φιλτράρονται στον Worker. Η σύνδεση και ο έλεγχος ακύρωσης παραμένουν επίσης ανεξάρτητοι.
- Server και Fleet Web/Client ζητούν το snapshot με την τελευταία γνωστή έκδοση. Όταν δεν έχει αλλάξει επιστρέφεται μικρή απάντηση unchanged, χωρίς επαναλήψη λήψης/συγχώνευσης ολόκληρου του στόλου. Οι τοπικές αλλαγές και ο γνωστός κανόνας ανά μηχανή διατηρούνται.
- Το αντίγραφο προσωπικού/προγράμματος λαμβάνεται ανά πίνακα σε σελίδες έως 50 εγγραφών από τον νέο Server (μέγιστο API 100). Ο Worker παράγει το JSON των γραμμών στη βάση. Μόνο πλήρες επιτυχημένο αντίγραφο αντικαθιστά το προηγούμενο τοπικό. Ο περιοδικός κύκλος του αντιγράφου είναι 5 λεπτά και έχει χωριστό σφάλμα/κουμπί επανάληψης. Η παλιά διαδρομή export διατηρείται για συμβατότητα.
- Στο delayed QR υπάρχει «Διακοπή & νέα προσπάθεια». Δημιουργείται νέο job ID, το προηγούμενο ακυρώνεται και τα παλιά progress/error/ACK/PDF δεν μπορούν να το αναστήσουν. Η καταχώρηση service και τα ήδη διαθέσιμα PDF διατηρούνται. Αν υπάρχει ήδη PDF γίνεται επαναχρησιμοποίηση, και σε σφάλμα OCR νέα ανάλυση του ίδιου PDF.
- Η ακύρωση που ζητείται από Web ελέγχεται στον νέο Server περίπου ανά 4 δευτερόλεπτα, όταν η σύνδεση λειτουργεί. Η τοπική ακύρωση από Server ενεργοποιείται άμεσα. Το WebView καταστρέφεται με ασφαλή ακύρωση στο κύριο νήμα. Σε διακοπή δικτύου η τοπική αναγνώριση ακύρωσης μπορεί να καθυστερήσει, αλλά ο Worker εξακολουθεί να αποκλείει τα παλιά αποτελέσματα.
- Ο Server εμφανίζει ακριβές στάδιο συγχρονισμού, endpoint, χρόνο τελευταίου ολοκληρωμένου κύκλου και χωριστή πρόοδο/σφάλμα αντιγράφου. Στα QR εμφανίζει φόρτωση, PDF, τοπική ανάγνωση, αποστολή και Workers AI όταν πράγματι χρησιμοποιείται. Έχει προτάσεις για σύνδεση, προσωρινά HTTP σφάλματα, πρόσβαση, QR/PDF και διαθέσιμο χώρο. Τα κουμπιά ζητούν πραγματικό νέο συγχρονισμό, επανάληψη αντιγράφου ή ακύρωση/επανάληψη τιμολογίου. Δεν αλλάζουν αυτόματα χρέωση Cloudflare ή διαπιστευτήρια.
- Διακοπείσα μαζική ανάγνωση με εναπομείναντα τιμολόγια μπορεί να συνεχίσει από τον αποθηκευμένο δείκτη, αντί να επανεκκινεί όλη τη λίστα. Το ίδιο προστατευμένο API δεν επαναφέρει ολοκληρωμένη εργασία.
- Το OTA Client έχει το ίδιο οπτικό ύφος με τον Server: πράσινη γραμμή σε έλεγχο, λήψη, επαλήθευση, εγκατάσταση και αναμονή επιβεβαίωσης. Ο Client δείχνει πραγματικό ποσοστό λήψης, bullets αλλαγών, άδεια/επιβεβαίωση Android και επανάληψη αποτυχίας. Το κουμπί ελέγχου παρακάμπτει το διάστημα αυτόματου ελέγχου. Το Πίσω κλείνει την καρτέλα OTA. Browser/PWA εξακολουθούν να χρησιμοποιούν τις συνηθισμένες επιλογές λήψης.
- Στον Server ο χειροκίνητος έλεγχος δείχνει τη γραμμή αμέσως, ακόμη και σε πολύ γρήγορη απάντηση. Η κίνηση συνεχίζεται σε κάθε ενεργό στάδιο. Υποστηρίζεται reduced motion. Δεν εμφανίζεται επινοημένο ποσοστό backup/επαλήθευσης.

## Έλεγχοι

- Πλήρης σουίτα δεδομένων, δικαιωμάτων, service/τιμολογίων, μισθοδοσίας/προγράμματος και συνθετικού backup/restore.
- Πραγματικός Worker σε τοπική SQLite: 40 μηχανές × 500 εγγραφές, 200 συνθετικά τιμολόγια, 10 ταυτόχρονες ενημερώσεις, ασφαλής ακύρωση, παλιά callbacks/ACK/PDF, διατήρηση επισυνάψεων, πρόσβαση, διαχωρισμός ουρών, unchanged και σελιδοποίηση αντιγράφου.
- Πραγματική Java για HTTP, πολιτική snapshot, paged mirror, OTA και αναγνώστη PDF. Μη προχωρούμενος δείκτης ή μερική/δικτυακή αποτυχία του αντιγράφου δεν επιστρέφει αντικατάσταση.
- Πραγματικές συναρτήσεις Client/Server UI σε VM για στάδια, χειροκίνητο έλεγχο, ποσοστά, bullets/escaping και διαθέσιμες ενέργειες. Κατασκευή και επαλήθευση και των δύο υπογεγραμμένων APK, καθώς και dry-run Worker.

Δεν έγινε εγκατάσταση σε φυσικό τηλέφωνο, οπτικός έλεγχος στο Android WebView, πραγματικό scan/AI παραγωγικού τιμολογίου ή backup/restore παραγωγικών δεδομένων από τον βοηθό. Το μεγάλο fixture δεν αποδεικνύει ότι όλες οι διαδρομές παραγωγής θα μένουν κάτω από το όριο CPU του λογαριασμού. Δεν αλλάζει το πρόγραμμα Cloudflare. Αν υπάρξει ξανά σφάλμα, ο νέος Server δείχνει την ακριβή διαδρομή/αιτία για στοχευμένο έλεγχο.

## Εγκατάσταση και backup

Η εξουσιοδοτημένη δημοσίευση ενεργοποιεί Web/Worker και διαθέτει τα νέα Server/Client μέσω OTA. Ενημέρωσε Server και Client πάνω από τις υπάρχουσες εγκαταστάσεις με επιβεβαίωση Android. Το Worker προηγείται ώστε οι νέες διαδρομές να είναι διαθέσιμες. Ανανέωσε το Web αν έχει μείνει παλιά cache.

Πριν ενημερώσεις, κράτησε πρόσφατο backup στον επιλεγμένο φάκελο. Το backup Server χρησιμοποιεί το τελευταίο πλήρες τοπικό αντίγραφο προσωπικού/προγράμματος και τα τοπικά διαθέσιμα PDF, όπως πριν. Με το χωριστό mirror έλεγξε τον χρόνο και την επιτυχή ολοκλήρωσή του ή πάτησε «Επανάληψη αντιγράφου προσωπικού» πριν πάρεις backup, αν χρειάζεσαι τις πιο πρόσφατες cloud αλλαγές. Δεν αποτελεί στιγμιαία συναλλαγή όλων των πινάκων. Διατηρείται η προηγούμενη δυνατότητα offline backup. Ο πηγαίος κώδικας δεν περιέχει παραγωγικά δεδομένα ούτε υποκαθιστά το backup.

Ολόκληρος ο κώδικας Client/Server/Web/Portal/Worker/κοινών OTA, μαζί με lockfiles, manifests, assets, tests, scripts και toolchain, παραδίδεται σε source ZIP και GitHub. Για συμβατά APK χρειάζεται το ήδη παραδομένο ιδιωτικό αρχείο υπογραφής και οι λογαριασμοί/μυστικά του BUILD_AND_HANDOFF_GR.md. Αυτά δεν καταχωρίζονται στο repository. Παλιές υπογεγραμμένες εκδόσεις παραμένουν στα GitHub releases. Τυχόν υποβάθμιση/απεγκατάσταση απαιτεί έλεγχο συμβατού backup πριν από διαγραφή δεδομένων εφαρμογής.
