# Fleet Control 5.40.1 — αποκατάσταση 503 και επανάληψη τιμολογίων

Client/Web 5.40.1 (code 53), Server 2.1.6 (code 22), Worker 5.3.3. Διατηρούνται οι αρχικές υπογραφές APK, τα υπάρχοντα κλειδιά, το σχήμα βάσης 5.1.0 και οι αλλαγές 5.40.0.

## Διάγνωση και αλλαγές

Το log παραγωγής που δόθηκε από τον χρήστη αφορά GET /api/snapshot της έκδοσης Worker 261f74f5-65af-489c-8f68-42f2052dc44a, με outcome exceededCpu, HTTP 503 και CPU 10 ms. Η τεκμηρίωση Cloudflare αναφέρει 10 ms ανά HTTP αίτημα για Workers Free. Δεν αλλάζει αυτόματα το πρόγραμμα χρέωσης ούτε το όριο του λογαριασμού.

- Το GET snapshot/sync επιστρέφει το ήδη αποθηκευμένο κανονικοποιημένο JSON. Δεν ξανακανονικοποιεί, ταξινομεί ή αναδημιουργεί όλα τα ιστορικά στη JavaScript. Η εξαίρεση αρχειοθετημένων μηχανών γίνεται στη βάση. Τα ίδια δικαιώματα πρόσβασης παραμένουν.
- Το status και ο συγχρονισμός καταλόγου μηχανών διαβάζουν μικρά περιληπτικά πεδία αντί για τις εργασίες/τιμολόγια όλων των μηχανών. Η ανανέωση ειδοποιήσεων βασίζεται στα πεδία που τις επηρεάζουν, όχι στις αλλαγές ποσοστού QR.
- Πρόοδος QR, νέες επισυνάψεις, ένδειξη ότι διαβάστηκε και νέα ανάλυση PDF ενημερώνουν μόνο το συγκεκριμένο service με έλεγχο της προηγούμενης τιμής. Μια άλλη εργασία δεν χάνει την αλλαγή της. Μια καθυστερημένη πρόοδος/αποτυχία δεν επαναφέρει ολοκληρωμένο PDF σε επεξεργασία/σφάλμα.
- Server και Client διαθέτουν προστατευμένο συγχρονισμό ανά μηχανή. Ο Server δεν ανεβάζει ξανά την αμετάβλητη τοπική εικόνα. Ο Client αποθηκεύει τα IDs των αλλαγμένων μηχανών και δεν διαγράφει νέα αλλαγή που έγινε όσο ανέβαινε μια προηγούμενη. Οι παλιές διαδρομές διατηρούνται για προγενέστερες εγκαταστάσεις.
- Οι προορισμοί μεταφοράς υπολογίζονται μόνο όταν ανοίγει ο έλεγχος ενός τιμολογίου, όχι επανειλημμένα για κάθε παραστατικό στις λίστες/ενημερώσεις προόδου.
- Προσωρινά HTTP 429/502/503/504 και σφάλματα δικτύου δεν καταναλώνουν το όριο τριών αποτυχιών δημιουργίας PDF. Διατηρούνται στην ουρά με μικρή αυξανόμενη αναμονή. Άλλες εργασίες συνεχίζουν. Πραγματικό σφάλμα δημιουργίας PDF εξακολουθεί να οδηγεί σε σαφή ένδειξη επανάληψης.
- Αν το PDF υπάρχει αλλά η ανάγνωση AI απέτυχε, η Επανάληψη διαβάζει ξανά το αποθηκευμένο PDF. Δεν επιστρέφει απλώς την ίδια επισύναψη με το παλιό σφάλμα. Διατηρούνται η επισύναψη και οι επιβεβαιωμένες διορθώσεις χρήστη.
- Οι προσωρινές αποτυχίες GET επαναλαμβάνονται έως τρεις φορές. Δεν επαναλαμβάνονται αυτόματα γενικές ενέργειες POST. Μη έγκυρο JSON δεν θεωρείται κενός στόλος/λίστα και τα ήδη φορτωμένα δεδομένα διατηρούνται. Οι αποτυχίες πύλης δείχνουν HTTP κωδικό και Ray όταν παρέχεται.

## Έλεγχοι και όρια τεκμηρίωσης

- Πραγματικός Worker και SQLite συμβατή με τις SQL διαδρομές: 40 μηχανές × 500 εγγραφές (20.000), 200 συνθετικά τιμολόγια και 10 ταυτόχρονες ενημερώσεις.
- Έλεγχος πρόσβασης, αμετάβλητων άλλων μηχανών, προστασίας από παλιά εγγραφή, αρχειοθέτησης, αναμονής 503 χωρίς απώλεια ουράς, επαναφοράς πραγματικής αποτυχίας PDF και μη υποβάθμισης ολοκλήρωσης.
- Επανάληψη OCR με συνθετικό PDF/προσομοίωση AI: νέα κλήση ανάλυσης, ίδιο αποθηκευμένο αρχείο, καθαρισμός παλιού σφάλματος. Οι δοκιμές AI δεν αποτελούν μέτρηση πραγματικής ακρίβειας μοντέλου.
- Πραγματικές συναρτήσεις Client/Portal σε VM: bounded GET retries, 503 και μη έγκυρο JSON, διατήρηση συνεδρίας/δεδομένων, μη επανάληψη POST, αποστολή μόνο αλλαγμένης μηχανής και διατήρηση νέας αλλαγής κατά τη διάρκεια upload.
- Πραγματική Java πολιτική Server: αμετάβλητη εικόνα και διαφορετική σειρά ιστορικού δεν δημιουργούν upload, νεότερες τοπικές/backup καταχωρήσεις και διορθώσεις χιλιομέτρων παραμένουν, αρχειοθετημένες/διαγραμμένες εγγραφές δεν ανασταίνονται.
- Πλήρης προηγούμενη σουίτα, συνθετικά backup/restore, Java HTTP/αναγνώστης PDF/OTA, build APK, αρχικές υπογραφές και dry-run Worker.

Το μεγάλο ιστορικό ελέγχεται τοπικά. Δεν αποδεικνύει ότι κάθε αίτημα παραγωγής θα μείνει κάτω από 10 ms ή ότι το Cloudflare D1 επιτρέπει οποιοδήποτε μέγεθος μιας εγγραφής snapshot. Δεν έγινε αλλαγή λογαριασμού, πραγματική ανάλυση παραγωγικού τιμολογίου, εγκατάσταση σε φυσικό τηλέφωνο ή backup πραγματικών δεδομένων από τον βοηθό. Αν εξακολουθεί να εμφανίζεται exceededCpu σε άλλη διαδρομή, χρειάζεται το συγκεκριμένο νέο log· η αύξηση CPU απαιτεί κατάλληλο πρόγραμμα Workers.

## Ενημέρωση και ανάκτηση

Η εξουσιοδοτημένη δημοσίευση αναπτύσσει Worker 5.3.3 και διαθέτει μαζί Server 2.1.6, Client/Web 5.40.1. Εγκατάστησε Server και Client μέσω OTA πάνω από τις υπάρχουσες εφαρμογές, ολοκληρώνοντας την επιβεβαίωση εγκατάστασης Android. Η τοπική βελτίωση συγχρονισμού απαιτεί νέο Server και Client. Το Web/Worker ενεργοποιούνται αυτόματα. Αν διατηρείται παλιό Web, κάνε ανανέωση.

Πριν εγκαταστήσεις Server, διατήρησε πρόσφατο backup πραγματικών δεδομένων στον επιλεγμένο φάκελο. Ο υπάρχων μηχανισμός OTA απαιτεί backup πριν την εγκατάσταση. Δεν διαγράφονται τιμολόγια ή βάσεις, δεν ξεκινά αυτόματα μαζική επανάλυση και δεν θεωρείται λυμένη η εκκρεμής προειδοποίηση Play Protect χωρίς έλεγχο του ακριβούς μηνύματος.

Για παλιά σφάλματα QR χωρίς διαθέσιμο PDF πάτησε Επανάληψη. Για υπάρχον PDF με σφάλμα ανάγνωσης πάτησε Επανάληψη στην καρτέλα Τιμολόγια. Παλαιότερες υπογεγραμμένες εκδόσεις παραμένουν στα GitHub releases. Η υποβάθμιση μπορεί να απαιτεί απεγκατάσταση και συμβατό backup για restore· δεν γίνεται αυτόματη επαναφορά παραγωγικών δεδομένων.

Το πλήρες source ZIP/GitHub περιλαμβάνει Android Client/Server, Web/Portal, Worker, κοινό OTA, manifests/assets, lockfiles, tests, build scripts, toolchain και οδηγίες. Πραγματικά κλειδιά, δεδομένα και τιμολόγια εξαιρούνται. Για συμβατά νέα APK απαιτείται το ήδη παραδομένο ιδιωτικό αντίγραφο υπογραφής και οι εξωτερικοί λογαριασμοί που περιγράφονται στο BUILD_AND_HANDOFF_GR.md.
