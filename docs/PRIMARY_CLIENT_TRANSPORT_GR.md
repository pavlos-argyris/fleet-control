# Web / Client προς κύρια βάση Server

Η ενεργοποίηση της κύριας βάσης παραμένει ρητή ενέργεια μέσα στον Server, μετά
από πλήρη μεταφορά, σύγκριση και δοκιμή ανάκτησης. Η εγκατάσταση του update από
μόνη της δεν μεταφέρει δεδομένα ούτε ενεργοποιεί νέο writer.

## Σύνδεση

Το Web και το Client ελέγχουν το μικρό control descriptor πριν από επιχειρησιακά
αιτήματα. Σε παλιό Worker χωρίς το πρωτόκολλο και χωρίς αποθηκευμένη ταυτότητα
παραμένει συμβατή η προηγούμενη cloud λειτουργία. Ένα αποθηκευμένο αποτύπωμα
αποκλείει την επιστροφή σε μη κρυπτογραφημένα επιχειρησιακά αιτήματα.

Στην πρώτη σύνδεση native και σε αλλαγή Server ζητείται σύγκριση ολόκληρου του
αποτυπώματος με «Server → Ρυθμίσεις → Κύρια βάση Server». Η νέα ταυτότητα
αποθηκεύεται μόνο μετά από σωστή επιβεβαίωση. Διαφορετικές καρτέλες/iframe
συντονίζονται με Web Locks. Δεν γίνεται reload ούτε εκκαθάριση προσχεδίων.

Το εφαρμοσμένο πρωτόκολλο χρησιμοποιεί ephemeral ECDH P-256, domain-bound
SHA-256 derivation και AES-GCM με direction/nonce/ephemeral key/realm/generation
binding. Το relay βλέπει μόνο ασφαλή πακέτα, όχι bearer tokens, passwords,
παραστατικά ή οικονομικά JSON. Οι συνήθεις έλεγχοι αυθεντικοποίησης,
δικαιωμάτων, CAS, audit και lease εκτελούνται στη native βάση.

## Αποθήκευση και διακοπή

Κάθε επιχειρησιακή μεταβολή δεσμεύει operation UUID σε durable IndexedDB
transaction **πριν** από δικτυακή αποστολή. Η δέσμευση είναι ατομική και μεταξύ
καρτελών. Το fallback localStorage απαιτεί Web Locks και επιτυχημένη εγγραφή·
αδυναμία μόνιμης αποθήκευσης σταματά την αποστολή. Το ελάχιστο τοπικό record
περιέχει hash, λογαριασμό, generation, κατηγορία διαδρομής, UUID και χρόνο· ποτέ
token, κωδικό ή σώμα μεταβολής.

Επανάληψη του ίδιου ανεπιβεβαίωτου προσχεδίου χρησιμοποιεί το ίδιο UUID,
ακόμη και μετά από νέα σύνδεση του ίδιου λογαριασμού. Το native receipt
δεσμεύεται στην ίδια transaction με δεδομένα/audit/event. Αλλαγή περιεχομένου
ή δικαιωμάτων δεν επαναχρησιμοποιεί ανεξέλεγκτα παλιό αποτέλεσμα.

Οι ανεπιβεβαίωτες ενέργειες παραμένουν ορατές στον ίδιο λογαριασμό. Η
αρχειοθέτηση μιας παλιάς εκκρεμότητας απαιτεί ρητό έλεγχο ιστορικού και επιλογή
«Υπάρχει» ή «Δεν υπάρχει». Διατηρείται τοπική απόφαση ελέγχου. Με αλλαγή
generation δεν εκτελείται αυτόματα νέο UUID για την ίδια παλιά εκκρεμότητα.
Η παλιά ουρά τιμολογίων επίσης απαιτεί έλεγχο πριν συνεχίσει σε άλλο Server.

Η τελευταία επαληθευμένη JSON προβολή διατηρείται ανά origin/generation/actor/
security revision, έως 7 ημέρες, 40 απαντήσεις και 30 MiB. Προσωρινή απουσία
Server επιτρέπει μόνο προβολή με πραγματικό χρόνο λήψης. Δεν βαφτίζεται νέα
απάντηση και δεν χρησιμοποιείται ως επιτυχής αποθήκευση. 401/403,
αλλοίωση ασφαλούς πακέτου και αλλαγή δικαιωμάτων δεν επιστρέφουν κρυφά cache.
Logout καθαρίζει προβολές/bindings και κρατά μόνο τις ανεπιβεβαίωτες ταυτότητες.

## Αρχεία

Τιμολόγια έως 15 MiB ανεβαίνουν σε επαληθευμένα τμήματα 256 KiB με ολόκληρο
SHA-256. Επαναλαμβανόμενο upload συνεχίζει από την επιβεβαιωμένη θέση.
Μεγάλο JSON μεταφέρεται ως ιδιωτικό body handle. Απαντήσεις/εξαγωγές έως
64 MiB ανασυντίθενται byte προς byte και επαληθεύονται πριν εμφανιστούν.
Τα handles δεσμεύονται σε actor/generation/current security revision και
επανελέγχουν την αρχική άδεια παραστατικού. Η αποδέσμευση handle δεν διαγράφει
το πραγματικό παραστατικό.

## Πραγματικοί έλεγχοι

- `test-primary-cipher-native.mjs`: το **shipped** crypto JS έναντι της
  πραγματικής production Java, δύο κατευθύνσεις και απόρριψη αλλοίωσης/domain.
- `test-primary-transport.mjs`: πραγματικό WebCrypto/DOM, lost ACK και receipt,
  νέα σύνδεση, διπλό κλικ, αποτυχία δίσκου πριν dispatch, μεγάλα ελληνικά JSON,
  binary PDF, multipart, ανάκληση, αλλαγή generation και local pending review.
- `test-business-runtime-native.mjs`: πραγματική SQLite και pinned handlers,
  response principal isolation, auth/revocation, receipt/business atomicity,
  ιδιωτικά αρχεία, migration και cold recovery.
- `test-primary-transport-browser.mjs`: υποχρεωτικός Chromium 320/390/768,
  πραγματικό IndexedDB και ταυτόχρονα tabs. Εκτελείται στο CI· τοπικά δεν
  υπάρχει εγκατεστημένο browser binary και δεν δηλώνεται ψευδές PASS.

Τα JVM/CI tests δεν ισοδυναμούν με εγκατάσταση και έλεγχο Android WebView,
Android Keystore ή φυσικού cold restart στο Note 10+.
