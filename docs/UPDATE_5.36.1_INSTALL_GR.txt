FLEET CONTROL — ΔΙΟΡΘΩΤΙΚΗ ΕΝΗΜΕΡΩΣΗ 5.36.1

Η έκδοση 5.36.1 είναι διορθωτική ενημέρωση πάνω από την ήδη εγκατεστημένη 5.36.

1. Κράτησε backup του υπάρχοντος φακέλου `cloudflare-worker`.

2. Μην αντικαταστήσεις τυφλά το υπάρχον production `wrangler.jsonc`. Κράτησε το δικό σου D1 `database_id`, τα secrets και τα bindings. Αντέγραψε μόνο:

   - `src/`
   - `public/`
   - `package.json`
   - `package-lock.json`

3. Από τον φάκελο `cloudflare-worker` εκτέλεσε:

   `npm install`

   `npm run deploy`

4. Από το Server APK → «Ενημερώσεις» ανέβασε και ενεργοποίησε:

   `Fleet_Control_Web_Assets_v5.36.1.zip`

5. Ανέβασε και ενεργοποίησε το:

   `Fleet_Control_Client_v5.36.1.apk`

   Έχει versionCode `42`, επομένως αναγνωρίζεται ως νεότερο από την εγκατεστημένη 5.36 και θα εμφανίσει prompt ενημέρωσης. Δεν χρειάζεται απεγκατάσταση.

6. Στο Web κάνε μία φορά `Ctrl+F5`. Στο APK κλείσε και άνοιξε ξανά την εφαρμογή ή περίμενε τον περιοδικό έλεγχο ενημέρωσης.

Η 5.36.1 περιλαμβάνει τη διόρθωση `NaN%` και τον masked, κινούμενο zig-zag κύκλο που ακολουθεί ομαλά το πραγματικό ποσοστό, καθώς και τη ζωντανή κοινή ενημέρωση προόδου σε όλες τις συνδέσεις.

Το Server APK δεν χρειάζεται αντικατάσταση για αυτή την έκδοση.
