# Portable Android build tools

Linux x86_64 Android API 23 framework, aapt, zipalign, ECJ 3.32, dx 10.0.0 and apksigner 31.0.2, including the shared libraries and Debian package copyright files used by the existing project. SDK additions are called by reflection for compatibility. JDK 17 is installed separately. The included tar.gz has a SHA-256 checksum and is unpacked only after checking it.
