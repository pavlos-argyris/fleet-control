Εγκατάσταση Web App
Δεν χρειάζεται αρχείο IPA. Το Fleet Control εγκαθίσταται ως Web App από το Safari.
  1. 1Άνοιξε αυτή τη σελίδα στο Safari.
  2. 2Πάτησε Κοινοποίηση και μετά Προσθήκη στην οθόνη Αφετηρίας.
  3. 3Ενεργοποίησε Άνοιγμα ως εφαρμογή Web και πάτησε Προσθήκη.
Μετά την προσθήκη θα εμφανιστεί κανονικό εικονίδιο Fleet Control στην Αφετηρία.
